# 游戏美术素材

此目录集中保存游戏当前实际使用的 **69 个图像文件**：45 张生物图、战斗背景/底座/迅迅立绘 3 张、战前布阵背景/底座 3 张、开局选择背景与石龛 4 张、难度遗物选择底图与遗物图标合集 2 张、地图背景 4 张及节点石碑 1 张、标题背景和徽记 2 个、商棚背景和商品图标合集 2 个、战后休整背景 1 张、战后奖励背景 1 张，以及可伸缩弹窗石框 1 张。未接入游戏的设计预览仍放在 `design/`，字体及其授权文件仍放在 `src/ui/fonts/`。

这里是便于查看与交接的素材合集。游戏运行时仍从 `public/` 和 `src/ui/assets/` 读取对应文件；尤其旧存档可能保存了 `/01.png` 等生物图片路径，因此本次不移动或改写运行时文件。后续修改素材时，需同步更新此目录和运行时对应文件。
