# 游戏美术素材

2026-10-23新增：`buff-icons/burn-brand.png`为灼烧烙印专属64×64透明PNG，运行副本位于`public/buff-icons/burn-brand.png`。电脑／手机战场、状态详情及预加载共用；暗影印记继续使用`shadow-mark.png`。设计与原图、处理记录位于`design/previews/burn-brand-icon-v1/`，不计入下文早期69张素材统计。

此目录集中保存游戏当前实际使用的 **69 个图像文件**：45 张生物图、战斗背景/底座/迅迅立绘 3 张、战前布阵背景/底座 3 张、开局选择背景与石龛 4 张、难度遗物选择底图与遗物图标合集 2 张、地图背景 4 张及节点石碑 1 张、标题背景和徽记 2 个、商棚背景和商品图标合集 2 个、战后休整背景 1 张、战后奖励背景 1 张，以及可伸缩弹窗石框 1 张。未接入游戏的设计预览仍放在 `design/`，字体及其授权文件仍放在 `src/ui/fonts/`。

这里是便于查看与交接的素材合集。游戏运行时仍从 `public/` 和 `src/ui/assets/` 读取对应文件；尤其旧存档可能保存了 `/01.png` 等生物图片路径，因此本次不移动或改写运行时文件。后续修改素材时，需同步更新此目录和运行时对应文件。

`momo-idle/` 为迅迅待机动画制作文件，含原始帧表、透明帧表、逐帧 PNG、GIF 与质检信息；目前未接入游戏运行时，不计入上述已使用素材数量。

`page-special-icons/` 为第五批页面专用图标，另含 11 张 128 × 128 透明 PNG：胜利双剑、商店刷新、竞技场三模式、瞭望塔、宝箱结果、强化铁砧和三种造物模板。运行时副本位于 `public/page-special-icons/`，设计原稿与预览位于 `design/previews/page-special-icons-png-v1/`；页面切换预加载同步使用这些 PNG。

`ui-symbol-icons/` 为第六批通用小图标，包含 16 张 128 × 128 透明 PNG：锁头、无遗物符、四向箭头、关闭、暂停、播放、加号、星芒、两种步骤菱形、提示菱形、警告及错误标记。运行时副本位于 `public/ui-symbol-icons/`，原稿与预览位于 `design/previews/ui-symbol-icons-png-v1/`。15 张已用于现有界面，暂停图预留；全组加入通用预加载。
