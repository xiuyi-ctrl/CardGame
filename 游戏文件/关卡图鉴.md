## 双生宝箱

每箱互斥随机一项：30%获得20～50金币、30%一个普通食物（不含圣果）、30%一个主模式商店可售道具、10%当前地区随机一阶伙伴。双生符可同时开两个箱，两个结果各自结算；预览与实际一致，读档不重抽。

满员或双箱得到两只伙伴时保留全部待处理对象，处理后回宝箱结果，再继续路线；不重复发奖或重复推进蛋。钥匙门保持自身奖励（25～40金币、1个普通食物及原有概率道具），不再额外产出圣果，不能用双生宝箱概率覆盖。

## 商店与收入

普通／精英固定胜利收入10／20金币；其他战斗、奖励与事件走各自分支，贪婪之眼只提高战斗胜利直接结算金币，不重复放大奖励卡、事件或宝箱金币。

货架四件不同商品，至少一件普通食物和一件战斗药水；40%概率加一个组合包，再补足其他货，最多一包。基础价格见[道具图鉴](道具图鉴.md)，实付按难度四舍五入；刷新基础10／15／25，最多三次，贪婪之眼翻倍。不能因离开／重进或侦查重抽货架。

## 两步选择与结果反馈

硬币结果、祭坛属性、遗迹和宝箱结果在事件生成时由种子锁定，不在选项文字中泄露。正反两面胜率相同，不改变概率。净化与随机诅咒按各50%执行。

猜中或净化成功后，在事件内弹窗选宠，不跳转队伍管理。选宠期间锁定其他选项，不允许重复领奖；待选状态写入存档，重新进入不会重抽。净化可以选择无诅咒伙伴，并明确提示无需清除。随机诅咒提示实际宠物名和诅咒名；泉水提示消耗食物及获得药水；双属性强化分别提示受益对象。

## 随机蛋与背包

- 普通概率70%，从获得蛋时的地区一、二阶池等概率选择；特殊概率30%，从现有蛋生特殊池等概率选择，仍不可进化、融合或野生捕获。
- 背包物品栏显示带问号的随机蛋图标及数量；详情逐个显示剩余过关次数。既不提前显示特殊／普通结果，也不显示将孵化的物种。
- 蛋记录沿用`carriedEggs`，背包数量由实际蛋记录计算，不额外创建可使用、可出售的物品，避免数量与孵化记录不一致。
- 获得蛋的关卡不计数；每次完成关卡并回地图／幕间时推进一次，重复完成同一关可以计数。打开或关闭背包、读档、取消布阵、查看历史瞭望塔不推进。
- 首领完成时计数，幕间成熟蛋在下一幕地图孵化；满员进入新伙伴处理，多蛋可同时孵化。
- 已存档蛋保留原物种、特殊结果和剩余次数，不按70/30重抽；旧普通物种占位的成熟特殊蛋继续按既有兼容规则孵化时砂兽。

## 奇遇奖励

第一幕不生成奇遇关；第二、三幕沿用每幕最多一个奇遇关、前五层不出现的地图规则。进入后从以下7项中不重复随机抽3项，玩家选择1项；造物保留，超进化与跳关道具从新奇遇池删除。

| 奖励 | 效果 |
| --- | --- |
| 圣果宝藏 | 获得2个必定驯服残血、可驯服敌人的圣果 |
| 龙之宝藏 | 获得120金币，计入累计金币获取 |
| 属性重塑 | 指定1只伙伴，永久+6最大生命或+3速度，仅选一项 |
| 完美进化 | 指定一只尚可进化的伙伴，直接进化到所选进化分支的最终形态，不增加新诅咒、不消耗材料 |
| 神秘蛋 | 获得随机蛋，再经过3次关卡后必定孵化特殊生物 |
| 净化药水 | 获得2瓶清除负面诅咒的药水 |
| 造物·自创生物 | 选择三个模板之一，随机获得4个不同技能；队伍满也可领取，选择后进入新伙伴替换处理 |

### 完美进化

按物种已有进化链寻找合法最终形态，不能跨物种选择。火狐可在九尾炎尊／传火狐尊之间自由选择；已在幻尾火狐或传火狐分支的伙伴继续到对应最终形态。最终形态、蛋生生物和造物不可选择。

保留主宠UID、站位、永久属性加成、已有诅咒和自创技能；技能及被动采用最终形态的既有规则，生命回满。原诅咒仍存在，但不会像旧超进化奖励那样新增随机诅咒。进化过程中不消耗另一只伙伴。

界面展示真正的最终形态预览；有多个最终分支时先选择分支再确认。第一幕地图没有奇遇，正常流程从第二幕起获得该奖励；不借此放宽第一幕的常规传奇融合限制。

### 属性重塑

指定伙伴后再选择生命或速度；两步选择和6／3参数随存档保存。实际属性、永久`bonusStats`、预览与按钮数值一致，保留已经生效的被动属性，不引入上限或随机倍率。

仅修改主模式新奇遇的属性重塑。熟练度模式属性之赐仍为生命+5或速度+2；旧存档已经生成的旧属性强化待选保留5／2。

### 奇遇神秘蛋

使用现有问号随机蛋图标和背包孵化进度。特殊结果从时砂兽、百变兽、镜影兽、晶核兽中等概率锁定，不包含普通生物。普通随机地图生成时即保存物种；定向测试入口按固定节点种子确定，领取和读档不重新抽取。

领取本关不计数，之后完成3次关卡即可孵化，允许重复同一关卡；打开背包、查看历史情报和读档不推进。幕间、满员处理、旧特殊蛋兼容沿用既有孵化流程。

这项奖励100%特殊，与流浪事件“神秘蛋”的70%普通／30%特殊规则分别处理。背包不提前揭示具体物种。

### 兼容范围

不重抽旧存档已经生成的奇遇候选及已领取待选奖励；旧进化之光、超进化和跳关奖励仍按保存时的规则完成。新生成奇遇才使用7项新池。

删除跳关仅指奇遇奖励池，不删除旧背包已有跳关道具、其他来源及使用功能。熟练度独立奇遇池不变。存档格式版本不变，新字段可选，缺省沿用原规则。


## 造物

三个模板随机获得4个不同技能，固定形态、不能进化或融合。当前属性、被动与技能池见[生物图鉴](生物图鉴.md)及[特殊机制](新生物设计/特殊生物与技能机制.md)。

## 主模式首领战利品

第一幕首领胜利获得40金币、1秘晶，第二幕获得60金币、1秘晶（金币沿用贪婪之眼加成）。固定奖励直接入账，再从以下三项中选择一项；普通战后恢复比例不变，不额外全体满血。

| 方向 | 第一幕 | 第二幕 |
| --- | --- | --- |
| 伙伴招募 | 当前地区两位不同二阶候选中选择一位 | 当前地区两位不同传奇候选中选择一位 |
| 伙伴强化 | 指定伙伴永久生命+4或速度+1 | 指定伙伴永久生命+6或速度+2 |
| 远征补给 | 2个随机普通食物、1瓶指定药水 | 1圣果、2瓶指定药水（同一种） |

招募卡不提前展示候选物种；满员进入新伙伴处理。强化和补给选择后锁定奖励，再选择对象或药水，不能返回重选；候选、补给与锁定状态随存档固定。第一幕胜利即开放传奇融合，领取后战后修整，再进入幕间结算，继续先到下一幕地图。

第三幕首领取消全部战利品：无金币、秘晶或特殊三选一，直接进入通关结算。熟练度模式不采用本规则；旧档已经生成的奖励保留，不读档重抽。
