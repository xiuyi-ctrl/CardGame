# 煤煤与炉甲獾

接入日期：2026-10-20。一、二阶与后续传奇形态均已实现，独立立绘尚未制作。

## 属性与技能

| 生物 | 阶段 | 生命 | 速度 | 技能 |
| --- | --- | --- | --- | --- |
| 煤煤 | 一阶 | 15 | 1 | 炭爪、炉壳 |
| 炉甲獾 | 二阶 | 22 | 2 | 炭爪、炉壳、灰烬庇护 |

- 炭爪：攻击单个前排敌人，造成2点伤害并附加灼烧1层；无前排时沿用后排回退规则。
- 炉壳：自身和指定的一名友方各获得3点护盾，冷却1回合。不能重复选自己获得6点；独自上场时仅自身获得3点；指定伙伴结算前阵亡时仍为自身加盾，不自动转给其他伙伴。
- 灰烬庇护：一名己方存活伙伴（可以是自己）获得4点护盾；施放时存在灼烧敌人则额外获得2点。每次施放占用一次基础行动。

## 被动：炉火 / 炽炉

煤煤被动名为「炉火」，炉甲獾被动名为「炽炉」。每个完整回合，前两次受到敌方攻击技能命中并存活后，使攻击者灼烧：煤煤1层，炉甲獾2层。日志与动画显示各自的实际被动名。

- 按一次技能行动计数，同一次多段攻击对同一只炉火生物只触发一次。
- 护盾完全吸收攻击仍触发；致死攻击不触发。
- 状态技能、灼烧/中毒结算、反伤和被动伤害不触发，避免循环。
- 敌我共享一整个回合的触发上限，下回合开始重置，新战斗不继承旧计数。
- 只附加灼烧，不立即结算灼烧伤害，不增加基础行动次数。

## 获取与成长

- 第一幕普通单体遭遇和“煤煤＋灼灼”组合加入煤煤；精英、斗兽场及守卫共用的第一幕精英候选池加入炉甲獾。
- 主模式一阶招募、孵化及相关事件池加入煤煤；二阶候选池加入炉甲獾，战后招募仍按幕次开放二阶。
- 两只煤煤融合成炉甲獾，沿用主宠永久强化、诅咒与固定技能组规则。
- 两只炉甲獾可融合为传奇熔炉兽，需先击败第一幕首领；不占用或替换原六条主要进化链。
- 开局六种选择不变；主模式各幕对应阶级遭遇、车轮战及熟练度对应阶级池均已补齐，见[灼烧生物与技能投放](灼烧生物与技能投放.md)。
- 暂未配置独立PNG立绘，使用现有獾图标回退，不借用其他生物立绘。

## 验证范围

专项测试覆盖敌我炉火、多段计数、每回合上限与重置、护盾命中、致死攻击、持续伤害、状态动画归属、技能冷却、4/6点护盾、敌方辅助选目标、融合与获取入口。数值为首版参数，尚未做真人体验或完整平衡评估。



# 烛烛与灯翅蛾

接入日期：2026-10-20。一、二阶与后续传奇形态均已实现，独立PNG立绘尚未制作。

## 属性与固定技能

| 生物   | 阶段 | 生命 | 速度 | 技能             |
| ------ | ---- | ---- | ---- | ---------------- |
| 烛烛   | 一阶 | 9    | 5    | 烛火、添薪       |
| 灯翅蛾 | 二阶 | 15   | 6    | 烛火、添薪、护灯 |

- 烛火：攻击单个敌人，造成3点伤害并附加灼烧1层，沿用普通前排保护规则。
- 添薪：选择一个已经灼烧的敌人，追加灼烧3层；跨前后排，但仍遵守嘲讽及嗜血目标限制。不造成即时伤害，不属于攻击技能。
- 护灯：为一名己方存活伙伴（包括自己）回复3点生命值，不超过最大生命；属于治疗技能，不再提供护盾。
- 以上主动技能均占用施法者一次基础行动。

## 被动：余温

存活持有者在场时，本阵营每回合首次攻击一个攻击前已经灼烧的敌人后触发：烛烛的「余温」为当前生命值最低的一名存活伙伴回复2点；灯翅蛾的「余温」为当前生命值最低的两名不同存活伙伴各回复2点。只有一名存活伙伴时只治疗一名。

- 敌我一个完整回合为一次计数周期，下回合开始重置。双方分别计算自己的机会。
- 同一阵营的同名被动共享每回合一次机会，不分别叠加。多个持有者同时在场时取最高值（先比较治疗值，再比较目标数量），因此同队时优先采用灯翅蛾的两目标版本。治疗对象在触发时一次选定，不因第一名回复后重新选择同一对象。
- 伙伴或持有者自身的攻击均可触发；多段、群攻和额外行动不会突破共享上限。
- 本次攻击刚点燃目标不触发；后续攻击该燃烧目标才可触发。
- 添薪、灼烧/中毒结算、反伤及被动伤害不触发。
- 按当前生命绝对值选择治疗对象，不按生命比例或缺血量；同值时按队伍顺序取第一只。满血不溢出，不复活阵亡伙伴；最低血量者已满血时，不改治其他伙伴。
- 第一次符合条件的攻击即消耗机会；全员满血时不会将机会存到本回合后续受伤时。
- 战斗存档保留本回合已触发标记，读档不刷新次数。

## 获取与融合

- 第一幕普通单体遭遇加入烛烛，双单位遭遇加入煤煤与烛烛组合；第一幕精英候选池加入灯翅蛾。
- 主模式一阶招募、孵化及相关事件池加入烛烛，二阶候选池加入灯翅蛾；战后招募沿用分幕二阶概率。
- 两只同形态烛烛融合成灯翅蛾；两只灯翅蛾可融合为传奇长明灵蛾，需先击败第一幕首领。沿用主宠永久强化、诅咒和固定技能组规则。
- 开局六种选择不变；主模式各幕对应阶级遭遇、车轮战及熟练度对应阶级池均已补齐，见[灼烧生物与技能投放](灼烧生物与技能投放.md)。图鉴自动展示。
- 暂用蝴蝶图标回退，不借用其他生物立绘；独立美术待制作。

## 熔炉兽

煤煤 → 炉甲獾 → 熔炉兽。传奇基础生命31、速度2，定位为反击点燃与护盾支援。

被动「熔炉之心」：每回合前两次受到敌方攻击技能命中且存活后，使攻击者灼烧2层，每次触发为自身获得1点护盾。

- 一次攻击技能计一次，多段不重复计数；护盾吸收命中仍可触发。
- 持续伤害、状态技能、反伤不触发；致死命中不触发。
- 每只独立计数，敌我一整个回合结束后，下回合开始重置。

| 固定技能 | 效果                                                         |
| -------- | ------------------------------------------------------------ |
| 熔岩重爪 | 攻击单个前排敌人，造成6点伤害；攻击前目标已灼烧则额外造成2点伤害 |
| 熔炉壁垒 | 自身获得8点护盾，冷却1完整回合                               |
| 灰烬庇护 | 一名己方存活伙伴获得4点护盾；施放时场上存在存活灼烧敌人则额外获得2点 |
| 封炉     | 全体存活己方伙伴各获得3点护盾，每场战斗限3次                 |

灰烬庇护同样适用于炉甲獾，可指定自己；条件在实际施放时判断。

## 长明灵蛾

烛烛 → 灯翅蛾 → 长明灵蛾。传奇基础生命23、速度6，定位为灼烧延续与全队回复。

被动「长明之光」：每回合我方首次攻击一个攻击前已经灼烧的敌人后，为全体存活伙伴各回复3点生命值。

- 每只持有者独立计次，不与另一只长明灵蛾或余温共享次数；多只可以同时触发。
- 持有者必须存活，伙伴或自身攻击均可触发；多段、群攻与额外行动不突破每只每回合一次。
- 本次攻击才附加灼烧不触发；添薪、旺火、迁移、持续伤害与反伤不触发。
- 满血不溢出、不复活；符合条件的第一次攻击即消耗机会。战斗读档不刷新标记，下回合或新战斗重置。

| 固定技能 | 效果                                                         |
| -------- | ------------------------------------------------------------ |
| 长明烛火 | 攻击单个敌人，造成5点伤害并附加灼烧2层                       |
| 旺火     | 为一个已灼烧敌人追加灼烧5层，不造成即时伤害                  |
| 护灯     | 为一名己方存活伙伴回复3点生命值，可指定自己                  |
| 余烬迁移 | 从指定灼烧敌人转移最多4层灼烧给随机另一名存活敌人，总层数不增加；冷却1完整回合 |

旺火与余烬迁移可跨前后排，仍遵守嘲讽和嗜血目标限制。余烬迁移仅剩一名敌人时不可选用；随机通过可播种随机源产生。

## 融合与获取

- 两只同物种、同形态二阶生物融合；传奇融合在第一幕首领胜利后开放。
- 使用新形态固定技能与被动，继承主宠永久属性强化、诅咒及已有自创技能，不继承材料宠强化或技能。
- 加入主模式第二幕精英、斗兽场、守卫及第三幕对应传奇遭遇；第三幕多单位组合与车轮战同步加入。主模式传奇获取池及熟练度传奇池同步包含两者，开局仍为原六种。详见[灼烧生物与技能投放](灼烧生物与技能投放.md)。
