## 二、P0：必须生成

### 2.1 应用图标（2 张）

**（1）Windows 应用图标**

- 用途：便携版 `.exe` 图标（桌面/任务栏/资源管理器）、Electron 窗口图标。
- 现状：`package.json` 的 `build` 段**没有 `icon` 字段**，打包沿用 Electron 默认图标（AGENTS.md 已记录该问题）；`win.signAndEditExecutable: false` 跳过签名不影响图标注入。
- 规格：
  - 源文件：**512×512 或 256×256 PNG，透明底**；
  - 或直接提供 `.ico`（含 256/128/64/48/32/16 六档尺寸，electron-builder 可从 PNG 自动生成 ICO）。
- 文件名与位置：`build/icon.png`（electron-builder 默认查找 `build/icon.ico` / `build/icon.png`）。
- 接入改动：`package.json` → `build.win.icon: "build/icon.ico"`（或 `build.icon` 全局字段）。
- 设计要求：小尺寸（16×16）仍可辨识；建议主视觉 = 龙形宠物 + 卡牌轮廓，底色用 UI 主色暗紫 `#241b3d`，描金 `#e8c26a`。

**（2）网页 favicon**

- 用途：浏览器标签页图标（`npm run dev` 走浏览器调试时可见；Electron 内不明显）。
- 现状：`index.html` **无 `<link rel="icon">` 标签**，`public/` 下也无 favicon 文件。
- 规格：**32×32 PNG/ICO**（可复用应用图标缩小版）。
- 接入改动：文件放 `public/favicon.ico`（或 `public/favicon.png`），`index.html` `<head>` 内加 `<link rel="icon" type="image/png" href="/favicon.png" />`。

### 2.2 缺失生物立绘（5 张）

- 用途：战斗卡（`.pet-image`）、生物图鉴大图、队伍/成长/铁匠铺/技能强化等界面的 `PetIcon`。
- 现状：`monsters.ts` 共 **50 个物种，45 张有图，5 张缺图**，界面显示对应 emoji 兜底。
- 通用规格：
  - **正方形、透明背景 PNG**，建议统一 **1024×1024**（见 §3.2 尺寸现状说明）；
  - 单体全身像，风格与现有 45 张一致（暗紫奇幻卡牌厚涂、轻描边、角色占画面约 80%）；

## 五、统一技术规范

| 项目 | 要求 |
|------|------|
| 格式 | 立绘/图标：**透明背景 PNG**；背景图/宣发：JPG 或 WebP（控制体积） |
| 色彩 | sRGB；与 UI 主色协调（背景暗紫 `#241b3d`、描金 `#e8c26a`、状态紫 `#b08dff`、治疗绿 `#6fd8a8`、伤害红 `#ff6b6b`） |
| 立绘尺寸 | 1024×1024（新图统一；现有 648/1280 混用靠 CSS 兼容） |
| 图标尺寸 | 64×64（道具/节点/遗物/事件）、48×48（状态/技能）、32×32（被动徽章/favicon） |
| 文件命名 | 全小写英文/数字，不含中文与空格；立绘沿用 `NN[-n].png` 编号体系 |
| 存放位置 | **运行时图放 `public/` 或 `src/ui/assets/`**（自动进包）；当前图像素材合集放根目录 `美术素材/`（不打包），未使用的草稿放 `design/`；应用图标放 `build/` |
| 体积控制 | 单张 PNG ≤ 1MB；立绘总量建议 ≤ 60MB（当前 45 张约 30~40MB） |
