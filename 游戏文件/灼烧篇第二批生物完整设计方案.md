# 灼烧篇第二批生物完整设计方案

版本：1.5。日期：2026-10-20。范围：五条进化链、15只可驯服生物、5只首领候选，以及它们使用的全部技能。

1.5接入：光苔球、光苔兽及灼烧反转；日炎灵仍未实现。净化在主动单体治疗后处理，每只持有者独立计次，不由群体治疗、被动恢复或吸血触发。

1.4调整：熔甲兽去掉铁刺、战吼，改用热壳顶撞与熔甲震荡；烈日神鹰改用火羽，掠日破盾增加按技能实际剥盾量转火。两只传奇本轮接入，其他未实现内容不随本次开放。

本文是本批生物的完整设计基准，替代旧差异化修订方案中的冲突内容。已接入熔甲、焚风两条完整进化链及光苔球、光苔兽；燃孢、幻尾两条链、日炎灵、本批首领与虚火未接入。范围见[一阶记录](熔壳虫与焚风雏鹰实现记录.md)、[二阶记录](熔甲虫与焚风鹰实现记录.md)、[传奇记录](熔甲兽与烈日神鹰实现记录.md)、[光苔记录](光苔球与光苔兽实现记录.md)。数值为首版参数，不代表已通过平衡评估。本文不修改煤煤、烛烛等既有生物效果。

## 一 玩法目标与生物配合

五条链分别提供播火、自燃换盾、破盾、净化和虚火保护。每条链可单独使用，也能与其他链或已有伙伴搭配，不要求集齐固定五只才开始发挥作用。

| 进化链 | 提供的作用 | 主要承接者 | 保留的取舍 |
| --- | --- | --- | --- |
| 燃孢崽 → 燃孢菇 → 瘟疫伞王 | 击杀后向尚未燃烧的目标播火 | 焚风、灼灼、熔炉兽、烛烛系列 | 没有击杀或没有新目标时，传播被动不产生收益 |
| 熔壳虫 → 熔甲虫 → 熔甲兽 | 自燃换盾、消耗护盾进攻 | 光苔治疗、炉甲獾加盾、焚风烙印 | 自燃会真实掉血，冲撞会减少自己的防护 |
| 焚风雏鹰 → 焚风鹰 → 烈日神鹰 | 高速烙印、燃烧条件剥盾 | 慢速熔甲、燃孢收割、其他单体输出 | 对无盾目标没有剥甲收益，不能给全队每段增伤 |
| 光苔球 → 光苔兽 → 日炎灵 | 单体治疗和异常净化 | 自燃熔甲、承伤前排、虚火持有者 | 提前清掉熔甲灼烧会减少下一回合的燃料 |
| 幻尾狐崽 → 幻火狐 → 九尾炎尊 | 为伙伴准备虚火，命中后封印具体攻击技能 | 脆弱焚风、前排熔甲、反击型煤煤 | 占用行动、保护量小、封技有共享次数；不能取消已经发生的攻击 |

### 本版相对上一稿的实质完善

1. 虚火幻身、借火藏形改为可以指定己方伙伴，包括自己。封招能力来自施法者被动，不要求被保护者属于幻尾系列。
2. 熔火自焚定为自损1点生命、获得4层真实灼烧和2点即时护盾，避免只有成本、没有当回合防护。回合结束仍会扣灼烧生命。
3. 烙印由下一次友方攻击承接，在该次攻击完成后一次引爆目标剩余全部灼烧并清空。不再提供固定2点加伤，不按段重复引爆；层数越高，集中结算收益越高，同时消耗后续持续伤害资源。
4. 光苔可以在熔甲完成回合开始转换后治疗，不必每次都毁掉燃料；危急时仍可用反转主动放弃燃料换取生存。
5. 普通形态适当提高生命作为首版起点，避免新增体系必须融合后才可使用；仍需要站位、治疗与虚火保护，不给予阵亡豁免。
6. 本批生物不再携带爪击或暗爪，分别以孢火弹、热壳顶撞、循焰飞羽、破式狐火替换；这是本批固定技能组的修改，不删除其他现有生物的技能。
7. 焚风雏鹰、焚风鹰、烈日神鹰统一使用火羽：先手单体5伤害＋灼烧2层。其他物种的火花不变；三个形态均已实现。
8. 熔甲虫、熔甲兽以热壳顶撞替换铁刺，熔火巨像不变。熔火自焚、裂壳冲撞均无冷却，仍受每只生物基础行动次数、生命和护盾条件限制。

## 二 通用规则

### 2.1 属性和行动

只有最大生命、当前生命、速度三项基础属性，不增加等级、攻击力、防御力或元素克制。本文面板不包含永久强化、诅咒、难度倍率和熟练度层数缩放。

敌我共同完成的一整轮为一个回合。每只存活且未被限制的生物每回合有一次基础行动，已有被动提供的额外行动继续遵循原规则。准备阶段按原流程选择指令，结束回合后按速度和已有先手规则执行；同速沿用现有确定性排序。

技能标注冷却1回合，表示使用后的下一完整回合不能再次使用。未标次数上限的技能可重复使用，但仍受行动、冷却、封印和目标条件限制。

### 2.2 真正灼烧

灼烧叠加层数。每回合结束的结算阶段，造成并消耗当前层数的一半，向上取整，层数归零移除。例如5层依次结算3、1、1点。沿用现有结算规则直接扣生命，不由普通护盾吸收；已有特殊伤害上限等规则仍按原逻辑处理。

不采用原Word中的固定每层2伤害、逐层独立两回合、上限6层规则。自燃获得的也是真正灼烧，既可作燃料，也会伤害自己；虚火不是灼烧。

### 2.3 目标与结算

- 普通单体敌方技能遵守前排保护；前排全灭后才能选择后排。文中标明“直接指定”的技能可以跨排，但继续遵守现有嘲讽和强制目标规则。
- 己方单体技能可选择任意存活伙伴，包括自己，不受前后排保护限制。
- 所有对手或伙伴在实际结算时都必须仍存活。指定目标死亡时按现有失效规则处理，不擅自改选另一对象。
- 治疗不超过最大生命，不复活。剥盾不产生额外生命伤害，也不触发“受到伤害”被动。
- “一次攻击”指一次攻击技能行动，而非一个命中段；所有新增被动均不因多段重复计数。
- 攻击前灼烧、护盾等条件在该次攻击开始时记录，不因本次攻击才附加灼烧而追溯满足条件。
- 所有随机经可播种随机源产生。同版本、同状态、同指令可复现。

### 2.4 融合与驯服

两只相同物种、相同形态融合为下一形态。主模式在击败第一幕首领后才开放传奇融合。融合采用新形态固定技能与被动，沿用主宠永久强化、诅咒与已有自创技能的现行继承规则，不继承材料宠强化，不增加旧技能保留选择。

可驯服生物仍要求满足当前残血与品阶规则；“驯服难度”是原有概率计算参数，不是固定成功率。首领不可驯服、不可融合，不作为玩家融合材料。

## 四 普通生物详情

### F01 燃孢崽

定位：击杀后承接下一目标准备的小型播火支援。生命11，速度3，品阶1，驯服难度0.75。

外观：小型褐红蘑菇，菌盖边缘散出橙色孢光，避免与紫色法师蘑菇立绘混用。

被动「初燃播种」：一个死亡前已灼烧的敌人阵亡后，向随机一名尚未灼烧的存活敌人施加1层灼烧。本阵营播火系列每回合共享一次；持有者必须存活，不要求由自己击杀。

| 技能 | 基础效果 |
| --- | --- |
| 孢火弹 | 单体4伤害；目标攻击前未燃烧时附加灼烧3层 |
| 火花 | 单体攻击6伤害，附加灼烧2层 |

配合：先用火花点燃，让迅迅、焚风或其他伙伴完成击杀；传播出的1层火为后续烛烛回复、熔炉兽条件增伤提供入口。弱点：单首领且没有小怪时，传播没有目标，必须依靠正常主动攻击。

融合：2只燃孢崽 → 燃孢菇。建议获取：第一幕普通遭遇、招募和孵化的一阶池；不加入开局候选。

### F02 熔壳虫

定位：低速自燃坦克，为后续盾攻形态打基础。生命14，速度2，品阶1，驯服难度0.70。

外观：黑炭色幼虫，壳缝微红，身体低矮；与四足獾和熔炉兽保持明显轮廓区别。

被动「热壳换火」：每回合开始、上一回合灼烧结算完成后，消耗自身最多1层灼烧，每层换2点护盾。每只持有者独立计算，不免疫剩余灼烧。

| 技能 | 基础效果 |
| --- | --- |
| 热壳顶撞 | 单体4伤害；命中后消耗自身1层灼烧，获得2盾；无火仍可攻击 |
| 熔火自焚 | 自损1生命，获得4层真实灼烧与2护盾；无冷却 |

配合：光苔在下回合换盾后治疗它；幻尾可以提前给它虚火，降低自燃准备回合的承伤。弱点：盾不能挡灼烧，低血时不能盲目自燃。

热壳顶撞还允许主动消耗残余1层火，提前换盾并避免该层后续持续伤害；代价是下一回合也少1层被动燃料。没有燃料时仍可用它正常攻击，不强迫每回合自焚。

融合：2只熔壳虫 → 熔甲虫。建议获取：第一幕一阶遭遇及对应随机伙伴池；不加入开局候选。

### F03 焚风雏鹰

定位：高速、条件剥盾。生命10，速度5，品阶1，驯服难度0.75。

外观：浅棕幼鹰，翅尖像烧过的羽毛，眼周一圈橙金色，不做另一只火焰狐狸。

被动「灼羽剥甲」：每回合首次攻击一个攻击前已灼烧且有护盾的敌人时，伤害前额外移除其2点护盾。无盾或未燃烧目标不消耗机会，不追加生命伤害。

| 技能 | 基础效果 |
| --- | --- |
| 循焰飞羽 | 单体4伤害；可越过前排攻击已经燃烧的后排，未燃烧者仍遵守前排保护 |
| 火羽 | 先手单体5伤害，附加灼烧2层 |

配合：承接上一回合残留灼烧，或利用速度更快伙伴提前点火；剥盾让随后出手的燃孢和熔甲更容易完成击杀。弱点：它通常比燃孢快，不能假定同回合慢速燃孢点火后自己还能先手受益。

也可主动选择火羽先手为合法前排点火，让本回合后手伙伴承接燃烧条件；没有额外行动时，不能同回合再施放循焰飞羽。

循焰飞羽可利用上一回合铺在后排的火越过前排，优先处理治疗或辅助；是否跨排取决于目标实际有真灼烧，不只看标记图标。

融合：2只焚风雏鹰 → 焚风鹰。建议获取：第一幕一阶池；需要前排或虚火保护。

### F04 光苔球

定位：能处理轻度灼烧的单体治疗。生命12，速度3，品阶1，驯服难度0.75。

外观：圆润淡绿苔球，中心暖白光，叶尖凝露，不使用太阳形人脸图标代替立绘。

被动「吸热苔」：每回合首次使用单体治疗技能后，额外移除被治疗伙伴1层灼烧；没有灼烧也消耗本回合机会。只由自己的主动治疗触发。

| 技能 | 基础效果 |
| --- | --- |
| 水弹 | 单体攻击3伤害 |
| 护灯 | 为一名己方伙伴回复3生命，可选自己 |

配合：在熔壳虫完成回合开始换盾后补回生命，也能救被敌人点燃的焚风或幻尾。弱点：当回合提前清火会减少下一回合换盾量，治疗不是始终无代价的最优选择。

融合：2只光苔球 → 光苔兽。建议获取：第一幕一阶池。

### F05 幻尾狐崽

定位：有限次保护与关键技能反制。生命11，速度4，品阶1，驯服难度0.70。

外观：灰白幼狐，尾尖出现半透明橙光，轮廓轻盈，避免与迅迅和灼灼同色同姿。

被动「疑火」：由自己施加的虚火在任意存活伙伴身上被敌方攻击消耗，且施法者与持有者在该技能后都存活时，封印攻击者刚使用的攻击技能，持续至下回合结束。每场战斗最多触发1次。

| 技能 | 基础效果 |
| --- | --- |
| 破式狐火 | 单体4伤害；目标攻击前有被封印的攻击技能时额外2伤害 |
| 虚火幻身 | 己方一名伙伴获得2层虚火，持续至下回合结束；冷却1回合 |

配合：保护正在自燃的前排，或为焚风挡住一次关键攻击；也可保护煤煤，让它承伤反灼烧后限制攻击者下一回合的技能。弱点：比自己更快的敌人本回合可能已经出手，保护不会追溯生效。

融合：2只幻尾狐崽 → 幻火狐。建议获取：第一幕一阶池。

## 五 精英生物详情

### F06 燃孢菇

定位：主动小范围播火与击杀续火。生命17，速度4，品阶2，驯服难度0.40。

外观：双层橙红菌盖，背部孢囊膨大，出手时孢子从菌褶飘出。

被动「传火孢」：每回合本阵营首次有灼烧敌人阵亡后，向随机一名尚未灼烧的敌人施加灼烧，层数为死亡前层数与2的较小值；与其他燃孢形态共享一次机会。

| 技能 | 基础效果 |
| --- | --- |
| 孢火弹 | 单体4伤害；目标攻击前未燃烧时附加灼烧3层 |
| 火花 | 单体攻击6伤害并附加灼烧2层 |
| 孢子引爆 | 单体攻击4伤害；目标攻击前已燃烧时，向另一未燃烧敌人播火1层 |

配合：焚风先用烙印点燃并标记，燃孢菇随后用引爆承接灼烧爆发；击杀传播给下一目标。弱点：敌方全员已燃烧时无法再靠扩散叠高层，应该改用攻击；烙印清空灼烧后，需要重新点火才能继续利用燃烧条件。

融合：2只燃孢菇 → 瘟疫伞王，受传奇解锁门槛限制。建议获取：第一幕精英，第二幕普通及对应二阶招募、孵化池。

### F07 熔甲虫

定位：盾攻两用前排。生命19，速度3，品阶2，驯服难度0.40。

外观：宽背甲虫，前端硬角带橙色熔线，冲撞时合拢甲片。

被动「熔蜕」：每回合开始时，消耗自身最多2层灼烧，每层换2点护盾，最多获得4点。转换发生在上一回合灼烧结算后。

| 技能 | 基础效果 |
| --- | --- |

## 七 首领完整设计

首领是候选内容，不意味着本次直接替换现有首领。首版统一不新增专属小怪，不把可驯服传奇直接塞入首领队伍；先验证单体战斗，再决定是否制作配套随从。首领阵亡后该战斗按原胜利流程结束，不额外复活或强制第二阶段。

行为优先级：危急时净焰照护；有自身燃料且治疗压力较低时倒流；没有有意义的治疗或转移目标时水弹。不在满血时反复空治疗。

玩家应对：利用奇偶节奏安排点火、施毒与集火。封印其水弹不能自动封印全部状态和治疗技能；其治疗有行动成本且强治疗限次，允许常规输出队打穿。

建议胜利奖励：沿用第三幕首领标准。

### F20 九尾魔尊

### N01 孢子引爆

建议ID：fire_spore_burst。分类：攻击。敌方单体，普通前排保护。伤害4，CD0，次数不限。

目标在攻击前已灼烧时，在本次攻击结束后向随机另一名未灼烧的存活敌人附加1层灼烧。只有一名敌人、其他敌人全已燃烧时，只造成基础伤害。额外播火不要求主目标存活，但要求本次攻击实际命中。

先进行技能自带播火，再处理本次击杀引发的燃孢共享传播。共享传播重新检查“未燃烧”，不会选择刚被技能点燃的对象。两种来源各自有限，不产生即时持续伤害。

配合：利用烙印集中击杀并点亮新的目标。不是点燃后立刻结算灼烧的伤害技能。

### N02 火孢散播

建议ID：fire_spore_sow。分类：状态。随机选择最多两名未灼烧的存活敌人，不受普通前排保护；继续遵守既有强制目标规则。每名附加灼烧2层，无即时伤害。冷却1，次数不限。

没有合法未燃烧目标时不可选择；执行时只剩一名合法者就只施加一名，已燃烧者不改为叠层。目标不重复，不触发攻击命中、吸血或长明之光。

### N03 熔火自焚

代码ID：molten_self_burn。分类：状态。目标自身。无冷却，次数不限。

实际执行时必须生命大于1：先直接失去1生命，再给自己附加4层真实灼烧，获得2点普通护盾。自损无视护盾，不触发攻击受击、反击、虚火和吸血；这1点自损不会单独杀死自己，但随后的灼烧可能。

自焚不立即触发回合开始转换。即时2盾只能挡后续正常攻击，不能挡回合结束灼烧。学会该技能但没有熔甲转换被动的生物不会自动获得转换能力，玩家应能看见这一风险。

### N04 裂壳冲撞

建议ID：shell_charge。分类：攻击。敌方单体，普通前排保护。无冷却，次数不限。

执行时自身至少有1盾。记录并消耗自身最多4盾，基础伤害为3＋实际消耗数，范围4至7，再按已有攻击修正和目标防护计算。技能使用前被打掉护盾，会降低实际伤害；若执行时已无盾，指令失效、不自动改招。

消耗盾是支付资源，不是受到攻击或破盾事件；不触发虚火、不反伤。可以消耗自己转换或伙伴给予的普通护盾，每次最多4，不随总盾量无限扩大。

### N05 灼烧烙印

建议ID：burn_brand。分类：状态。直接指定任意敌方单体，遵守强制目标限制。冷却1，次数不限。

目标获得2层真实灼烧与1份烙印。下一次本阵营攻击技能实际命中它时，消耗烙印；该次技能的攻击伤害、技能与被动附加状态及即时反击结算后，若目标仍存活，将它当时剩余的全部真实灼烧一次结算，并清空灼烧。

例如目标原有5层，烙印附加2层，随后由不附加灼烧的攻击命中，则在攻击伤害后引爆7层，按灼烧规则造成7点灼烧伤害并清空。若承接的是火羽且成功附加2层，则引爆当时9层；若中途层数被净化、迁移或自然消耗，则只按实际剩余层数计算，不锁定施印时数值。

引爆是一次灼烧结算，不是额外攻击：不吃战吼等攻击增伤，不由普通护盾吸收，遵守现有特殊伤害上限；即使伤害被上限截断，仍清空全部层数。多段整次技能只引爆一次，群攻只引爆各自已被标记并实际命中的目标，不能在每一段重复引爆。标记目标没有灼烧时也会消耗烙印，但额外灼烧伤害为0。

持续伤害、反伤、纯状态技能不消耗烙印，不触发引爆。攻击伤害全部被普通护盾吸收仍算命中；只有指令失效或没有实际命中才不消耗。目标被攻击本体直接击倒时不再对尸体追加引爆，死亡传播按正常致死事件记录；若由引爆击倒，则死亡事件保留清空前灼烧层数快照，供燃孢传播判断，不因先移除状态而丢失触发资格。

每目标每来源阵营最多1份烙印，重复施放可正常叠加技能本身的2层灼烧，但只刷新标记，不增加引爆次数。烙印最晚保留至下回合结束。两个阵营分别归属，不能由敌人的攻击替我方消耗；目标阵亡移除标记，烙印本身不随燃孢传播。

要求攻击前已灼烧的既有被动，仍依据承接攻击前的状态正常触发；烙印爆发不额外触发一轮攻击被动。引爆后若目标存活且没有新的独立后续点火，它不再满足后续攻击的燃烧条件，因此存在“现在引爆还是留火”的取舍。

### N06 掠日破盾

建议ID：sun_sunder。分类：攻击。敌方单体，普通前排保护。基础伤害4，冷却1，次数不限。

伤害前额外移除目标最多4盾。若本次同时满足焚风被动，先剥被动值，再剥技能值，之后正常伤害。技能实际移除每2盾附加1层灼烧，向下取整、最多2层；被动移除和伤害吸收的盾不计入，不足2盾不附火。剥盾余量不转为生命伤害。

无盾目标仍可攻击，只有基础4伤害；不会因此占用焚风的条件剥盾机会。

### N17 熔甲震荡

ID：molten_quake。攻击，全体敌人，基础3伤害并附加灼烧1层，冷却1回合。选择与执行时都需自身至少3盾；执行前失盾则失效，不换招。整次施放只扣3盾，不按目标数扣费。伤害和附火沿用各目标正常攻击结算，可承接烙印；反伤等照常，不产生额外行动。

熔甲震荡、掠日破盾归熟练度传奇技能池。默认沿用混合攻击强化：震荡每级伤害＋1、灼烧＋1，固定耗盾3；掠日破盾每级只加基础伤害2，剥盾上限4、每2盾转1火及最多2火不随强化增加。两技能最多强化3级，传奇消耗倍率不变。

### N07 灼烧反转

建议ID：burn_reversal。分类：治疗。己方单体，可选自己。冷却1，次数不限。

先移除最多3层真实灼烧，再回复2＋实际移除层数的生命，基础最多5。没有灼烧仍可治疗2。被动净化在本次基础治疗后处理，不追加进本技能的层数计价。

例：目标5层火，技能移除3层、治疗5；若施法者为光苔兽且本回合净化未用，随后被动再移除1层，最终余1层，而不是治疗6。

### N08 净焰照护

建议ID：clean_flame_care。分类：治疗。己方单体，可选自己。CD0，每场2次。

先回复4生命，技能移除1层灼烧，再处理该次施法可触发的光苔净化被动。只要该技能或本次被动实际移除了灼烧或中毒，最后再回复2生命；最多追加一次，不按种类或层数叠加。

没有净化被动的学习者仍可获得“治疗4＋移除1层火＋符合条件时治疗2”。无异常时只治疗4。追加治疗不是新技能，不递归触发被动。

### N09 虚火幻身

建议ID：illusory_flame。分类：增益。己方单体，可选自己。冷却1，次数不限。

目标获得2层虚火，虚火上限2层，持续至下回合结束。已有虚火时补足到2并刷新持续，不增加到4。该次实际施法者记录为此份虚火的来源；详细所有权和封技规则见第九节。

虚火每层将一次敌方攻击技能对持有者的总伤害减少2点。该技能本身不提供护盾、真正灼烧、伤害反射、嘲讽或封印；封印需来源生物仍持有并能触发对应被动。

### N10 借火藏形

建议ID：borrowed_flame_veil。分类：增益。己方单体，可选自己。CD0，每场2次。

目标获得1层虚火并刷新至下回合结束，仍受总上限2；同时移除目标1层降攻或减速，优先降攻。没有对应减益仍可使用，不能清除诅咒、恐惧、眩晕和技能封印。

获得虚火即使达到层数上限也刷新来源和持续，不凭空恢复来源已经使用过的封技次数。不是免费的换位或额外行动。

### N11 阴阳倒流

建议ID：yin_yang_backflow。分类：状态。直接指定敌方单体，遵守强制目标规则。冷却1，次数不限。首领专属。

消耗自身最多2层真实灼烧，向目标附加等量灼烧，总层数不增加。自身无灼烧时不可选，执行时无燃料则失效，不额外造成伤害或治疗。与长明灵蛾的余烬迁移不同：这里只从自身向敌人转移，不搬运两名敌人之间的火。

### N12 孢火弹

建议ID：fire_spore_bolt。分类：攻击。敌方单体，普通前排保护。基础伤害4，CD0，次数不限。

若目标在攻击开始前没有真实灼烧，命中后附加灼烧3层；原先已灼烧则只造成基础伤害，不叠加这3层。由其他伙伴在本次攻击之前点燃，会改变实际执行结果，技能预览应标明条件。

定位是铺设首层较厚灼烧，供后续孢子引爆、焚风跨排、燃孢死亡传播和既有烛烛系列使用。对已有火的目标改用火花叠层或孢子引爆扩散，而不是所有场景无脑用同一招。它不在本次刚点燃时追溯触发要求“攻击前已燃烧”的效果。

### N13 热壳顶撞

建议ID：heated_shell_bump。分类：攻击。敌方单体，普通前排保护。基础伤害4，CD0，次数不限。

技能实际命中并完成攻击及其即时反击后，若施法者仍存活且有真实灼烧，消耗自身1层灼烧，获得2点普通护盾。每次技能最多一次；无灼烧仍可造成4点基础伤害。消耗只减少层数，不额外造成灼烧伤害，不是治疗或受击。

这是熔壳虫在准备燃料后的主动调节手段，不替代后续回合开始的被动换盾。当前消耗掉的1层，不能再拿去做下一回合的转换；新获得的盾不能抵挡已经结算的伤害，也不能吸收灼烧。没有换盾被动的学习者也能使用这次明确写入技能的1层换2盾，但不会获得自动回合转换能力。

### N14 循焰飞羽

建议ID：flame_tracing_feather。分类：攻击。敌方单体。基础伤害4，CD0，次数不限。

普通情况下遵守前排保护；如果所选后排在技能实际执行前已有真实灼烧，则允许越过仍存活的前排攻击它。后排未燃烧且前排仍存活时不可选；准备阶段合法但执行前灼烧被移除，则本次指令失效，不改打前排。没有存活前排时按正常回退规则可选后排。

不附加灼烧，不提高伤害，不无视护盾或减伤，继续遵守嘲讽和其他强制目标规则。虚火、烙印图标本身不等于真灼烧；有烙印但灼烧已被清除时，不能单凭烙印跨排。

配合火孢散播跨排点火、焚风自身上一回合烙印或已有伙伴铺火。命中已有火且有盾的后排时，可以正常触发焚风条件剥盾；不额外赠送剥盾次数。

### N15 破式狐火

建议ID：sealed_style_foxfire。分类：攻击。敌方单体，普通前排保护。基础伤害4，CD0，次数不限。

目标在攻击开始时至少有一个尚未到期、确实被封印的攻击类技能，则本次额外增加2点攻击伤害。被封印的只有治疗、增益或状态技能时不满足条件；仅在冷却中、次数耗尽或因目标限制不能用，也不算封印。

封印可以来自本系虚火被动，也可以来自其他伙伴；不要求由这只狐施加。多个攻击技能被封印仍只加2，不消耗或延长封印，不按段重复加伤。额外伤害与基础伤害一起经过正常减伤和护盾，不附加真灼烧。

没有封印时是4伤害；有封印时为6伤害。与火花的区别是承接控制而非叠火，可在需要保留目标未灼烧状态、或不想给自燃换盾敌人补燃料时使用。

### N16 火羽

代码ID：fire_feather。分类：攻击。敌方单体，遵守普通前排保护和现有强制目标规则。基础伤害5，命中附加灼烧2层，先手，CD0，次数不限。

先手指该次技能行动排在非先手技能之前，不是额外行动；多名先手行动之间仍按现有速度与同速排序。火羽不因为使用者同时拥有循焰飞羽就获得跨排能力。

灼烧在命中后施加，因此不能让本次攻击追溯触发“攻击前已灼烧”类剥盾或回复；后续伙伴攻击可利用这2层灼烧。焚风雏鹰、焚风鹰、烈日神鹰均已使用此技能；其他物种的火花不变。

## 九 被动与新增状态的严格规则

### 9.1 燃孢共享传播

三个可驯服形态每阵营每回合共享1次。优先选目标数更多的档位，再比较每目标层数上限；同档按队伍顺序确定日志来源。不同形态同场不把次数相加。

死亡事件前记录灼烧层数，技能击杀、持续伤害击杀和合法被动击杀均可触发；不是尸体仍留有状态就重复触发。持有者须在当前事件后存活。多人同时死亡按现有确定性事件顺序，先发生的符合条件死亡消耗机会，不回头挑层数最大的尸体。

没有未燃烧目标也视为本回合机会已用。传播只附加状态，不即时伤害、不直接制造下一次传播。腐化伞王使用自己单独的首领计数；双方阵营不共享次数。

### 9.2 回合交界与熔甲转换

顺序为：本回合行动完成 → 正常灼烧/中毒结算及死亡 → 旧回合效果到期处理 → 新回合开始触发与次数重置 → 玩家准备指令。新回合转换只消耗持续伤害结算后剩余的灼烧，不提前拦截上一回合本应承受的灼烧伤害。

新战斗不凭空带入燃料或虚火。转换不消耗基础行动、不制造生命治疗、不触发受击。每只持有者独立，转换得到的护盾与已有盾相加，遵守现有护盾总上限；每次转换上限不等于把原有护盾清零重设。

### 9.3 焚风剥盾

每只持有者每回合一次。判定攻击前同时有真灼烧和正数护盾，先剥被动盾，再剥技能盾，再计算正常攻击。多段只剥一次；额外行动不重置机会。

群攻时被动只作用于一名满足条件者，选择护盾最多者，同值按站位顺序；不对每个群攻目标都给一份。对无盾或未燃烧者攻击不消耗机会。

### 9.4 光苔净化

每只施法者每回合一次，只由自己使用单体治疗技能触发。伙伴的被动回复、持续回复、治疗道具和追加回复不触发。首次符合类别的治疗即消耗机会，无异常也不保留到本回合后续行动。

先完成技能自身规定的清除和基础治疗，再对目标实际剩余异常进行被动净化；净焰照护的条件追加治疗最后结算。满血伙伴仍可被选择用于净化，实际回复量钳制到最大生命。

不清除普通护盾、虚火、烙印归属、诅咒或未列出的异常，不把“净化”泛化为任意移除所有负面状态。

### 9.5 虚火减伤与来源

虚火是独立增益，每目标总上限2层，与普通护盾和真实灼烧分开显示。一个目标的整份虚火只记录一名来源，最新一次成功施加或刷新覆盖归属；不把两名幻尾的层数混存，也不能一次消耗触发两名来源被动。

当敌方攻击技能对持有者产生正数的正常攻击伤害时，整次技能最多消耗1层虚火，提供2点总减伤额度。额度从首个正数伤害段开始依次抵扣，剩余额度可用于同一技能后续段，最低抵到0，不返还生命。再按正常顺序由护盾吸收剩余伤害。

伤害本来会全部被普通护盾吸收时仍可消耗虚火；原本没有正数攻击伤害时不消耗。持续伤害、反伤、自损、己方技能、纯状态技能不消耗。移除虚火不是移除护盾，不能被破盾技能或灼烧反转直接处理。

施法者阵亡后，已给予的虚火仍保留减伤直到到期，但不再封技。持有者在攻击后阵亡也不封技。来源是没有封技被动的学习者时，虚火始终仅提供减伤。

### 9.6 封招时机与上限

封印发生在整次攻击技能完成后，不取消本次已选技能，不吞掉多段后续命中。封印的对象是攻击者刚使用的确切技能，持续至下回合结束。只限制该技能，不让整个单位无条件失去基础行动。

次数属于施法来源，来源保护的全部伙伴共享上限：疑火每场1次；镜火封式每回合1次；九尾惑技和幻境封招每回合2次，同一攻击者每回合只贡献一次。

多名幻尾可分别持有自己的上限，但同一份虚火仅触发其记录来源。次数用完后虚火仍减伤，但不追加封印。来源被封印主动技能不等于其被动失效；死亡才按上节停止封技。相同技能的重复封印只刷新至较晚到期，不累加持续。

眩晕、封印、虚火、烙印和各类计数需要随战斗存档保存；读取存档不刷新次数。新战斗按正常规则清空临时标记。

## 十 可实际执行的配合示例

### 10.1 烙印收割与播火

组合：焚风鹰、燃孢菇，加一名前排和治疗。

1. 焚风鹰速度6，先用烙印给合法可攻击目标2层火与标记；烙印本身没有额外先手属性。
2. 燃孢菇速度4，孢子引爆仍造成4点基础攻击伤害，并因目标攻击前已有火，向另一未燃烧敌人播火1层。
3. 若主目标仍存活，攻击结束后引爆其实际剩余的全部灼烧；在没有其他层数变化时，这里是2点灼烧伤害，然后清火。若此前已有更多火，引爆相应增加。
4. 若主目标因攻击或引爆阵亡，燃孢按对应死亡前快照传播；不向已经被技能播火点燃的对象继续堆火。若目标存活，原目标已经没有火，下回合不能继续直接吃其燃烧条件。

这条配合需要合法目标、速度和一次击杀，不预设每次必能杀死。只有两名敌人时，主动播火已经点燃剩下一名，被动可能没有传播目标。

### 10.2 自燃 换盾 治疗 冲撞

组合：熔甲虫、光苔兽、幻火狐。

1. 第一回合幻火狐可先给熔甲虫虚火，光苔兽按实际血线决定治疗其他伙伴或攻击。
2. 熔甲虫自焚，直接损失1生命、获得4层火与2盾。回合结束火结算2点，剩2层；不考虑敌人伤害时累计失去3生命。
3. 第二回合开始，熔甲虫消耗剩余2层火获得4盾；此前2盾若未被打掉，则现有6盾。
4. 光苔兽速度4，先用愈光回复至多8生命；由于燃料已经转换，不会额外毁掉这2层燃料。
5. 熔甲虫速度3，消耗最多4盾冲撞，基础伤害7。若之前6盾仍在，则留下2盾；如果被打掉部分，则伤害按实际剩余盾重算。

对熔甲兽，同样两层燃料转换为6盾。上例不承诺敌人一定攻击指定目标，也不将护盾视为能吸收灼烧。

### 10.3 前排反击与虚火封技

组合：已有煤煤或炉甲獾、幻火狐、光苔。

幻火狐先给前排虚火；敌人用攻击命中前排后，虚火最多减2点，煤煤在满足原有条件时仍可对攻击者施加真灼烧。整次攻击结束后，狐的来源被动封印该技能；下回合玩家可以利用已点燃目标，或让光苔修复前排血线。

已有煤煤被动上限和狐的封技上限分别计算，不互相刷新；虚火不把煤煤的反灼烧层数翻倍。

### 10.4 播火与长明灵蛾续航

组合：燃孢菇或瘟疫伞王、已有长明灵蛾、任意输出前排。

燃孢把真实灼烧铺到新目标后，下一次我方攻击在攻击前已经燃烧的目标，可满足长明之光。第一次点火的状态技能不触发回复；点火攻击如果目标原先没有火，也不能回溯触发。长明灵蛾每只独立一次的现有规则不改，燃孢不额外赠送治疗次数。

### 10.5 拆盾与慢速冲撞

组合：烈日神鹰、熔甲兽、已有炉甲獾或熔炉兽。

敌人已有灼烧时，烈日神鹰先用掠日破盾，可剥最多4被动盾＋4技能盾，再结算4点基础攻击；熔甲兽后手用已准备护盾冲撞。另一回合可以改为烙印，由冲撞命中后引爆目标当时剩余全部灼烧；不再给冲撞本体固定加2。

没有额外行动时，鹰不能同回合既烙印又破盾；若两技能跨回合安排，必须确认标记尚未被其他攻击消耗。外部盾能支援冲撞，但慢速加盾者若在熔甲之后行动，只能准备下回合资源。

### 10.6 需要保留的冲突

- 燃孢擅长点燃尚未燃烧者，长明灵蛾的余烬迁移可调整已燃烧目标层数；二者不保证永远同时有最佳目标。
- 光苔提前净化能救命，但可能使熔甲下一回合无燃料；玩家可以换目标治疗，或接受放弃燃料。
- 友方抢先攻击会消耗烙印；虚火保护错对象也可能整轮不触发。体系要求查看出手顺序，而不是所有增益自动锁定最佳伙伴。
- 多名同系燃孢不增加传播次数；单一攻击者不能连续触发传奇狐两次封招，避免同种堆叠成为唯一阵容。

### 10.7 新普攻与跨链承接

燃孢用孢火弹点燃一个未燃烧目标，后续伙伴攻击它即可利用真灼烧条件。若被点燃者在后排，下一回合焚风可在灼烧仍存在时使用循焰飞羽跨排；火已归零则不能继续跨排，不预支未来的点火。

幻尾给前排虚火，敌人攻击并被封印后，下一回合狐可用破式狐火承接6点基础条件伤害；与火花不同，它不会给熔甲类敌人补燃料。没有其他攻击技能被封印时只能造成4点，不是永远优于火花。

熔壳虫的热壳顶撞则允许选择把最后1层真灼烧在行动中换成2盾，或保留给下一次被动转换。它不从队友身上抽火、不消耗虚火，不与普通护盾混用燃料。

## 十一 获取与模式接入设计

此节是完整批次的接入要求。当前熔甲、焚风完整进化链及光苔前两阶已接入；燃孢、幻尾、日炎灵与本批首领尚未实现。

### 主模式

- 开局选择、开局同伴仍保持现有候选，不加入本批生物。
- 一阶加入第一幕普通各规模组合、车轮战及一阶招募、商店招募、孵化和相关事件池。
- 二阶加入第一幕精英、斗兽场和守卫，并进入后续普通混编、二阶招募和孵化池。
- 传奇加入第一幕首领之后开放的融合，以及第二幕精英、斗兽场、守卫和第三幕普通混编、传奇阶级获取池。第一幕地图不直接生成本批传奇。
- 侵蚀战复用普通遭遇。各幕人数、规模概率、关卡权重与现有车轮战轮数不额外扩大；组合不得同时堆满大量治疗、封技和自动盾。
- 招募奖励卡不提前显示候选，沿用锁定奖励后进入候选界面的规则，不额外偏向已有进化链。
- 五只首领作为对应幕的新候选，幕次按第七节；加入时保留现有首领候选，不强制每局都遇到新首领。

### 熟练度模式

- 可驯服三阶分别加入对应生物池，沿用层数门槛、生命缩放、强化和竞技场规则；商店仍从一阶池招募，镜像仍只复制我方。
- 主动学习只获得技能，不获得原物种被动。尤其自焚不自带换盾，虚火不自带封招，UI必须明确说明。
- 普通新增技能池：孢子引爆、熔火自焚、裂壳冲撞、灼烧烙印、灼烧反转、虚火幻身、孢火弹、热壳顶撞、循焰飞羽、破式狐火、火羽。
- 传奇新增技能池：火孢散播、掠日破盾、熔甲震荡、净焰照护、借火藏形。其中掠日破盾、熔甲震荡已接入，其他仍待实现。
- 禁用玩家学习池：阴阳倒流。复用技能不重复加入，不因传奇也会使用火花或水弹而把它们升为传奇。
- 本批四个替代技能均保留各自机制，不套用原通用普攻的高层替换映射，也不把孢火弹强行升级成用途不同的孢子引爆。既有通用映射只作用于仍实际携带对应原技能的生物；不把自焚替换为无关输出，不把治疗替换为攻击。新技能没有自然高阶版本则只强化。
- 新首领不自动替换熟练度15、30、50层的现有规则；首版仅主模式候选。若要加入熟练度，另做首领缩放和50层兼容验证。

## 十三 美术与界面信息

- 每只生物制作独立透明PNG，不借用现有其他物种立绘；普通、精英、传奇保持轮廓连续，首领保持明显体量差异。
- 真灼烧继续使用已有灼烧图标；虚火使用橙紫半透明焰形，烙印使用鹰爪状日纹，不复用真灼烧图标以免混淆。
- 战场按现行最多3个Buff图标显示，并使用既有排序与右键详情展示所有状态，不为本批改成无限图标列。
- 虚火详情显示层数、每次减伤、来源、到期；烙印显示“下次我方攻击命中后引爆全部灼烧并清空”、归属与到期；被动详情显示已用次数与上限。不要把当前层数当成锁定的最终伤害，层数仍可能在引爆前变化。
- 自焚、冲撞在指令区显示资源要求；技能选中后不显示一个已经支付但实际执行前还能无代价回退的假资源值。
- 首领技能和被动在开战前及右键详情中可查，不将关键免伤、封技或燃料规则隐藏成未知惩罚。

## 十四 验收与数值检查

1. 三种燃孢共享次数、同回合多死亡、持续伤害死亡、持有者死亡、目标全燃烧、施法播火与死亡传播先后顺序。
2. 自焚生命不足、灼烧直扣生命、前后回合燃料变化、转换后治疗、冲撞执行前失盾、来自队友的盾可用但每次最多4。
3. 烙印多人抢占、多段只引爆一次、本次命中附加的新灼烧计入、零层命中也消耗标记、引爆后清空与死亡传播快照、后排标记不赋予普通攻击跨排能力、剥盾不变成额外生命伤害。
