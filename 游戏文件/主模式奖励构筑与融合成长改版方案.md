# 主模式奖励构筑与融合成长改版方案

记录日期：2026-10-19。

本文整理讨论后的修改版方案。问题依据见[主模式问题分析](主模式问题分析.md)。本阶段仅记录设计，不修改运行时代码。

## 一、设计目标

奖励决定“这局怎么玩”，融合决定“哪些伙伴承担这套打法”。

- 同一种开局可以发展出不同阵容与配合。
- 玩家能够主动争取成长材料，而不是完全等待随机重复宠。
- 融合的收益与减少单位的成本清晰、可判断。
- 保留现有六条主要进化链，优先利用已有灼烧、中毒、护盾、反伤和速度机制。

## 二、已确认的修改与排除项

| 项目 | 结论 | 状态 |
| --- | --- | --- |
| 公共行动点机制 | 删除，不再维护或展示队伍共享的行动点预算 | 2026-10-20 已实施 |
| 基础行动 | 每只存活、未受眩晕等限制的生物，每回合拥有一次基础行动 | 2026-10-20 已实施 |
| 额外行动被动 | 保留暗影追猎等被动明确提供的额外行动 | 已保留，补齐我方追加行动结算 |
| 进化保留旧技能 | 不加入“进化时用一个旧技能替换新技能”的功能 | 用户明确排除 |
| 主模式常规进化技能 | 继续采用新形态的固定技能组 | 沿用现有设计 |
| 祝福获得时机 | 每幕开始时、战胜该幕首领后各一次 | 用户已明确确认，未实施 |
| 同系伙伴定向保底 | 不加入连续未获得同系伙伴后的定向选择机制 | 用户明确排除 |
| 本阶段工作 | 仅整理文档，不改运行时代码 | 用户明确要求 |

除已确认的祝福获得时机外，远征祝福的其他参数、招募候选调整及每阶两只融合仍为建议方案，不因写入本文而视为已确认执行。

### 行动规则的配套约定

以下沿用现有交互方向，作为后续实施时的默认约定：

- 玩家先给各生物选择技能，点击“结束回合”后，敌我按速度统一执行。
- 结算前可以修改或取消尚未执行的技能指令，不涉及扣除或返还行动点。
- 换位占用发起者本回合的基础行动；另一只被交换位置的生物不因此失去自己的行动。
- 捕获和使用道具不占用生物基础行动，仍消耗相应物品。
- 休息表示该生物放弃本回合行动；眩晕、死亡、刚召唤入场等限制继续按规则处理。
- 公共行动点删除不等于放宽出战人数上限，也不等于允许同一生物重复执行基础行动。
- 额外行动属于明确被动效果，不计入基础行动次数限制；保留已有防止无限连动的约束。

## 三、奖励构筑：普通补给与关键选择配合

### 1. 普通战后保留补给职责

普通战后的食物、恢复和招募继续承担短期补给与扩充队伍的作用。避免每场战斗都加入复杂的永久效果选择，使流程过于冗长。

### 2. 新增持续整局的“远征祝福”

获得时机已确认，其余第一版参数仍为建议，具体数值待验证：

| 项目 | 建议初始方案 |
| --- | --- |
| 获得时机 | 每幕开始时一次、战胜该幕首领后一次 |
| 全局选择次数 | 三幕完整通关共 6 次，其中最终首领后的 1 次不计入通关前的有效构筑机会 |
| 每次候选 | 三选一 |
| 携带上限 | 最多 4 个 |
| 重复获得 | 同一祝福最多强化一次 |
| 首批规模 | 约 12 个 |
| 持续范围 | 本次远征，随新一局重置 |
| 作用对象 | 队伍或指定机制，不依附于某只材料宠的存活 |

祝福在宠物融合或阵亡后仍保留，避免构筑因为单只宠物的损失完全清空。它与开局遗物区分：开局遗物继续提供起步资源，祝福承担局内持续构筑。

祝福不再依赖幕中节点触发。上一幕首领战后的选择与下一幕开始时的选择分别保留，不合并为一次；最终首领后的选择没有后续主线战斗收益，评估构筑强度时需单独统计。

### 3. 祝福优先改变配合方式

| 方向 | 效果概念 | 希望产生的决策 |
| --- | --- | --- |
| 灼烧 | 击败燃烧目标时，将部分灼烧转移给另一名敌人 | 集中击杀与灼烧铺场如何配合 |
| 中毒 | 每回合首次攻击中毒目标时，攻击者恢复少量生命 | 施毒者与承接攻击者如何分工 |
| 护盾 | 每回合首次为队友加盾时，同时治疗另一名受伤伙伴 | 支援单位何时使用护盾 |
| 速度 | 每回合首次以低于目标的速度攻击时，附加少量减速 | 慢速队也有可发展的应对路线 |
| 通用生存 | 提供有限的容错与恢复收益 | 在专门配合与稳定生存之间选择 |

以上是效果概念，不是已确定的技能文本或最终数值。首批应利用现有状态与战斗事件，不为每个祝福另建一套独立战斗规则。

### 4. 限制收益放大

- 明确“队伍每回合一次”“每个目标一次”或“击杀一次”等触发范围。
- 多段、群攻、反伤、持续伤害和召唤物是否触发，必须逐项定义。
- 避免一次附加状态又触发自身附加状态，形成循环。
- 不能只按面板伤害给效果定价，需考虑段数、目标数、次数和持续时间。
- 携带上限达到后，应允许替换或放弃新祝福，不自动移除已有构筑。
- 候选既提供已有方向的延伸，也保留转向和通用选项，避免第一次选择锁死全局。

## 四、招募：增加候选方向性

建议对现有招募奖励做以下调整：

1. 选择招募奖励后，从两只明确展示的生物中选择一只。
2. 提高已有进化链伙伴的候选权重，同时保留不同物种，允许玩家改变路线。
3. 第二、三幕逐步允许二阶伙伴进入招募池，避免后期仍只能从零开始积累材料。

候选权重以及高阶候选概率尚未确定。不加入连续未获得同系伙伴后的定向选择或保底补偿机制。

目标是让玩家能够完成构筑，但不保证每一局都得到同一套最优阵容。

## 五、融合成长：降低材料阻塞，保留固定技能组

### 1. 建议统一为每阶两只同物种

| 阶段 | 当前通常需求 | 建议方案 |
| --- | --- | --- |
| 一阶升二阶 | 两只同物种 | 两只同物种 |
| 二阶升三阶 | 三只同物种 | 两只同物种 |

若完全从基础宠合成一只三阶宠，通常成本由六只同系基础宠降为四只；直接捕获二阶伙伴和免费进化仍可以缩短成长路径。

这项仍属建议，后续需要验证是否导致传奇出现过早、队伍重复度上升或材料失去价值。

### 2. 不实施旧技能继承选择

- 主模式常规进化继续使用新形态的固定技能组。
- 不增加“保留一个旧技能”的选择界面。
- 不增加从材料宠复制技能或被动的机制。
- 本项讨论不涉及删除熟练度模式营火融合原有的技能继承流程。

主宠已有永久强化的保留继续按原规则处理；特殊自创生物原有规则不在本轮常规进化改版中扩展。

### 3. 重新核算融合前后的队伍价值

删除公共行动点后，两只宠物仍然各有一次基础行动，融合成一只后基础行动只有一次。因此不能认为删除行动点已经解决融合后的短期战力下降。

融合评估必须同时比较：

- 融合前后实际可上场的人数及基础行动次数。
- 队伍总生命、护盾、治疗和持续恢复能力。
- 一回合及连续两到三回合的有效输出，而非只看单段面板。
- 速度变化是否跨越关键敌人的出手顺序。
- 新技能与新被动能否在当前队伍及祝福下发挥作用。
- 空出的出战位置是否有合适伙伴填补。

不能为补偿融合人数损失，给所有进化单位无条件增加额外行动。这会与多段、群攻和被动触发进一步叠加。明确提供额外行动的现有被动仍保留。

### 4. 各阶承担不同成长职责

- 二阶：提供可靠的基础战力与更明确的角色，让早期融合具有可感知收益。
- 三阶：提供机制突破，让它成为本局构筑的核心或重要支点。
- 不使用统一倍率机械放大所有物种；输出、治疗、护盾、反伤与速度型分别评估。
- 不要求融合在任何局面都无条件最优，但要让收益与代价可理解，避免“进化后明显更弱且没有新用途”。

### 5. 融合确认展示必要信息

确认前显示：

- 主宠与将被消耗的材料。
- 融合前后的属性、固定技能和被动变化。
- 队伍人数减少及出战阵容是否出现空缺。
- 永久强化与诅咒的保留结果。

不显示旧技能继承选项，也不把减少单位的成本隐藏在“进化成功”之后。

## 六、建议实施顺序与验证

| 阶段 | 工作 | 验证重点 |
| --- | --- | --- |
| 1 | 校正自动玩家与合法开局、布阵规则 | 不能绕过出战人数；分清模拟能力与真人体验 |
| 2 | 实施已确认的行动规则简化 | 每只一次基础行动；额外行动被动、眩晕、取消指令和车轮战正常 |
| 3 | 制作少量祝福与关键奖励流程 | 同一开局能形成不同阵容与配合；触发不循环 |
| 4 | 调整招募方向性与融合成本 | 材料等待降低，三阶不会过早普及 |
| 5 | 分角色调整融合收益 | 常见融合不会频繁造成无法解释的战力下降 |
| 6 | 重调普通、困难与地狱参数 | 分幕、分首领检验，缩小常规战与关键战断层 |

每轮控制改动范围，先确认成长结构，再调整敌方倍率。不要同时大量修改祝福、宠物面板、融合成本与难度参数，以免无法判断结果来源。

### 需要观察的结果

- 同一开局在不同种子下，是否出现不同的祝福组合、终局阵容和战术选择。
- 各进化链材料获取次数、等待时长、融合次数与融合发生的幕次。
- 融合后短期输出、续航及胜率变化，区分有无替补填补空位。
- 普通战、精英、首领以及特殊挑战的损失与失败分布。
- 首领前是否有足够准备机会，以及失败原因是否可理解。
- 治疗、食物、金币和战斗道具是否各自存在实际选择价值。

## 七、当前状态

2026-10-20 行动规则已接入：删除共享行动点字段与界面显示，按单位独立记录基础行动；换位仅占发起者行动，捕获与药水不占行动、不自动结算。旧存档加载时移除废弃行动点字段。暗影追猎保留追加行动，次数与冷却正常消耗。此项不修改宠物、敌人及融合数值。

本文是修改后的设计记录。删除公共行动点、每只生物每回合一次基础行动、保留额外行动被动，以及不加入旧技能保留功能，已按用户要求纳入方案。

祝福获得时机已确定为每幕开始时和战胜该幕首领后，同系伙伴定向保底已排除。其余奖励构筑参数、招募候选调整、每阶两只融合及具体数值仍待确定和验证。当前没有为这些方案修改运行时代码。
