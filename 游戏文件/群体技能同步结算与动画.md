# 群体技能同步结算与动画

## 执行规则

- 群攻同一段的全部合法目标先承受伤害与技能附带效果，然后处理反伤、受击被动、死亡自爆、治疗联动及其他后续效果。
- 多段群攻按“第一段全部目标 → 第一段后续效果 → 第二段全部目标 → 第二段后续效果”的顺序执行。不把所有段数合并成一次伤害。
- 同一段已经发出的群攻，不因首个目标的反伤杀死施法者而漏掉其他目标；施法者死亡后不再发出下一段。
- 同段全部目标死亡时，保留该段所有目标的命中与死亡反馈，后续段和战斗结束后的动画停止。
- 群体友方治疗、护盾与增益同步作用于全部目标；炉壳对自身与指定伙伴也同步显示。治疗引发的净化等后续被动在该批治疗之后处理。
- 伤害前剥盾、减伤、免疫等本就参与本次伤害计算的规则仍在伤害计算时生效；攻击自带的灼烧、中毒等随命中同步显示。
- 随机多目标攻击按预先选定目标分批，同一目标重复命中仍分段播放；不额外抽取目标。
- 单体技能保留原有执行顺序，不改技能面板、次数、冷却或强化表数值。

## 实现与兼容

战斗逻辑将群体主效果与后续反应分开执行。局部反应队列只在本次技能调用内存在，不写入存档。

同批日志携带可选的 `simultaneousGroup` 标记，并保存该批完成后的统一生命、护盾与状态快照。动画队列令同批目标在同一时间点起播，后续反应在下一动画节拍播放。不同目标仍保留各自的伤害／治疗飘字，不把不同减伤、护盾结果合并成一个数。

旧存档和旧日志没有此标记时仍按原有方式读取。电脑与手机端共用动画实现，无页面布局修改。

## 验证

专项测试覆盖群攻统一快照、反伤延后、反伤击杀施法者、多段群攻、终结群攻、死亡自爆连锁、治疗后净化、群体治疗／护盾与炉壳，以及动画首帧同时飘字。

自动化动画验证使用实际 React Hook 与模拟时钟；不视为人工视觉验收。真机与桌面实机观感尚待确认。本次不生成 APK、不提交或发布版本。

验证结果：13项专项测试通过；完整87个测试文件、926项测试通过；生产构建通过（含TypeScript检查）。
