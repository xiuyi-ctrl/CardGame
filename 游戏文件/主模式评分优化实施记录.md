# 主模式评分优化实施记录

日期：2026-10-25。仅新开的主模式远征启用新评分，已有存档、历史最高评级及解锁不追溯重算；熟练度模式保持原有独立结算。

## 一、评分公式

总分100，分别计算四项，不再给全部维度统一乘以幕次系数。

| 维度 | 满分 | 公式与口径 |
| --- | ---: | --- |
| 远征进度 | 50 | 50×三幕完成比例平均值。单幕未击败首领时，按完成路线层数/该幕总层数计算；击败该幕首领才按完整一幕计算 |
| 阵亡控制 | 25 | 25×clamp(1－阵亡数/累计参战人次/20%,0,1)。没有真实参战记录时为0 |
| 挑战战绩 | 15 | 每幕最多5分。精英、侵蚀、守卫胜利2点；斗兽场、车轮战胜利3点。5×min(1,该幕实际挑战点/该幕挑战目标)，三幕相加 |
| 战斗效率 | 10 | 逐场计算min(1,参考回合/实际回合)，取平均×10。没有真实战斗记录时为0 |

挑战目标一般为5点；检查发现混合地区第二幕seed13等地图的可达路线不足5点，因此每幕目标取5点与无需钥匙合法可达路线最大挑战点的较小值。完全没有挑战机会的幕，击败首领后才得到该幕5分。该目标在本幕首次完成节点时记录，不因消耗钥匙、购买或战斗结果反复变化，不调整地图布局或随机顺序。

效率参考回合：普通/事件4，精英/侵蚀/守卫/斗兽场6，首领10，车轮战max(4,敌人数×4)。快于参考回合不额外加分；这些是首版参数，后续可依据真人表现调整。

各维度和总分严格限制在各自上限；总分最后四舍五入，明细显示到一位小数。捕捉成功率、消费、金币结余、融合次数和终局队伍人数不直接参与总分，保留原统计与对应遗物解锁。

## 二、统计入口

- 每个“幕次:节点ID”最多记录一次真实战斗，确认战斗结算时写入结果、实际回合、参战人数、阵亡人数及敌人数。
- 额外行动、技能选择、取消指令不增加回合或参战次数；新远征总回合由真实已结算战斗加当前战斗已执行轮次计算。
- 车轮战按uid合并当前与已倒下的出战者，排除未登场替补，整关只算一场和一次挑战胜利。
- 记录生命降为0且结算时未当场复活的参战者；时砂回溯当场存活不算阵亡。离场后使用复活石不会抹除记录。挑战失败被战后保底救回的倒下伙伴仍计入战斗损失。
- 融合、主动释放、事件献祭不记为战斗阵亡；捕获新伙伴补入队伍不抵消阵亡。同步修正原先用队伍人数差判断阵亡的遗漏。
- 合法跳关只计路线进度，不记战斗、挑战胜场或效率。进入节点、进入布阵、取消布阵、打开/关闭背包不计完成。
- 非战斗节点在完成返回地图或继续前进时计路线进度；正常战斗胜利计进度，挑战/事件战斗失败但可继续路线也计完成该节点，终止远征的失败节点不计完成。
- 模拟战、熟练度、自定义测试不进入新主模式评分；调试跳转退回旧评分，不伪造缺失的前三幕统计。

## 三、评级与兼容

| 等级 | 分数线 |
| --- | ---: |
| S | 90 |
| A | 75 |
| B | 55 |
| C | 40 |
| D | 低于40 |

未击败第一幕首领最高C；未击败全部三幕首领最高B。总分照常显示，评级旁明确说明限制原因。只走普通战、完整通关且无阵亡、效率达标可得85分A；更高评级需额外挑战表现。

新主模式开局初始化`runStats.rating.version=2`；缺少此字段的旧存档沿用原五维计算并显示“旧评分”，不把未知统计补成零阵亡或满效率。旧公式的历史行为不追溯修改，显示条宽度仍受容器约束。

普通A级通关解锁困难、困难A级通关解锁地狱的条件不变，原有遗物统计条件不变；已有解锁和最高评级继续保留。新评分记录随存档保存，读档及重复确认不重记。
