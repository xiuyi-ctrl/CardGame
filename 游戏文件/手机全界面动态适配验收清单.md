# 手机全界面动态适配验收清单

日期：2026-10-21。横屏优先，竖屏保留旋转提示及可操作兜底。不修改玩法、数值、存档结构、关闭规则和电脑端布局。

## 布局规则

- 手机入口仍为 Android 或符合触控媒体条件的网页；手机 CSS 最后加载并限定在 `.mobile-ui` 下。
- 使用实际 CSS 视口和安全区，不按物理截图像素计算尺寸，不使用整页缩放。
- 覆盖桌面媒体查询遗留的最小高度、绝对定位及纵向堆叠；立绘、卡片网格与间距按可用空间调整。
- 标题和主要操作保持可达；长文字和列表在指定内容区滚动，触控按钮至少44×44 CSS像素。
- 战斗菜单使用标题栏预留空间，伙伴详情按钮位于选中伙伴信息行，不挤占技能列表。
- 商店四件商品两列两行，长描述单独滚动；招募保持两位候选，不添加技能描述、下一形态或融合信息。
- 普通融合确认仍只展示融合后的伙伴；熟练度营火融合保留原有主副宠与技能继承流程。

## 自动检查与实际渲染

新增8项全界面布局约束检查，连同原有4项开局检查共12项。这些只检查 CSS 约束与夹具覆盖，不冒充视觉验收。

独立 Electron 验收使用真实 Chromium 排版、隐藏窗口，不启动 agent-browser。夹具及私有页面导出只在验收服务器启用，不进入生产入口、Windows 包或 APK。

```powershell
# 全部页面／压力状态，六种横屏及一种竖屏
.\node_modules\.bin\electron.cmd tools/mobile-layout/check.cjs

# 指定页面的小屏快速复查
.\node_modules\.bin\electron.cmd tools/mobile-layout/check.cjs --quick --scenes=shop,battle-selected,roster-long

# 关闭手机模式，复查桌面布局
.\node_modules\.bin\electron.cmd tools/mobile-layout/check.cjs --desktop --scenes=title,map,formation,battle,shop,roster,arena3,codex

# 小屏截图索引
.\node_modules\.bin\electron.cmd tools/mobile-layout/gallery.cjs
```

手机矩阵：640×320、640×360、740×360、844×390、915×412、1024×600、390×844，均为 CSS 像素。测试过程中实际调整窗口尺寸；竖屏关闭旋转提示后检查兜底内容。

使用 Electron 的 Chromium 设备模拟明确指定 CSS 视口，避免 Windows DPI 与最小窗口宽度把390px撑成392px。检查等待实际使用的字体与图片加载完成，不以窗口外框尺寸代替页面视口。

产物在被 Git 忽略的 `dump/mobile-layout/`：

- `index.html`：页面、视口、截图链接及自动几何检查结果。
- `report.json`：越界、父容器裁切、横向溢出、遮挡、小触点和滚动到底结果。
- `run.json`：本轮 CSS 的 SHA-256、用例数及失败列表。
- `desktop.html`／`desktop-report.json`：桌面复查结果。
- 页面 PNG 与 `gallery-*.png`：视觉核查证据。

发现错误时脚本返回非零退出码。正文允许滚动，不以所有内容同时挤入首屏为通过标准。快速检查会重写手机报告，完整交付以最后一次全矩阵检查为准。

修改严格限定于单个页面时，可用 `--scenes=test-pick --merge` 专项复测七种尺寸并更新原报告，`run.json`分别记录新测与保留用例数量；共享样式变化必须重跑全矩阵，不能据局部复测声称全部页面通过。

- 按钮越界、父容器裁切、非预期横向溢出、小触点、当前操作层遮挡及滚动到底检查均通过；界面截图另作视觉复核。
- 1280×720、1920×1080下19类主要桌面页面共38个组合通过，关闭手机样式后布局保持隔离。
- `npm test`：63个文件、700项测试通过；`npm run typecheck`、`npm run build`、`npm run android:debug`通过。
- 已生成 `android/app/build/outputs/apk/debug/app-debug.apk`，核对包内 CSS 与最终网页构建一致，且未打入验收夹具。
- 手机与桌面验收记录中的 CSS SHA-256 均与当前源码一致。静态规则检查、真实 Chromium 渲染和 Android 真机验收是不同层次，不能互相替代。

### 自动提示高度修复验收

- 修复手机提示同时继承顶部位置和设置底部位置导致纵向拉伸的问题；短提示按内容收缩，长提示换行，底部预留操作区。
- 新增招募成功、获得食物及商店长提示三类状态；当前共78类页面／状态，七种手机视口全量重跑546个组合，失败数为0。报告加入提示框真实边界及高度检查，防止提示再次拉伸或超出视口。
- 复查首页、布阵、战斗、选中伙伴和存档管理在两个桌面尺寸中的10个组合，全部通过。手机渲染报告中的CSS摘要与最终源码一致。
- 本轮相关测试22项通过，类型检查与Android测试包构建通过；包内CSS与最终网页构建一致。新结果不代表重新执行了上述历史完整游戏逻辑测试，也不代表完成了Android真机验收。
- 后续手机修改保持全部界面动态适配，新增提示和弹窗也纳入相同七种视口检查；共享样式变更应运行完整矩阵。

## 仍需 Android 真机复核

Chromium 验证不等于全部 Android 设备验收。请用最终 APK 覆盖安装，复核系统栏／刘海安全区、系统字体放大、旋转、触控滚动及原生导入／分享，尤其是不同厂商 WebView 的表现。不要先卸载旧包；签名不兼容时先导出存档。

手机适配阶段未修改正式签名；后续版本发布按用户明确要求执行。
