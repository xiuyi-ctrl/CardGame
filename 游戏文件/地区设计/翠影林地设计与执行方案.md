## 二、地区与开局流程

主模式流程：

**选择地区 → 选择难度与遗物 → 选择主力与同行伙伴 → 开始远征**

首版地区：

| 地区 | 标识 | 定位 |
| --- | --- | --- |
| 混合地区 | `mixed` | 原有主模式，完整保留现有生物池、遭遇组合、首领及获取规则 |
| 翠影林地 | `emerald_forest` | 新增地区，以中毒、治疗净化、狐火与防守配合为特色 |

- 地区不承担难度分级，不增加额外数值倍率。
- 每局开始后地区固定，三幕均属于所选地区。
- 继续游戏直接读取存档地区，不重新选择地区。
- 熟练度模式不增加地区选择。
- 地区选择页可返回首页；难度页可返回地区选择。
- 返回更换地区时清空尚未确认的生物选择，保留合法的难度与遗物选择。
- 不按地区拆分已有难度、遗物及其他解锁记录；解锁继续按存档原有规则处理。

## 三、翠影林地生态

### 3.1 完整生物名单

| 一阶 | 二阶 | 传奇 |
| --- | --- | --- |
| 迅迅 | 迅牙 | 迅天 |
| 泡泡 | 泡泡将 | 泡泡龙神 |
| 铁墩 | 铁卫 | 铁壁神 |
| 刺刺 | 棘尾 | 棘刺王 |
| 咪咪 | 蟒影 | 深渊蛇王 |
| 光苔球 | 光苔兽 | 日炎灵 |
| 火狐 | 幻尾火狐 | 九尾炎尊 |

共7条进化链、21种可驯服形态。不包含烛烛、灼灼、煤煤、熔壳虫、焚风雏鹰及其进化。

棘刺王显式纳入林地传奇池；不借此修正或扩展混合地区原有传奇池。林地应使用明确配置的完整名单，不直接依赖混合地区传奇池推导。

### 3.2 开局候选

- 主力：迅迅、泡泡、火狐。
- 同行伙伴：铁墩、咪咪、刺刺。
- 保留当前“两只同种主力＋一只同行伙伴”的开局数量。
- 起始金币、食物、难度解锁及遗物规则不变。
- 火狐进入林地开局，是此前“不进入开局候选”约定的地区限定调整；混合地区开局不变。

### 3.3 投放与获取

地区限制覆盖以下入口，不仅限制普通战斗：

| 入口 | 地区规则 |
| --- | --- |
| 普通战、精英、侵蚀 | 使用本地区对应幕次、进度、规模和品阶的合法遭遇组合 |
| 斗兽场、车轮战、守卫 | 使用本地区对应关卡的合法阵容，保持原人数、轮数及品阶门槛 |
| 战后招募 | 两位候选来自本地区对应品阶池，不在奖励卡提前展示 |
| 孵化 | 从本地区原入口允许品阶的生物池生成 |
| 商店伙伴 | 当前主模式商店无伙伴商品，不新增商品；熟练度商店招募沿用原池，不接入地区 |
| 随机伙伴事件、奇遇奖励 | 产生随机伙伴时受本地区生物池约束，不改变原奖励类别和品阶规则 |
| 首领固定随从、事件指定敌人 | 按首领及事件专用配置检查，不误当随机伙伴池过滤或替换 |

统一规则：

- 遭遇组合必须所有成员都属于林地对应品阶池。
- 从现有遭遇表保留合法组合及其原相对权重，不逐只替换非法成员，不改变组合人数。
- 各幕、进度和关卡原有的规模与品阶规则不变。
- 招募等单宠获取在地区同阶池内等概率；不根据已有队伍加权，不新增定向保底。
- 招募继续保持两位候选及原有锁定、选择、满员处理规则。
- 第一幕不直接投放传奇，击败第一幕首领后开放传奇融合。
- 不修改融合需求、固定技能组、技能数值或技能学习规则。

若某类固定遭遇表过滤后为空，须在接入前补齐并列出林地合法组合，不允许运行时回退到混合地区或生成空敌人。补齐组合必须遵守原关卡的规模与品阶限制；补齐结果属于后续实现产物，本文不伪称已完成全部遭遇表核验。

## 四、三幕与首领

| 幕次 | 场景主题 | 首领安排 |
| --- | --- | --- |
| 第一幕 | 林缘营地 | 古树之主 |
| 第二幕 | 幽暗密林 | 苔藓领主 |
| 第三幕 | 古树遗迹 | 暂从现有第三幕首领池等概率选择1个 |

第三幕过渡池为熔火领主、玄铁渊龙、炼狱魔君；每局仅选其中一个，不额外增加数值。专属第三幕首领暂不设计，待后续单独确定后替换，不在本轮补充其属性、技能、随从或美术。

- 林地每幕末层只生成1个首领节点，所有前一层合法路线均能通向它。
- 古树之主、苔藓领主及第三幕过渡首领保留当前属性、技能、被动与随从。
- 首领及其固定随从属于专用遭遇，不受21种可驯服形态名单限制，仍不可作为普通随机伙伴投放。
- 混合地区继续保留每幕2～3个首领节点。
- 地图长度、节点奖励、第一幕成长节奏沿用现有规则。
- 幕间继续先进入下一幕地图，不自动进入布阵。

## 五、数据、兼容与界面约束

### 5.1 最小数据与接口改动

- 新增主模式地区标识 `mixed / emerald_forest`，在当前远征状态与存档中保存。
- 集中配置地区名称、生物池、开局候选及首领池，避免各获取入口维护不同名单。
- 地区随新局创建传递至地图、遭遇和随机伙伴生成；预览读取相同地区的确定结果。
- 混合地区保持原生成路径和随机调用顺序，不因增加地区选择而消耗额外游戏随机数。

### 5.2 存档兼容

- 旧存档缺失地区时按混合地区处理，不重生成已存地图、奖励或招募候选。
- 继续游戏及存档导入保留本局地区，不重抽生物或首领。
- 已有伙伴、资源、布阵记忆与解锁记录沿用原逻辑，不因地区功能追溯改写。
- 熟练度模式的地图、池、开局及成长流程不受本次地区功能影响。

### 5.3 界面与美术

- 地区选择页显示名称、场景、特色与生态详情入口；生态详情列出完整生物及进化链。
- 地图和幕间显示当前地区，三幕场景主题按第四节呈现。
- 沿用现有像素风，首版复用已有森林素材，不新增专属首领立绘。
- 手机保持横屏动态适配，优先同屏展示主要选择和确认操作；主要触控区域至少44×44 CSS像素。
- 生态长列表允许必要的内容区滚动，标题、返回和确认保持可达；不通过整页缩放或裁切掩盖内容。
- 不改动其他电脑页面布局，不增加竖屏游戏功能。
