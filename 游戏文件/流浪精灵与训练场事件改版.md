# 流浪精灵与训练场事件改版

日期：2026-10-27，接续[前八类事件改版](主模式八类事件改版20261027.md)第9、10项。

## 流浪精灵

事件生成时从当前幕次、当前地区的合法单体遭遇池锁定一只生物，第一／二／三幕分别使用对应一／二／三阶搭配池。挑战与喂食始终指向这一只生物，不在点击、读档或领奖时重新抽取；选项说明显示该物种名字。

| 选项 | 效果 |
| --- | --- |
| 挑战 | 与1只精灵战斗，禁止战斗内额外捕获；胜利获得该物种伙伴及20金币；失败全队损失最大生命20%，最低保留1血，不额外损失金币 |
| 喂食 | 消耗2份随机持有的捕捉食物，直接获得该物种伙伴；60%概率附带永久强化，强化内+1速度／+2最大生命各占50%，其余40%无额外强化 |
| 离开 | 绕道而行，无事发生 |

食物按当前实际库存逐份抽取，每次在仍有库存的种类之间等概率选择；每抽一份即从临时库存移除。同种持有2份可被连续选中，不能扣出负数。捕捉食物包含圣果，排除治疗圣水；总数不足2份时界面禁用，结算也拒绝，不发伙伴、不扣食物。提示列出实际消耗品名及数量、获得伙伴和强化结果。

挑战奖励为正常基础形态的满生命伙伴，不复制敌方难度加成、残血、临时Buff或战斗强化。喂食强化计入`bonusStats`和实际属性，随存档保留并按已有永久属性规则继承。

队伍未满直接加入；满员进入处理新伙伴界面，保留伙伴及喂食强化，处理后返回地图。挑战金币正常入账，计入累计金币获取；失败不提供伙伴。事件战斗沿用原有不永久删除阵亡伙伴及胜利按难度战后恢复规则。

## 训练场挑战

| 选项 | 效果 |
| --- | --- |
| 接受挑战 | 2～3只当前幕次较强对手，使用现有对应品阶的合法固定搭配；胜利全队永久+1最大生命，包括后备伙伴 |
| 离开 | 继续赶路，无事发生 |

不额外添加敌人倍率。失败随机伙伴诅咒及离开规则沿用原设计，风险继续写在选项说明中。

修复原生命奖励先添加、再被战斗单位同步覆盖的问题：先同步战斗结果和战后恢复，再增加全队最大生命、当前生命及`bonusStats.hp`。因此已参战与后备均实际获得+1，存读档、属性重算及既有融合继承不会丢失这次永久强化。

## 兼容与验证

旧存档已生成的事件仍保留旧结果；新生成事件使用本轮规则。已有训练场的生命奖励结算修正同样生效。熟练度独立事件表不改。

专项测试覆盖当前幕／地区合法池、同一物种、胜负奖励、2份食物筛选与实际消耗、60%强化分布、两种强化、满员处理、后备伙伴奖励及存读档。手机保持横屏动态适配，并检查长描述下主要按钮是否可达。

验证结果：120个测试文件、1294项测试通过；类型检查及生产构建通过。两个事件页覆盖六种横屏手机尺寸及三种桌面尺寸，共18组实际渲染检查通过，已查看最小手机尺寸和桌面截图。真机触控及实际难度尚待游玩确认。本轮未生成新APK、未提交、推送或发布。
