# 主模式改版设计整理

记录日期：2026-10-19，最后更新：2026-10-20。

## 一、问题背景

主模式当前存在三类相互关联的问题：

**重复可玩性不足。** 战后奖励主要改变资源数量（食物、回复、随机基础宠），较少改变打法方向；同一进化链在不同局中形成不同用途的机会有限，玩家体验容易退化为“何时抽到某只宠物、这局还缺多少融合材料”。

**难度曲线断层。** 自动模拟显示常规战胜率约 97%～98%，而首领战在普通/困难/地狱分别为 75.8%/58.6%/36.0%，斗兽场为 41.0%/31.0%/26.7%。普通难度 75 次整局失败中 47 次最后一场是失败的首领战。设计风险在于：沿途战斗没有逐步检验或训练关键战所需能力，玩家到首领才发现准备不足。同时多个惩罚维度（敌方生命、速度、商店价格、战后回复、精英概率、幕间生命下限）叠加，实际难度可能临界跳变。

**融合收益与行动成本缺乏统一尺度。** 基础宠物生命约 7～14，常见攻击 5～8 点，先后手和一次集火就可能决定永久阵亡；固定加伤/减伤按段生效，对单段、多段、群攻价值差异大；融合消耗同物种单位、降低队伍人数、减少行动次数，但玩家容易预期“进化一定更强”。

分析数据来自固定策略自动玩家，存在布阵绕过人数上限、开局同伴池不一致、技能选择过于简单、道具与捕获策略不完整等偏差，因此仅用于发现异常形状，不直接作为调参目标。

## 二、设计目标

- 奖励决定“这局怎么玩”，融合决定“哪些伙伴承担这套打法”。
- 同一种开局可以发展出不同阵容与配合。
- 玩家能主动争取成长材料，而非完全等待随机重复宠。
- 融合的收益与减少单位的成本清晰、可判断。
- 保留现有六条主要进化链，优先利用已有灼烧、中毒、护盾、反伤和速度机制。
- 保留现有六条主要进化链的固定技能组，不加入旧技能继承选择。

## 三、行动规则

### 已确认并实施的修改





| 项目               | 结论                                                   | 状态              |
| :----------------- | :----------------------------------------------------- | :---------------- |
| 公共行动点机制     | 删除，不再维护或展示队伍共享行动点预算                 | 2026-10-20 已实施 |
| 基础行动           | 每只存活、未受眩晕等限制的生物每回合一次基础行动       | 2026-10-20 已实施 |
| 额外行动被动       | 保留暗影追猎等明确提供的额外行动，补齐我方追加行动结算 | 已保留            |
| 进化保留旧技能     | 不加入“用一个旧技能替换新技能”的功能                   | 用户明确排除      |
| 主模式常规进化技能 | 继续采用新形态固定技能组                               | 沿用现有设计      |

### 交互默认约定

- 玩家先给各生物选择技能，点击“结束回合”后敌我按速度统一执行。
- 结算前可修改或取消尚未执行的技能指令，不涉及行动点扣除或返还。
- 换位占用发起者本回合基础行动；被交换位置的生物不因此失去行动。
- 捕获和使用道具不占用生物基础行动，仍消耗相应物品。
- 休息表示该生物放弃本回合行动；眩晕、死亡、刚召唤入场等限制按规则处理。
- 删除公共行动点不等于放宽出战人数上限，也不等于允许同一生物重复执行基础行动。
- 额外行动属明确被动效果，不计入基础行动次数限制，保留防止无限连动的约束。

### 实施记录

2026-10-20 行动规则已接入：删除共享行动点字段与界面显示，按单位独立记录基础行动；换位仅占发起者行动，捕获与药水不占行动、不自动结算。旧存档加载时移除废弃行动点字段。暗影追猎保留追加行动，次数与冷却正常消耗。此项不修改宠物、敌人及融合数值。

**注意：** 删除行动点不消除融合的行动次数成本——两只生物各行动一次，融合成一只后基础行动仍只有一次，融合前后有效战力仍需重新核算。

## 四、奖励构筑：普通补给与远征祝福

### 普通战后补给

食物、恢复和招募继续承担短期补给与扩充队伍作用，避免每场战斗都加入复杂永久效果选择。

### 远征祝福

获得时机已确认，其余第一版参数仍为建议，具体数值待验证：





| 项目         | 建议初始方案                                                 |
| :----------- | :----------------------------------------------------------- |
| 获得时机     | 每幕开始时一次、战胜该幕首领后一次                           |
| 全局选择次数 | 三幕完整通关共 6 次，最终首领后的 1 次不计入通关前有效构筑机会 |
| 每次候选     | 三选一                                                       |
| 携带上限     | 最多 4 个                                                    |
| 重复获得     | 同一祝福最多强化一次                                         |
| 首批规模     | 约 12 个                                                     |
| 持续范围     | 本次远征，随新一局重置                                       |
| 作用对象     | 队伍或指定机制，不依附于某只材料宠的存活                     |

祝福在宠物融合或阵亡后仍保留。它与开局遗物区分：遗物提供起步资源，祝福承担局内持续构筑。上一幕首领战后的选择与下一幕开始时的选择分别保留，不合并；最终首领后的选择无后续主线战斗收益，评估构筑强度时需单独统计。

### 祝福方向





| 方向     | 效果概念                                       | 希望产生的决策               |
| :------- | :--------------------------------------------- | :--------------------------- |
| 灼烧     | 击败燃烧目标时，将部分灼烧转移给另一名敌人     | 集中击杀与灼烧铺场如何配合   |
| 中毒     | 每回合首次攻击中毒目标时，攻击者恢复少量生命   | 施毒者与承接攻击者如何分工   |
| 护盾     | 每回合首次为队友加盾时，同时治疗另一名受伤伙伴 | 支援单位何时使用护盾         |
| 速度     | 每回合首次以低于目标的速度攻击时，附加少量减速 | 慢速队也有可发展的应对路线   |
| 通用生存 | 提供有限的容错与恢复收益                       | 在专门配合与稳定生存之间选择 |

以上为效果概念，非最终技能文本或数值。首批应利用现有状态与战斗事件，不为每个祝福另建独立战斗规则。

### 限制收益放大

- 明确“队伍每回合一次”“每个目标一次”或“击杀一次”等触发范围。
- 多段、群攻、反伤、持续伤害和召唤物是否触发，必须逐项定义。
- 避免一次附加状态又触发自身附加状态，形成循环。
- 不能只按面板伤害定价，需考虑段数、目标数、次数和持续时间。
- 携带上限达到后，应允许替换或放弃新祝福，不自动移除已有构筑。
- 候选既提供已有方向延伸，也保留转向和通用选项，避免第一次选择锁死全局。

## 五、招募候选改版

### 范围

仅调整主模式战后招募奖励（含普通战利品、斗兽场与车轮战中的招募选项）。不改变捕获、孵化、商店招募、事件赠宠和熟练度模式。

### 交互流程

1. 战后奖励卡只显示通用招募图标与“从两位候选伙伴中选择一位”，不提前展示候选物种、形态、头像或属性。
2. 点击招募后才揭晓两位候选，可查看立绘、名称、生命、速度、被动和固定技能，不展示下一形态或融合情况。
3. 点击招募即锁定本次奖励，不能返回奖励列表或改选其他奖励；界面只保留两位候选各自的确认招募按钮。
4. 确认一位后领取完成，清空其余奖励，进入战后休整。不可同时领取两个候选或另一份奖励。
5. 满员仍保留招募奖励，确认后进入现有新伙伴处理流程，支持替换、融合或放生；不自动释放伙伴，放生不返还奖励。

### 候选生成

候选在奖励生成时通过现有种子随机一次确定，并随奖励保存。没有免费或付费刷新。读档不重抽，已锁定的招募选择继续保持锁定。





| 幕次   | 一阶概率 | 二阶概率 |
| :----- | :------- | :------- |
| 第一幕 | 100%     | 0%       |
| 第二幕 | 70%      | 30%      |
| 第三幕 | 40%      | 60%      |

每位候选独立抽取阶级，再从该阶级六条主要进化链中等概率选取；第二位排除第一位已选的完全相同物种形态。同一进化链的不同形态可以同时出现。

- 不提高已有进化链伙伴权重，不按队伍、祝福或材料缺口调整概率。
- 不加入连续落空的定向保底或补偿。
- 不提供三阶、首领、小怪或造物。
- 加入时采用该形态正常初始属性和固定技能，不额外赠送强化、诅咒或技能。

### 展示与兼容

候选界面采用奶油色终端外框、深墨像素描边和橙金角饰，两张卡始终左右排列。卡片顶部使用横向资料区：左侧为缩小立绘（常规 88×88，小窗口 64×64），右侧显示名称、生命与速度；下方依次为被动、技能及橙色确认招募按钮。技能仅展示带背景的技能名称和数值，不展开效果描述；被动说明保留。悬停或键盘聚焦突出对应卡框；不显示底座、下一形态或融合信息。小窗口压缩边框与留白，在最小 960×640 内无需滚动即可展示两位候选及确认按钮。

旧存档中只有一个 monsterId 的招募奖励沿用原有单宠领取流程，不读档重抽；新生成的主模式招募奖励使用双候选。其他奖励种类不变。

### 验证要求

- 奖励卡不泄露候选；点击后才显示双候选。
- 候选不完全重复、分幕池正确、与现有队伍组成无关。
- 进入招募后无返回或取消入口，逻辑层禁止改领其他奖励；存档恢复保持候选与锁定状态。
- 确认只获得一位、消耗一份奖励；界面不包含下一形态和融合信息。
- 拒绝未揭晓时确认、伪造候选与重复领取。
- 满员进入既有处理流程；其他模式和旧单宠奖励保持兼容。
- 自动模拟玩家能处理新步骤，避免流程停滞。

### 实施状态

已接入奖励生成、不可返回的二选一领取、像素双卡详情、满员处理和自动模拟流程；新增字段可随现有存档保存。

## 六、融合成长改版

### 范围

仅调整主模式六条主要进化链的常规融合；不改熟练度营火融合、造物、免费进化和超进化的独立流程，不新增碎片、兑换或万能材料。

### 材料数量





| 阶段       | 原需求（含主宠） | 修改后     |
| :--------- | :--------------- | :--------- |
| 一阶升二阶 | 两只同物种       | 两只同物种 |
| 二阶升三阶 | 三只同物种       | 两只同物种 |

主宠与材料必须具有相同 speciesId，即相同物种、相同形态，不能用同一进化链的其他形态替代。完全从一阶合成三阶，材料总量由六只降为四只；捕获或招募二阶仍可缩短成长路径。融合不自动执行。

### 幕次限制

主模式第一幕仅开放一阶升二阶，击败第一幕首领后立即开放传奇进化，首领战后的奖励与休整阶段即生效。常规融合、待处理伙伴融合、免费进化与超进化共用此限制；材料仍为两只同物种同形态。第二、三幕旧存档默认开放，第一幕已有传奇不删除，新远征重新锁定。熟练度模式不受影响。本轮不调整地图长度或首领数值。

### 结果与继承

- 采用下一形态基础属性、固定技能和固定被动，不加入保留旧技能、复制材料技能或被动的选择。
- 保留主宠永久生命与速度强化，叠加到新形态；保留主宠诅咒，并重新计算其属性影响。
- 材料宠的强化、诅咒、技能和被动不转移。
- 融合后生命回满；临时状态、护盾等不转为永久收益。
- 主宠 uid、前后排与列位置保留；材料移除，其出战位置空出，不自动补位。
- 现有特殊自创技能例外保持原规则，不扩展到普通融合；熟练度营火技能继承不受影响。

### 确认信息与材料选择

队伍管理、战后休整、背包与新伙伴处理中的常规融合均需确认。弹窗仅展示融合后的生物信息，不展示融合前主宠、材料详情卡、人数变化或出战空位提示。

结果卡显示新形态立绘、名称、生命、速度、固定技能与被动，以及最终永久强化和诅咒。候选材料多于一只时保留简短下拉选择，选项提供必要辨识信息，不展开独立材料详情；仅一只时默认选中且不显示选择控件。缺失或失效时不可确认。

美术采用奶油色像素终端外框：标题使用现有融合 PNG 徽记，左侧立绘与右侧名称、生命/速度图标横排；被动和技能分别使用橙色区签，技能只显示名称与数值。底部以灰绿标签展示永久强化，有诅咒时使用红色铭牌，操作区为橙色“确定融合”和灰白“取消”。所有内容由实际融合结果绘制。

新伙伴处理允许选择待处理的同形态伙伴或队伍内同形态伙伴作为材料。消耗待处理伙伴时队伍人数不变；消耗队伍内伙伴时队伍人数减少一只，待处理伙伴继续保留。

这些信息仅用于融合确认，不回加到招募候选界面。

### 各阶成长职责

- 二阶：提供可靠的基础战力与更明确的角色，让早期融合具有可感知收益。
- 三阶：提供机制突破，成为本局构筑的核心或重要支点。
- 不使用统一倍率机械放大所有物种；输出、治疗、护盾、反伤与速度型分别评估。
- 不要求融合在任何局面都无条件最优，但要让收益与代价可理解，避免“进化后明显更弱且没有新用途”。

### 实施状态

已完成每阶两只同形态、指定材料与融合结果确认卡。确认覆盖普通队伍、战后休整、背包和新伙伴处理；所有融合入口均保留主宠位置并准确移除材料。初版完整单元测试共 480 项通过；后续确认展示简化不改变融合和继承规则。本轮没有调整宠物或敌方数值，没有实施行动点或祝福改版，也未改熟练度营火融合与技能继承。

## 七、融合专项评估

评估日期 2026-10-20，运行时数据版本 `8881a49`，未修改战斗引擎、宠物、技能、被动、敌人或平衡基线。主矩阵 23,040 场，毒系起手敏感性补充 1,440 场，合计 24,480 场；种子 2000–2019。

### 结论

降低材料数量已解决一部分“合不出来”的问题，但没有自动解决“合完少一个单位是否划算”。无替补时优先复核 **泡泡→泡泡将、咪咪→蟒影、刺刺→棘尾**。并非所有融合都弱：铁卫→铁壁神在能使用护盾与多段技能的策略下明显有收益；迅牙→迅天、灼刃→灼天在前瞻策略下大体能抵消减少一个单位的成本。不能根据原自动玩家结果统一给三阶加数值。有替补通常显著改善融合表现，但这不意味着替补是免费收益。

### 实验设计

主矩阵覆盖六条进化链×两个进化阶段、满血与受伤两组、六种固定压力场景（快攻、防守反伤、毒火状态、回复消耗、进阶精英、首领小怪）、原贪心与一回合前瞻两种决策策略、四种方案（不融合、融合无替补、融合后补输出、融合后补治疗）。对照阵容是“两只材料宠+一只固定队友”；无替补组是“融合结果+原固定队友”；补位组加入一只原本待命的同阶段替补。每表格单元为六场景×20种子=120场。

**解释边界：** 这些胜率是固定压力样本通过率，不是主模式通关率或真人胜率，未按地图遭遇概率加权；前瞻策略仅逐单位改进一次，非全局最优；未测试五人满编、所有队友组合、困难/地狱、强化诅咒组合、捕获、道具、祝福和跨战资源循环；补位组假定已有替补，未计算获取成本；阵亡数受单位数量影响，不能仅凭阵亡只数判断强弱。

### 优先复核的三个阶段

**泡泡→泡泡将：续航资源与行动容量同时收缩。** 两只泡泡合计 28 生命，泡泡将 22，保留 78.6%；两只水愈各回 2 合计潜在每回合 4，潮汐再生回 3；两只泡泡合计 10 次水浴每次 5 治疗，泡泡将愈光 2 次每次 8。前三结算队伍有效治疗由 14.46 降到 11.68，实际 HP 输出由 12.82 降到 10.15。无替补时快攻 100%→60%，进阶精英 100%→50%；防守反伤和回复场景没有下降。判断：优先验证“二阶支援升级是否足以补偿失去一位治疗者”，后续候选方向是治疗可用次数、支援行动效率或持续恢复价值，不同时全面提高生命和伤害。

**咪咪→蟒影：毒源与启动节奏改变。** 总生命 20→17，速度 3→4，两次基础行动变一次。原咪咪毒牙使攻击自动附毒；蟒影变为对已中毒目标增伤，需要主动毒刺或其他毒源配合。前三结算实际 HP 输出 26.85→19.54，下降约 27.2%。进阶精英 100%→10%，首领 15%→0%，普通四类场景仍均通过。补充起手测试：强制首回合毒刺后无替补满血 68.3%→59.2%，受伤 60.8%→40.8%，没有修复损失；仍不是所有最优毒序列的穷举。判断：优先复核进化时失去自动施毒的启动代价，而不是只给影袭加伤害；后续比较有外部毒源与无毒源两种阵容，再决定是否调整毒刺效率、毒源或增伤兑现方式，不增加旧技能继承。

**刺刺→棘尾：生命与两个控制位的损失。** 两只刺刺 22 生命，棘尾 16，保留 72.7%，是首阶段最低生命保留率。被动单次反伤从 2 提高到 3，但失去一个前排单位与一个控制指令位。前三结算 HP 输出 25.11→25.06 基本不变；通过率仍下降 10.8 个百分点。进阶精英 75%→10%，其余普通四类场景仍均通过。判断：优先复核前排有效生命、削弱/嘲讽覆盖与保护队友的收益；棘尾可保持“控制反伤”定位，不必补成通用高伤攻击手。

### 不能按旧自动玩家误判的阶段

**铁卫→铁壁神。** 满血无替补原贪心 55.8%→41.7%，前瞻 66.7%→90.0%。原贪心几乎只用钢刺；前瞻会使用铁壁双击、铁壁领域等技能。前三结算获盾由两铁卫的 8.72 提高到铁壁神队伍 27.68。结论：已有可兑现机制提升，不建议当前直接加强；先改善模拟器对护盾、多段和群体收益的识别，再用五人阵容和其他敌人复测。获盾量不是实际吸收量。

**迅牙→迅天、灼刃→灼天。** 满血无替补原贪心分别下降 13.3 与 14.2 个百分点，前瞻分别上升 2.5 与 0.8 个百分点。先手、条件连击与速度/灼烧机制影响选择，单段伤害排序不能充分发挥。迅天入场速度由迅牙 7 变为 6，但有先手技能与攻击后速度成长，不能只据初始速度下降判断三阶更弱。目前没有充分依据统一提高基础属性。

**蟒影→深渊蛇王。** 默认前瞻满血无替补 69.2%，低于不融合 73.3%；强制毒雾起手可提高到 75.8%，超过对照约 2.5 个百分点。最终形态对启动方式更敏感。应先复核施毒与爆发序列，不宜直接归类为“必须数值加强”。

### 建议处理顺序

1. 优先做针对性候选验证：泡泡将的续航预算、蟒影的毒源启动、棘尾的承伤/控制覆盖。一次只改变一个维度，不直接同时提高面板和技能。
2. 先校正策略再判断三阶：铁壁神、迅天、灼天，以及深渊蛇王的毒序列。保留旧策略作对照。
3. 补充阵容与决策边界：五人满编；外部毒源、治疗与护盾协作；不融合但换上替补的最优布阵；不同站位与速度阈值。
4. 再做难度与整局验证：困难/地狱、材料获取节奏和战后续航。删除行动点或加入祝福后应重新评估，不能沿用本报告数值结论。

本报告没有实施任何宠物或敌方数值调整；上述方向仍是下一轮待验证的建议。

- 同一开局在不同种子下，是否出现不同的祝福组合、终局阵容和战术选择。

- 治疗、食物、金币和战斗道具是否各自存在实际选择价值。
