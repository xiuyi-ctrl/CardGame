# 探险家罗盘

日期：2026-10-27。保留原有七件遗物，新增探险家罗盘后合计八件，开局仍最多携带一件。

| 项目 | 设计 |
| --- | --- |
| 标识 | explorer_compass |
| 图标 | 刻有未知符文的青铜罗盘，深青表盘、奶白／红色指针，透明像素图标 |
| 效果 | 无需经过节点，即可随时查看本幕所有瞭望塔后三层的情报 |
| 解锁 | 单局实际访问五个不同的瞭望塔节点 |

## 已确认的效果含义

已访问塔原本就能重新打开，本遗物进一步开放本幕**未访问**的瞭望塔。玩家已确认采用这个含义。它不直接揭示整张地图，也不把瞭望范围扩大到后三层以外。

- 携带后，本幕所有瞭望塔显示可查看标记，包含尚未到达和未经过分支上的塔；点击先打开该塔的情报。
- 以被查看的塔为起点，仍只提供它后三层，接近首领层时按剩余层数截断。情报内容、随机预生成结果与实际节点使用同一数据，不重抽奖励、敌人或事件。
- 远程查看不移动当前位置，不选择路线，不把节点记为已访问，不增加评分、金币、访问次数，也不推进携带蛋孵化。
- 当前可达的塔，在情报页额外提供“前往此瞭望塔”。确认后才按原地图规则走入，计入实际访问；不可达塔不提供这个按钮。
- “关闭瞭望”只返回原地图位置。点击查看或反复关闭不能刷计数。
- 侦察／跳关道具选择模式仍优先执行对应道具操作。
- 跨幕后对新地图继续生效；旧幕地图不新增回看入口。效果属于本局携带遗物，不是账号永久全图透视。熟练度不启用。
- 未携带时保留原规则：只能打开当前或已实际访问过的塔。

## 解锁统计与存档

- 新增可选统计`runStats.watchtowerVisits`，三幕累计；同一塔只在实际进入时计一次。
- 不要求携带本遗物才能累计，也不要求通关；第五个不同塔实际走入后立即解锁并提示。
- 重复预览、重新打开、读档、取消和关闭均不增加。跨幕清空当幕访问列表，但保留本局累计；新一局清零计数，已解锁遗物按存档槽保留。
- 旧档缺失计数时，仅从该档仍保留的当幕不同已访问塔恢复；不能证明的更早幕次访问不补造。
- 测试局不解锁，熟练度不参与主模式解锁条件。

## 界面与资源

- 八件遗物与“不携带”共九个选项，桌面和手机均以三列三行显示；手机触控区域至少44px，主要选项一屏显示。
- 罗盘预览页的“前往”和“关闭”并排，避免挤占手机情报区；不可达时只显示关闭。
- 遗物选择、成就及图标预加载沿用统一遗物清单。
- 透明原图、提示词和64×64最近邻导出位于`design/relics/explorer-compass-v1/`。
- 运行图标：`public/starter-growth-icons/explorer_compass.png`；集中副本：`美术素材/starter-growth-icons/explorer_compass.png`。使用内置imagegen生成，保留原图，未修改旅者护符。
