# 删除熟练度、只保留成长点 —— 优化方案

## 一、核心思路

**熟练度本质是"经验条"，成长点是"可分配的资源"。** 删掉熟练度后，成长点直接作为唯一的成长货币，战斗/事件/商店直接产出成长点，玩家拿到就能花。

这样做的收益：

- **少一层转换**：不需要"熟练度 → 等级 → 成长点"的三段式，直接"产出 → 消费"。
- **节奏更可控**：成长点产出速度 = 玩家变强速度，调一个数就行。
- **叙事更干净**：不再有"熟练度"和"成长点"两个相似概念，降低理解成本。
- **Roguelike 感更强**：成长点像金币一样是"资源"，玩家会精打细算，而不是被动等升级。

代价是：失去"等级"这个直观的成长反馈。可以用**生物身上的成长点累计数**作为替代显示（如 `🐭迅迅 +7`）。

## 三、需要改动的章节（逐条）

- 标题：`熟练度远征模式` → **成长远征模式**（或保留"熟练度"作为模式名，但内部不出现"熟练度"数值）
- 开头核心特色：`熟练度是唯一的成长主轴` → **成长点是唯一的成长资源**

> 建议：模式名可以保留"熟练度远征"作为品牌，但文档内部统一用"成长点"。

### 3.2 第二章 与主模式的核心差异





| 维度       | 主模式              | 成长远征模式                       |
| :--------- | :------------------ | :--------------------------------- |
| 成长主轴   | 融合进化 + 属性强化 | **成长点分配**                     |

### 3.3 第五章 整章重写（核心）

原第五章「熟练度成长系统」→ **「成长点系统」**

#### 5.1 成长点获取





| 场景         | 成长点 | 说明                 |
| :----------- | :----- | :------------------- |
| 参与战斗     | +1     | 上场即得，无论胜败   |
| 击杀普通敌人 | +1     | 每击杀 1 个          |
| 击杀精英敌人 | +2     | 额外 +1              |
| 击杀首领     | +3     | 额外 +2              |
| 存活奖励     | +1     | 战斗结束时该生物存活 |
| 事件奖励     | +1~3   | 部分事件给予         |
| 商店购买     | +1~2   | 部分商品给予         |

> 与原熟练度数值相比，这里做了**减半**处理：原来一场战斗约 +6~8 熟练度，现在约 +3~4 成长点。因为成长点直接可花，产出必须更谨慎。

#### 5.2 成长点上限





| 项目                 | 上限      | 说明               |
| :------------------- | :-------- | :----------------- |
| 单只生物累计成长点   | **10 点** | 达到上限后不再获得 |
| 单只生物可持有未分配 | 无上限    | 鼓励攒点解锁技能槽 |

> **关键设计**：10 点上限意味着每只生物最多获得 10 次成长机会。玩家必须做取舍——是点属性，还是解锁技能槽。

#### 5.3 成长选项





| 选项            | 消耗 | 效果               | 上限   |
| :-------------- | :--- | :----------------- | :----- |
| 提升生命        | 1 点 | 生命 +2            | +20    |
| 提升速度        | 1 点 | 速度 +1            | +10    |
| 解锁第 4 技能槽 | 2 点 | 从技能库三选一装备 | 1 次   |
| 解锁第 5 技能槽 | 3 点 | 从技能库三选一装备 | 1 次   |
| 替换技能        | 1 点 | 替换 1 个已有技能  | 无限制 |

**技能槽解锁规则**：解锁后立即从技能库随机展示 3 个技能，选 1 装备。不满意可花 1 成长点重随。

## 四、数值平衡的连锁影响

删掉熟练度后，以下数值需要重新校准：





| 项目           | 原值          | 新值         | 理由                                   |
| :------------- | :------------ | :----------- | :------------------------------------- |
| 单只成长点上限 | 10（等级）    | 10（累计）   | 数值不变，但含义从"等级"变为"累计资源" |
| 每场战斗产出   | +6~8 熟练度   | +3~4 成长点  | 直接可花，产出必须减半                 |
| 满级所需场次   | 8~10 场       | 8~10 场      | 保持不变                               |
| 事件奖励       | +2~5 熟练度   | +1~3 成长点  | 同步减半                               |
| 商店成长之书   | +2/+5 熟练度  | +1/+2 成长点 | 同步减半                               |
| 奇遇奖励       | +5 熟练度     | +2 成长点    | 同步减半                               |
| Boss 被动      | 10 熟练度触发 | 5 成长点触发 | 同步减半                               |

> **核心原则**：所有涉及熟练度的数值，**除以 2 后向上取整**，保持整体节奏不变。

## 五、删除熟练度后的"损失"与"补偿"





| 损失                        | 补偿方案                                                     |
| :-------------------------- | :----------------------------------------------------------- |
| 失去"等级"的直观反馈        | 用 `+7` 这样的累计成长点显示，或用进度条 `████░░░░░░ 7/10`   |
| 失去"满级"的仪式感          | 单只达到 10 点时弹出「**成长圆满**」提示，给予 1 次免费技能替换 |
| 失去"熟练度"的叙事包装      | 模式名可保留"熟练度远征"，但内部统一叫成长点；或改名为"**成长远征**" |
| 事件/商店中"熟练度"标签失效 | 改为「**成长**」标签，视觉上更简洁                           |

## 六、改文档的推荐顺序

1. **先改术语总表**（第二章）——确定所有数值基准。
2. **重写第五章**——这是核心，其他章节都引用它。
3. **同步改第七、八、九章**——事件/商店/奇遇的数值。
4. **改第十、十二、十三章**——战斗、结算、技术方案。
5. **最后改第十四、十五章**——平衡性与意图总结。
6. **补一节「示例 run」**——用具体流程验证新数值是否合理。
