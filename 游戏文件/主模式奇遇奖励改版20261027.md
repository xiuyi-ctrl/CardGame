# 主模式奇遇奖励改版

日期：2026-10-27。

第一幕不生成奇遇关；第二、三幕沿用每幕最多一个奇遇关、前五层不出现的地图规则。进入后从以下7项中不重复随机抽3项，玩家选择1项；造物保留，超进化与跳关道具从新奇遇池删除。

| 奖励 | 效果 |
| --- | --- |
| 圣果宝藏 | 获得2个必定驯服残血、可驯服敌人的圣果 |
| 龙之宝藏 | 获得120金币，计入累计金币获取 |
| 属性重塑 | 指定1只伙伴，永久+6最大生命或+3速度，仅选一项 |
| 完美进化 | 指定一只尚可进化的伙伴，直接进化到所选进化分支的最终形态，不增加新诅咒、不消耗材料 |
| 神秘蛋 | 获得随机蛋，再经过3次关卡后必定孵化特殊生物 |
| 净化药水 | 获得2瓶清除负面诅咒的药水 |
| 造物·自创生物 | 沿用三个属性模板、自创技能及队伍未满才可领取的规则 |

## 完美进化

按物种已有进化链寻找合法最终形态，不能跨物种选择。火狐可在九尾炎尊／传火狐尊之间自由选择；已在幻尾火狐或传火狐分支的伙伴继续到对应最终形态。最终形态、蛋生生物和造物不可选择。

保留主宠UID、站位、永久属性加成、已有诅咒和自创技能；技能及被动采用最终形态的既有规则，生命回满。原诅咒仍存在，但不会像旧超进化奖励那样新增随机诅咒。进化过程中不消耗另一只伙伴。

界面展示真正的最终形态预览；有多个最终分支时先选择分支再确认。第一幕地图没有奇遇，正常流程从第二幕起获得该奖励；不借此放宽第一幕的常规传奇融合限制。

## 属性重塑

指定伙伴后再选择生命或速度；两步选择和6／3参数随存档保存。实际属性、永久`bonusStats`、预览与按钮数值一致，保留已经生效的被动属性，不引入上限或随机倍率。

仅修改主模式新奇遇的属性重塑。熟练度模式属性之赐仍为生命+5或速度+2；旧存档已经生成的旧属性强化待选保留5／2。

## 奇遇神秘蛋

使用现有问号随机蛋图标和背包孵化进度。特殊结果从时砂兽、百变兽、镜影兽、晶核兽中等概率锁定，不包含普通生物。普通随机地图生成时即保存物种；定向测试入口按固定节点种子确定，领取和读档不重新抽取。

领取本关不计数，之后完成3次关卡即可孵化，允许重复同一关卡；打开背包、查看历史情报和读档不推进。幕间、满员处理、旧特殊蛋兼容沿用既有孵化流程。

这项奖励100%特殊，与流浪事件“神秘蛋”的70%普通／30%特殊规则分别处理。背包不提前揭示具体物种。

## 兼容范围

不重抽旧存档已经生成的奇遇候选及已领取待选奖励；旧进化之光、超进化和跳关奖励仍按保存时的规则完成。新生成奇遇才使用7项新池。

删除跳关仅指奇遇奖励池，不删除旧背包已有跳关道具、其他来源及使用功能。熟练度独立奇遇池不变。存档格式版本不变，新字段可选，缺省沿用原规则。

## 验证

覆盖两地区三难度第一幕无奇遇、第二三幕仍有奇遇；奖励池、120金币、两份物品、属性6／3及旧5／2兼容；基础形态及分支直达最终、固定技能与永久强化继承、非法目标与不可进化单位；特殊蛋3次计数、存读档、满员和手机动态适配。

验证结果：122个测试文件、1309项测试通过；类型检查与生产构建通过。600组第一幕地图均无奇遇。新奇遇两组候选、完美进化、最终分支及属性重塑两步页面，在六种横屏手机尺寸和三种桌面尺寸下共54组实际渲染检查通过，已查看最小手机尺寸截图。真机触控及实际游玩仍待确认。本轮未生成APK、提交、推送或发布。
