# 🎮 驯牌远征 · 成长远征模式（Roguelike 独立模式）

一个独立于主模式的 Roguelike 新玩法。玩家从少量初始生物出发，通过战斗、专属事件、商店、奇遇逐步强化核心生物、获取新生物，最终挑战模式专属首领。核心特色：成长点是唯一的成长资源——不依赖融合、不依赖驯服，纯粹通过战斗积累让生物变强。

## 术语与数值总表

| 术语 | 数值 | 说明 |
| :--- | :--- | :--- |
| 总层数 | 50 层 | 线性爬塔 + 3 个 Boss（层15/30/50） |
| 队伍上限 | 6 只 | 比主模式少，强调核心培养 |
| 出战上限 | 3 只 | 精英化，每只都有出场价值 |

| 属性提升上限 | 生命 +20 / 速度 +10 | 含事件/商店加成 |
| 技能槽上限 | 5 个（默认 3 + 最多解锁 2） | 解锁后从技能库三选一 |

## 一、模式定位

| 维度 | 设定 |
| :--- | :--- |
| 模式类型 | 独立模式（主菜单进入） |
| 解锁条件 | 通关主模式第 1 幕 |
| 核心玩法 | 单局 Roguelike，成长点分配，逐层推进 |
| 单局时长 | 40~60 分钟 |
| 地图结构 | 线性爬塔（每层 1 个节点，无分支） |
| 层数 | 50 层 + 3 个 Boss（层15/30/50） |
| 存档 | 单局内可保存退出，死亡即结束（Roguelike 标准） |

## 二、与主模式的核心差异

| 维度 | 主模式 | 成长远征模式 |
| :--- | :--- | :--- |
| 成长主轴 | 融合进化 + 属性强化 | **成长点分配** |
| 初始生物 | 御三家选 1 + 随机 1 只 | 从 6 只品阶 1 生物中选 2 只 |
| 融合 | 核心养成手段 | 无进化链，融合不可用 |
| 驯服 | 核心获取手段 | 战斗中不可驯服，事件/商店可招募 |
| 地图 | 3 幕爬塔，多分支 | 单幕长塔，无分支 |
| 事件 | 通用事件池 | 专属事件池（围绕成长点设计） |
| 商店 | 通用商品 | 专属商品（围绕成长点设计） |
| 奇遇关 | 通用奖励 | 专属奖励（围绕成长点设计） |
| 死亡惩罚 | 全队阵亡即失败 | 单只阵亡即永久删除，全队阵亡即结束 |

## 五、成长点系统（核心）

成长点是本模式唯一的成长资源。不依赖熟练度等级，战斗/事件/商店直接产出成长点，玩家拿到就能花。

### 5.1 成长点获取

| 场景 | 成长点 | 说明 |
| :--- | :--- | :--- |
| 事件奖励 | +1~3 | 部分事件给予 |
| 商店购买 | +1~2 | 成长之书类商品给予 |

> 成长点产出节奏经过精心设计：每场战斗约获得 3~4 成长点（通过参与/击杀/存活），约 8~10 场战斗可将单只生物点满。

### 5.2 成长点上限

| 项目 | 上限 | 说明 |
| :--- | :--- | :--- |
| 单只生物累计成长点 | **10 点** | 达到上限后不再获得 |
| 单只生物可持有未分配 | 无上限 | 鼓励攒点解锁技能槽 |

> **关键设计**：10 点上限意味着每只生物最多获得 10 次成长机会。玩家必须做取舍——是点属性，还是解锁技能槽。

### 5.3 成长选项

每消耗指定成长点，从以下选项中选择一个：

| 选项 | 消耗 | 效果 | 上限 |
| :--- | :--- | :--- | :--- |
| 提升生命 | 1 点 | 生命 +2 | +20 |
| 提升速度 | 1 点 | 速度 +1 | +10 |
| 解锁第 4 技能槽 | 2 点 | 从技能库三选一装备 | 1 次 |
| 解锁第 5 技能槽 | 3 点 | 从技能库三选一装备 | 1 次 |
| 替换技能 | 1 点 | 替换 1 个已有技能 | 无限制 |

**技能槽解锁规则**：解锁第 4/5 技能槽后，立即从当前技能库中随机展示 3 个技能，玩家选择 1 个装备到新槽位。若不满意可花 1 成长点重新随机（与「替换技能」共用次数限制）。

### 5.4 属性提升上限

| 属性 | 上限 | 说明 |
| :--- | :--- | :--- |
| 生命 | +20 | 最多消耗 10 个成长点 |
| 速度 | +10 | 最多消耗 10 个成长点 |

与事件/商店的属性强化叠加，但总上限不变。

## 六、生物获取

### 6.1 获取途径

本模式战斗中不可驯服，获取新生物的途径为：

| 途径 | 概率 | 说明 |
| :--- | :--- | :--- |
| 商店「生物招募」 | 中 | 商店出售随机生物（品阶 1~2，20 金币） |
| 事件「生物招募」 | 中 | 部分事件可招募新生物 |

### 6.2 生物池

- 从主模式基础生物池中抽取（品阶 1~2）
- 首领不可获取

### 6.3 队伍管理

- 队伍上限 6 只
- 超出时进入「处理队伍」界面（替换/放生）
- 本模式禁用融合，因此无融合选项
- 替换时可选择放生任意一只（含出战成员）

## 十、战斗设计

### 10.1 敌人规模

| 层数 | 普通战斗 | 精英 | 说明 |
| :--- | :--- | :--- | :--- |
| 1~10 层 | 1v1 | 2v2 | 前期简单 |
| 11~25 层 | 1v1 ~ 2v2 | 2v2 | 中期中等 |
| 26~50 层 | 2v2 ~ 3v3 | 2v2 | 后期困难 |

**出战规则**：玩家最多出战 3 只生物（精英化设计），敌方 n 只时玩家最多可上场 min(n+1, 3) 只。

### 10.2 敌人强度

- 基础属性：复用主模式同品阶生物数据
- 缩放公式：`finalHp = baseHp × (1 + 0.05 × (layer - 1))`
- 速度不随层数变化（保持基础值）
- 精英/Boss 额外加成：生命 ×1.5

### 10.3 战斗奖励

| 奖励 | 说明 |
| :--- | :--- |
| 金币 | 每场战斗 8~16 金 |
| 道具 | 精英战斗后掉落 |

## 十一、回复机制

| 场景 | 回复量 | 说明 |
| :--- | :--- | :--- |
| 战后自动回血 | 80% | 仅回复存活生物，阵亡者不回复 |
| 休憩点 | 50% | 休憩节点选择 |
| 商店休憩 | 100% | 商店内选择休憩 |

**回复特点**：相比主模式（战后 60%），成长远征模式的回复更慷慨（80%），因为无法通过驯服/融合补充队伍，需要维持现有宠物的续航能力。50层长途跋涉中，合理利用休憩点和商店休憩是生存关键。但仅回复存活生物——阵亡者不会被战后回血复活。

## 十二、死亡与结算

### 12.1 死亡规则

| 场景 | 结果 |
| :--- | :--- |
| 单只宠物阵亡 | 永久删除，若队伍非空则继续 |
| 全队阵亡 | 本局结束，进入结算界面 |
| 击败层50 Boss | 本局胜利，进入结算界面 |

### 12.2 结算界面


## 十四、平衡性建议

| 关注点 | 建议 |
| :--- | :--- |
| 初始生物数量 | 2 只（6 选 2） |
| 成长点消耗 | 属性 1 点、槽位 2~3 点、替换 1 点 |
| 属性上限 | 生命 +20、速度 +10，防止数值膨胀 |
| 技能槽上限 | 5 个，防止技能过多 |
| 队伍上限 | 6 只，出战 3 只，强调精英化 |
| 敌人强度 | 每层 +5%，3 个 Boss 递增难度 |
| 单局时长 | 40~60 分钟，适合深度游玩 |
| 禁用融合 | 本模式禁用融合，成长点是唯一成长主轴 |
| 驯服限制 | 战斗中不可驯服，生物获取靠事件/商店 |

## 十五、设计意图总结

| 目标 | 实现方式 |
| :--- | :--- |
| 独立的 Roguelike 体验 | 单局爬塔，死亡即结束，与主模式完全分离 |
| **成长点为核心** | 禁用融合与驯服，成长点是唯一成长资源 |
| 紧凑的节奏 | 线性爬塔，50 层，40~60 分钟一局 |
| 精英化队伍 | 队伍上限 6 只，出战 3 只，强调核心培养 |
| 专属内容 | 专属事件、商店、奇遇，围绕成长点设计 |
| 重复可玩性 | 随机地图与事件，不同策略选择 |
