# 🎮 驯牌远征 · 成长远征模式（Roguelike 独立模式）

一个独立于主模式的 Roguelike 新玩法。玩家从少量初始生物出发，通过战斗、专属事件、商店、奇遇逐步强化核心生物、获取新生物，最终挑战模式专属首领。核心特色：成长点是唯一的成长资源——不依赖融合、不依赖驯服，纯粹通过战斗积累让生物变强。

## 术语与数值总表

| 术语 | 数值 | 说明 |

| 总层数 | 50 层 | 线性爬塔 + 3 个 Boss（层15/30/50） |
| 队伍上限 | 5 只 | 比主模式少，强调核心培养 |

## 一、模式定位

| 维度 | 设定 |
| :--- | :--- |
| 模式类型 | 独立模式（主菜单进入） |
| 解锁条件 | 通关主模式第 1 幕 |
| 核心玩法 | 单局 Roguelike，成长点分配，逐层推进 |
| 单局时长 | 40~60 分钟 |
| 地图结构 | 线性爬塔（每层 1 个节点，无分支） |
| 层数 | 50 层 + 3 个 Boss（层15/30/50） |
| 存档 | 单局内可保存退出，死亡即结束（Roguelike 标准） |

## 二、与主模式的核心差异

| 维度 | 主模式 | 成长远征模式 |
| :--- | :--- | :--- |
| 成长主轴 | 融合进化 + 属性强化 | **成长点分配** |
| 初始生物 | 御三家选 1 + 剩余3只选1 | 从 6 只品阶 1 生物中选 2 只 |
| 融合 | 核心养成手段 | 无进化链，融合不可用 |
| 驯服 | 核心获取手段 | 战斗中不可驯服，事件/商店可招募 |
| 地图 | 3 幕爬塔，多分支 | 单幕长塔，无分支 |
| 事件 | 通用事件池 | 专属事件池（围绕成长点设计） |
| 商店 | 通用商品 | 专属商品（围绕成长点设计） |
| 奇遇关 | 通用奖励 | 专属奖励（围绕成长点设计） |
| 死亡惩罚 | 全队阵亡即失败 | 单只阵亡即永久删除，全队阵亡即结束 |

## 四、地图结构

### 4.1 线性爬塔

```
第 1 层 → 第 2 层 → ... → 第 15 层(Boss1) → ... → 第 30 层(Boss2) → ... → 第 50 层(Boss3)
```

- 每层 1 个节点，类型随机
- 节点类型及概率：

| 节点类型 | 概率 | 说明 |
| :--- | :--- | :--- |
| 战斗 | 55% | 普通战斗 |
| 精英 | 15% | 精英战斗，高奖励 |
| 事件 | 12% | 专属事件池 |
| 休憩 | 8% / 每10层保底 | 回复 100% 生命 + 宠物融合 |
| 商店 | 不固定 | 每隔 6~8 层一个，最多 6 个，前 5 层不出现 |
| 奇遇关 | 不固定 | 每隔 10~20 层一个，最多 4 个，前 5 层不出现 |
| Boss | 固定 | 层15/30/50 |

### 4.2 固定节点规则

固定节点优先于随机生成，覆盖对应层的随机结果：

| 规则 | 说明 |
| :--- | :--- |
| 第 1 层 | 强制战斗（教学战） |
| 第 10/20/40 层 | 强制休憩（回复 100% 生命 + 宠物融合） |
| 商店 | 每隔 6~8 层出现一个（随机间隔），最多 6 个，不与 Boss 层/休憩层重叠，前 5 层不出现 |
| 奇遇关 | 每隔 10~20 层出现一个（随机间隔），最多 4 个，不与 Boss/商店/休憩层重叠，前 5 层不出现 |
| 第 15 层 | Boss 1：第一幕Boss随机（古树之主/潮汐巨蟹/暗影之王） |
| 第 30 层 | Boss 2：第二幕Boss随机（苔藓领主/幽灵船长/岩甲巨像） |
| 第 50 层 | Boss 3：成长之主（固定） |

### 4.3 层进度概率微调

| 层范围 | 调整 |
| :--- | :--- |
| 1~10 层 | 精英 -8%，战斗 +5%，休憩 +3%（教学期） |
| 11~25 层 | 精英 -3%，战斗 +3%（中期平稳） |
| 26~40 层 | 精英 +3%，战斗 -3%（难度爬升） |
| 41~50 层 | 精英 +5%，战斗 -2%，休憩 +1%（后期高压） |

### 4.3 地图生成

使用专属 `generateGrowthMap()` 生成线性爬塔地图：
- 单幕 50 层，每层 1 个节点
- 保底休憩：层 10/20/40 强制休憩（回复 100% 生命 + 可选宠物融合）
- 商店每隔 6~8 层随机出现（最多 6 个），奇遇关每隔 10~20 层随机出现（最多 4 个）
- 前 5 层不出现商店和奇遇关
- 不与 Boss 层（15/30/50）和休憩层重叠
- 按概率表生成其余节点类型

## 五、成长点系统（核心）

成长点是本模式唯一的成长资源。不依赖熟练度等级，战斗/事件/商店直接产出成长点，玩家拿到就能花。

### 5.1 成长点获取

| 场景 | 成长点 | 说明 |
| :--- | :--- | :--- |
| 每关保底 | +1 | 队伍中所有宠物（含后备）每关结束自动获得 |
| 战斗参与 | +1 | 参与战斗的宠物额外获得 |
| 击杀普通敌人 | +2 | 每只 |
| 击杀精英敌人 | +4 | 每只 |
| 击杀 Boss 小怪 | +2 | 每只 |
| 击杀 Boss 本体 | +6 | 每场 1 只 |
| 事件奖励 | +1~3 | 部分事件给予 |
| 商店购买 | +1~2 | 成长之书类商品给予 |

> 每关所有宠物保底 +1；参与战斗额外 +1 + 击杀奖励。普通战斗参与宠物约 +4~6，精英约 +10，Boss 战约 +10~14。

### 5.2 成长点上限

| 项目 | 上限 | 说明 |
| :--- | :--- | :--- |
| 单只生物累计成长点 | **无上限** | 累计获取越多，成长越强 |
| 单只生物可持有未分配 | 无上限 | 鼓励攒点解锁技能槽 |

> **设计意图**：无上限意味着玩家可以持续积累成长点，但属性提升有硬上限（生命 +30、速度 +15），技能槽最多解锁 3 个，因此成长点的实际价值随积累逐渐递减。

### 5.3 成长选项

每消耗指定成长点，从以下选项中选择一个（属性提升消耗递增）：

| 选项 | 消耗 | 效果 | 上限 |
| :--- | :--- | :--- | :--- |

| 提升速度 | 递增（见下表） | 速度 +1 | +15 |
| 解锁第 3 技能槽 | 5 点 | 从普通技能库三选一装备 | 1 次 |
| 解锁第 4 技能槽 | 8 点 | 从普通技能库三选一装备 | 1 次 |
| 解锁第 5 技能槽 | 10 点 | 从普通技能库三选一装备 | 1 次 |
| 替换技能 | 8 点 | 替换 1 个已有技能，从普通技能库三选一 | 无限制 |

### 5.3a 强化技能

消耗成长点永久强化已有技能，每个技能最多强化 3 次。

| 强化等级 | 消耗 | 累计消耗 | 攻击/治疗/护盾加成 | Buff 效果值加成 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 8 点 | 8 点 | +2 | +1 |
| 2 | 10 点 | 18 点 | +4 | +2 |
| 3 | 12 点 | 30 点 | +6 | +3 |

**强化规则**：
- 攻击技能（`kind: 'attack'`）：每级伤害 +2
- 连击技能（`hits ≥ 2`）：每级段数 +1（优先于伤害 +2，最多 2 次）
- 攻击+治疗混合技能：每级伤害 +1 且 治疗 +1
- 攻击+状态混合技能：每级伤害 +1 且 效果值 +1（减速/降攻随升级提升）
- 治疗/护盾技能（`kind: 'heal'`）：每级治疗量 +2
- Buff 技能（`kind: 'buff'`）：每级效果值 +1（护盾每级 +2）
- 状态技能（`kind: 'status'`）：每级效果值 +1
- 传奇技能可强化，但消耗 ×1.5
- 强化绑定在宠物+槽位上，替换技能后强化消失
- 通过「还原石」可重置强化，返还 50% 累计消耗
- 强化效果为永久加成，跨战斗生效

**UI 显示要求**：
- 已强化技能在技能名右侧显示金色加号标记：+1 级显示 `+`，+2 级显示 `++`，+3 级显示 `+++`
- 加号颜色使用金色（`#e8c26a`），与技能名保持同行显示
- 强化后的数值（伤害/治疗/buff 效果值）用金色字体标出，区分于基础数值
- `SkillTag` 组件需支持 `enhanced?: number` 属性（0-3），控制加号显示和数值高亮
- `skillBrief` 函数需接收 `enhanced?: number` 参数，在技能名后追加金色加号

### 5.3b 成长点转移

将 1 只宠物的成长点转移给另 1 只宠物，用于"纠错"——让玩家调整成长点分配策略，但手续费防止滥用。

| 项目 | 说明 |
| :--- | :--- |
| 手续费 | 转移量的 50%（向上取整） |
| 转移下限 | 1 点 |
| 目标限制 | 不能转移给自身 |

**计算公式**：
- 手续费 = `ceil(转移量 × 0.5)`
- 目标实际获得 = `转移量 - 手续费`

**示例**：

| 转移量 | 手续费 | 目标获得 |
| :--- | :--- | :--- |
| 10 点 | 5 点 | 5 点 |
| 1 点 | 1 点 | 0 点 |
| 8 点 | 4 点 | 4 点 |
| 15 点 | 8 点 | 7 点 |

**设计意图**：
- 给玩家"纠错"的机会：前期误分配的成长点可以转移给更需要的宠物
- 手续费防止滥用：50% 损耗确保转移有代价，不能频繁倒手
- 不能转移给自身：避免无损耗刷点

## 六、生物获取

### 6.1 获取途径

本模式战斗中不可驯服，获取新生物的途径为：

| 途径 | 概率 | 说明 |
| :--- | :--- | :--- |
| 商店「生物招募」 | 中 | 商店出售随机生物（品阶 1~2，20 金币） |
| 事件「生物招募」 | 中 | 部分事件可招募新生物 |

### 6.2 生物池

- 从主模式基础生物池中抽取（品阶 1~2）
- 首领不可获取

### 6.3 队伍管理

- 队伍上限 5 只
- 超出时进入「处理队伍」界面（替换/放生）
- 本模式禁用融合，因此无融合选项
- 替换时可选择放生任意一只（含出战成员）

| :--- | :--- | :--- | :--- |

| 终焉成长 | 治疗 | 回复20HP，自身永久+1伤害，每次使用累加（限3次，最多+3） | 10 |

| 成长爆发 | 攻击 | 对所有敌人造成8伤害 | 3 |

| 属性 | 值 |
| :--- | :--- |
| 基础生命 | 10 |
| 基础速度 | 2 |
| 被动 | 献祭（存活时回合结束给Boss+1成长值，死亡时+3成长值） |

| 技能 | 类型 | 效果 |
| :--- | :--- | :--- |
| 傀儡束缚 | 攻击 | 造成5伤害，封印目标1个随机技能1回合 |

**Boss机制说明：**
- 成长值是Boss的核心资源，通过攻击命中和傀儡献祭累积
- 消耗成长值可释放强力技能（终焉成长/成长冲击/成长爆发/成长召唤）
- 技能封印可暂时封锁对手的特定技能（战斗日志会显示被封印的技能名）
- 成长之主的buff弹窗会显示当前剩余成长值
- 傀儡通过献祭被动为Boss提供成长值，归魂技能可主动释放造成AOE伤害后自爆
- 成长之主+1只傀儡时每回合结束获得2点成长值（自身+1+傀儡献祭+1）

## 十一、回复机制

| 场景 | 回复量 | 说明 |
| :--- | :--- | :--- |
| 战后自动回血 | 80% | 仅回复存活生物，阵亡者不回复 |
| 休憩点 | 100% + 融合 | 层 10/20/40 保底出现；回复全部生命 + 可选宠物融合 |

**回复特点**：相比主模式（战后 60%），成长远征模式的回复更慷慨（80%），因为无法通过驯服/融合补充队伍，需要维持现有宠物的续航能力。50层长途跋涉中，合理利用休整节点的回复或融合选项是生存关键。但仅回复存活生物——阵亡者不会被战后回血复活。

**休憩节点双选项**：
- **休息（恢复满血）**：全队回复 100% 生命
- **宠物融合**：单界面操作，拖拽/点击宠物到主宠槽和副宠槽；确认后属性继承（副宠50%基础属性）；玩家手动选择副宠技能学习和主宠技能替换

## 十二、死亡与结算

### 12.1 死亡规则

| 场景 | 结果 |
| :--- | :--- |
| 单只宠物阵亡 | 永久删除，进入**死亡墓园**，若队伍非空则继续 |
| 全队阵亡 | 本局结束，进入结算界面 |
| 击败层50 Boss | 本局胜利，进入结算界面 |

### 12.2 死亡墓园与复活

战斗中阵亡的宠物会进入**死亡墓园**（`deadPets`），而非直接删除。死亡墓园是成长远征模式的容错机制，通过奇遇关和事件关可以复活已死亡的宠物。

| 复活来源 | 复活比例 | 触发方式 |
| :--- | :--- | :--- |
| **奇遇关：生命之泉** | 100% 基础属性 | 奇遇关奖励三选一中随机出现 |
| **事件关：灵魂墓园** | 50% 基础属性 | 事件关「灵魂墓园」事件的选项 |

**复活规则**：
- 复活后的宠物属性为原基础属性 × 复活比例（向上取整，最低 1 点）
- 复活后清除所有状态（灼烧/中毒/眩晕等）
- 复活后重置技能次数和冷却
- 若队伍已满（5只），复活的宠物会加入队伍，需要在「处理队伍」界面选择放生或替换
- 死亡墓园最多保留 10 只死亡宠物，超出后最早的记录被覆盖

## 十四、平衡性建议

| 关注点 | 建议 |
| :--- | :--- |
| 初始生物数量 | 2 只（5 选 2） |
| 成长点消耗 | 属性递增（HP: 2→10 点/次，SPD: 2→5 点/次）、槽位 5/8/10 点、替换 8 点、强化 8/10/12 点 |
| 属性上限 | 生命 +30、速度 +15，防止数值膨胀 |
| 技能槽上限 | 5 个，防止技能过多 |
| 队伍上限 | 5 只，出战 3 只，强调精英化 |
| 敌人强度 | 每层 +10% 生命、+10% 速度，3 个 Boss 递增难度 |
| 单局时长 | 40~60 分钟，适合深度游玩 |
| 禁用融合 | 本模式禁用融合，成长点是唯一成长主轴 |
| 驯服限制 | 战斗中不可驯服，生物获取靠事件/商店 |

## 十五、设计意图总结

| 目标 | 实现方式 |
| :--- | :--- |
| 独立的 Roguelike 体验 | 单局爬塔，死亡即结束，与主模式完全分离 |

| **死亡墓园** | 阵亡宠物可复活，通过奇遇关或事件关触发 |
