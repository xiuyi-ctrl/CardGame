# 🎮 驯牌远征 · 成长远征模式（Roguelike 独立模式）

一个独立于主模式的 Roguelike 新玩法。玩家从少量初始生物出发，通过战斗、专属事件、商店、奇遇逐步强化核心生物、获取新生物，最终挑战模式专属首领。核心特色：成长点是唯一的成长资源——不依赖融合、不依赖驯服，纯粹通过战斗积累让生物变强。

## 术语与数值总表

| 术语 | 数值 | 说明 |
| :--- | :--- | :--- |

| 队伍上限 | 5 只 | 比主模式少，强调核心培养 |

## 一、模式定位

| 维度 | 设定 |
| :--- | :--- |
| 模式类型 | 独立模式（主菜单进入） |
| 解锁条件 | 通关主模式第 1 幕 |
| 核心玩法 | 单局 Roguelike，成长点分配，逐层推进 |
| 单局时长 | 40~60 分钟 |
| 地图结构 | 线性爬塔（每层 1 个节点，无分支） |
| 层数 | 50 层 + 3 个 Boss（层15/30/50） |
| 存档 | 单局内可保存退出，死亡即结束（Roguelike 标准） |

## 二、与主模式的核心差异

| 维度 | 主模式 | 成长远征模式 |
| :--- | :--- | :--- |
| 成长主轴 | 融合进化 + 属性强化 | **成长点分配** |
| 初始生物 | 御三家选 1 + 剩余3只选1 | 从 6 只品阶 1 生物中选 2 只 |
| 融合 | 核心养成手段 | 无进化链，融合不可用 |
| 驯服 | 核心获取手段 | 战斗中不可驯服，事件/商店可招募 |
| 地图 | 3 幕爬塔，多分支 | 单幕长塔，无分支 |
| 事件 | 通用事件池 | 专属事件池（围绕成长点设计） |
| 商店 | 通用商品 | 专属商品（围绕成长点设计） |
| 奇遇关 | 通用奖励 | 专属奖励（围绕成长点设计） |
| 死亡惩罚 | 全队阵亡即失败 | 单只阵亡即永久删除，全队阵亡即结束 |

## 四、地图结构

### 4.1 线性爬塔

```
第 1 层 → 第 2 层 → ... → 第 15 层(Boss1) → ... → 第 30 层(Boss2) → ... → 第 50 层(Boss3)
```

- 每层 1 个节点，类型随机
- 节点类型及概率：

| 节点类型 | 概率 | 说明 |
| :--- | :--- | :--- |
| 战斗 | 55% | 普通战斗 |
| 精英 | 15% | 精英战斗，高奖励 |
| 事件 | 12% | 专属事件池 |
| 休憩 | 8% | 回复 50% 生命 |
| 商店 | 不固定 | 每隔 6~8 层一个，最多 6 个 |
| 奇遇关 | 不固定 | 每隔 10~20 层一个，最多 4 个 |
| Boss | 固定 | 层15/30/50 |

### 4.2 固定节点规则

固定节点优先于随机生成，覆盖对应层的随机结果：

| 规则 | 说明 |
| :--- | :--- |
| 第 1 层 | 强制战斗（教学战） |
| 商店 | 每隔 6~8 层出现一个（随机间隔），最多 6 个，不与 Boss 层重叠 |
| 奇遇关 | 每隔 10~20 层出现一个（随机间隔），最多 4 个，不与 Boss/商店重叠 |
| 第 15 层 | Boss 1：第一幕Boss随机（古树之主/潮汐巨蟹/暗影之王） |
| 第 30 层 | Boss 2：第二幕Boss随机（苔藓领主/幽灵船长/岩甲巨像） |
| 第 50 层 | Boss 3：成长之主（固定） |

### 4.3 层进度概率微调

| 层范围 | 调整 |
| :--- | :--- |
| 1~10 层 | 精英 -8%，战斗 +5%，休憩 +3%（教学期） |
| 11~25 层 | 精英 -3%，战斗 +3%（中期平稳） |
| 26~40 层 | 精英 +3%，战斗 -3%（难度爬升） |
| 41~50 层 | 精英 +5%，战斗 -2%，休憩 +1%（后期高压） |

### 4.3 地图生成

使用专属 `generateGrowthMap()` 生成线性爬塔地图：
- 单幕 50 层，每层 1 个节点
- 商店每隔 6~8 层随机出现（最多 6 个），奇遇关每隔 10~20 层随机出现（最多 4 个）
- 不与 Boss 层（15/30/50）和其他固定节点重叠
- 按概率表生成其余节点类型

## 五、成长点系统（核心）

成长点是本模式唯一的成长资源。不依赖熟练度等级，战斗/事件/商店直接产出成长点，玩家拿到就能花。

### 5.1 成长点获取

| 场景 | 成长点 | 说明 |
| :--- | :--- | :--- |
| 战斗参与 | +2 | 参与战斗即获得 |
| 战斗存活 | +2 | 存活额外获得 |
| 击杀奖励 | +2~6 | 普通 +2 / 精英 +4 / Boss +6 |
| 事件奖励 | +1~3 | 部分事件给予 |
| 商店购买 | +1~2 | 成长之书类商品给予 |

> 成长点产出节奏：每场战斗约获得 4~6 成长点，约 6~8 场战斗可将单只生物点满。

### 5.2 成长点上限

| 项目 | 上限 | 说明 |
| :--- | :--- | :--- |
| 单只生物累计成长点 | **无上限** | 累计获取越多，成长越强 |
| 单只生物可持有未分配 | 无上限 | 鼓励攒点解锁技能槽 |

> **设计意图**：无上限意味着玩家可以持续积累成长点，但属性提升有硬上限（生命 +30、速度 +15），技能槽最多解锁 3 个，因此成长点的实际价值随积累逐渐递减。

### 5.3 成长选项

每消耗指定成长点，从以下选项中选择一个：

| 选项 | 消耗 | 效果 | 上限 |
| :--- | :--- | :--- | :--- |
| 提升生命 | 2 点 | 生命 +2 | +30 |
| 提升速度 | 2 点 | 速度 +1 | +15 |
| 解锁第 3 技能槽 | 5 点 | 从普通技能库三选一装备 | 1 次 |
| 解锁第 4 技能槽 | 8 点 | 从普通技能库三选一装备 | 1 次 |
| 解锁第 5 技能槽 | 10 点 | 从普通技能库三选一装备 | 1 次 |
| 替换技能 | 5 点 | 替换 1 个已有技能，从普通技能库三选一 | 无限制 |

**技能槽解锁规则**：解锁第 3/4/5 技能槽后，立即从**普通技能库**中随机展示 3 个技能，玩家选择 1 个装备到新槽位。

### 5.4 技能池分类

**普通技能池排除**：Boss 专属技能（44 个）+ 传奇专属技能（15 个）+ 成长之主技能（4 个）

## 六、生物获取

### 6.1 获取途径

本模式战斗中不可驯服，获取新生物的途径为：

| 途径 | 概率 | 说明 |
| :--- | :--- | :--- |
| 商店「生物招募」 | 中 | 商店出售随机生物（品阶 1~2，20 金币） |
| 事件「生物招募」 | 中 | 部分事件可招募新生物 |

### 6.2 生物池

- 从主模式基础生物池中抽取（品阶 1~2）
- 首领不可获取

### 6.3 队伍管理

- 队伍上限 5 只
- 超出时进入「处理队伍」界面（替换/放生）
- 本模式禁用融合，因此无融合选项
- 替换时可选择放生任意一只（含出战成员）

## 八、专属商店

本模式商店围绕成长点成长设计，与主模式商店不共用。

### 8.1 商品池（6 种）

| 商品 | 价格 | 效果 |
| :--- | :--- | :--- |
| 成长之书（小） | 15 金 | 选择 1 只宠物，+1 成长点 |
| 成长之书（大） | 25 金 | 选择 1 只宠物，+2 成长点 |
| 技能槽解锁 | 50 金 | 选择 1 只宠物，解锁一个技能槽（无需成长点） |
| 遗忘之石 | 30 金 | 选择 1 只宠物，重置其成长点 |
| 生物招募 | 20 金 | 获得 1 只随机生物（品阶 1~2） |
| 治疗圣水 | 30 金 | 全队回复 50% 生命 |

### 8.2 商店规则

- 每次进店随机出售 4 种商品（从 9 种商品池洗牌抽取）
- 每种商品限购 1 次
- 可花金币刷新商品（5 金 → 10 金 → 15 金，最多 3 次）
- 进入商店时可选择购买商品（刷新最多3次）

本模式奇遇关围绕成长点成长设计，与主模式奇遇关不共用。

### 9.1 奖励池（6 种）

| 奖励 | 效果 |
| :--- | :--- |
| **成长之赐** | **全队各获得 5 成长点** |
| **属性之赐** | **选择 1 只宠物，永久 +5 生命 或 +2 速度（不计入属性提升上限）** |

- 从 6 种奖励中随机抽取 3 种展示，玩家选择 1 种
- 结果由种子预掷，可复现

## 十、战斗设计

### 10.1 敌人规模

| 层数 | 普通战斗 | 精英 | 说明 |
| :--- | :--- | :--- | :--- |
| 1~10 层 | 1v1 | 2v2 | 前期简单 |
| 11~25 层 | 1v1 ~ 2v2 | 2v2 | 中期中等 |
| 26~50 层 | 2v2 ~ 3v3 | 2v2 | 后期困难 |

**出战规则**：玩家最多出战 3 只生物（精英化设计），敌方 n 只时玩家最多可上场 min(n+1, 3) 只。

### 10.2 敌人强度

- 基础属性：复用主模式同品阶生物数据
- 缩放公式：`finalHp = baseHp × (1 + 0.05 × (layer - 1))`
- 速度不随层数变化（保持基础值）
- 精英/Boss 额外加成：生命 ×1.5

## 十一、回复机制

| 场景 | 回复量 | 说明 |
| :--- | :--- | :--- |
| 战后自动回血 | 80% | 仅回复存活生物，阵亡者不回复 |
| 休憩点 | 50% | 休憩节点选择 |
| 休整节点 | 100% 或宠物融合 | 营火节点选择回满血或跨种融合 |

**回复特点**：相比主模式（战后 60%），成长远征模式的回复更慷慨（80%），因为无法通过驯服/融合补充队伍，需要维持现有宠物的续航能力。50层长途跋涉中，合理利用休整节点的回复或融合选项是生存关键。但仅回复存活生物——阵亡者不会被战后回血复活。

## 十二、死亡与结算

### 12.1 死亡规则

| 场景 | 结果 |
| :--- | :--- |
| 单只宠物阵亡 | 永久删除，进入**死亡墓园**，若队伍非空则继续 |
| 全队阵亡 | 本局结束，进入结算界面 |
| 击败层50 Boss | 本局胜利，进入结算界面 |

### 12.2 死亡墓园与复活

战斗中阵亡的宠物会进入**死亡墓园**（`deadPets`），而非直接删除。死亡墓园是成长远征模式的容错机制，通过奇遇关和事件关可以复活已死亡的宠物。

| 复活来源 | 复活比例 | 触发方式 |
| :--- | :--- | :--- |
| **奇遇关：生命之泉** | 100% 基础属性 | 奇遇关奖励三选一中随机出现 |
| **事件关：灵魂墓园** | 50% 基础属性 | 事件关「灵魂墓园」事件的选项 |

**复活规则**：
- 复活后的宠物属性为原基础属性 × 复活比例（向上取整，最低 1 点）
- 复活后清除所有状态（灼烧/中毒/眩晕等）
- 复活后重置技能次数和冷却
- 若队伍已满（5只），复活的宠物会加入队伍，需要在「处理队伍」界面选择放生或替换
- 死亡墓园最多保留 10 只死亡宠物，超出后最早的记录被覆盖

## 十四、平衡性建议

| 关注点 | 建议 |
| :--- | :--- |
| 初始生物数量 | 2 只（5 选 2） |
| 成长点消耗 | 属性 2 点、槽位 5/8/10 点、替换 5 点 |
| 属性上限 | 生命 +30、速度 +15，防止数值膨胀 |
| 技能槽上限 | 5 个，防止技能过多 |
| 队伍上限 | 5 只，出战 3 只，强调精英化 |
| 敌人强度 | 每层 +10% 生命、+5% 速度，3 个 Boss 递增难度 |
| 单局时长 | 40~60 分钟，适合深度游玩 |
| 禁用融合 | 本模式禁用融合，成长点是唯一成长主轴 |
| 驯服限制 | 战斗中不可驯服，生物获取靠事件/商店 |

## 十五、设计意图总结

| 目标 | 实现方式 |
| :--- | :--- |
| 独立的 Roguelike 体验 | 单局爬塔，死亡即结束，与主模式完全分离 |
| **成长点为核心** | 禁用融合与驯服，成长点是唯一成长资源 |
| 紧凑的节奏 | 线性爬塔，50 层，40~60 分钟一局 |
| 精英化队伍 | 队伍上限 5 只，出战 3 只，强调核心培养 |
| 专属内容 | 专属事件、商店、奇遇，围绕成长点设计 |
| 重复可玩性 | 随机地图与事件，不同策略选择 |
| **死亡墓园** | 阵亡宠物可复活，通过奇遇关或事件关触发 |
