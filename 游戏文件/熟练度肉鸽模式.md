# 🎮 驯牌远征 · 熟练度远征模式（Roguelike 独立模式）

一个独立于主模式的 Roguelike 新玩法。玩家从少量初始生物出发，通过战斗、专属事件、商店、奇遇逐步强化核心生物、获取新生物，最终挑战模式专属首领。核心特色：熟练度是唯一的成长主轴——不依赖融合、不依赖驯服，纯粹通过战斗积累让生物变强。

## 术语与数值总表

| 术语 | 数值 | 说明 |
| :--- | :--- | :--- |
| 总层数 | 15 层 | 线性爬塔 + 最终首领 |
| 队伍上限 | 6 只 | 比主模式少，强调核心培养 |
| 出战上限 | 3 只 | 精英化，每只都有出场价值 |
| 初始资源 | 30 金币 | 无食物/道具 |
| 熟练度满级 | Lv.10（55 点） | 约 8~10 场战斗满级 |
| 成长点上限 | 10 点（基础） | 事件/商店可额外获取 |
| 属性提升上限 | 生命 +20 / 速度 +10 | 含事件/商店加成 |
| 技能槽上限 | 5 个（默认 3 + 最多解锁 2） | 解锁后从技能库三选一 |
| Boss 生命 | 40 | 熟练之主 |
| Boss 小怪 | 2 只（各 10HP） | 熟练傀儡 |
| 战后回血 | 80% | 仅回复存活生物 |
| 敌人缩放 | 每层 +5% 生命 | 速度不变 |

## 一、模式定位

| 维度     | 设定                                         |
| :------- | :------------------------------------------- |
| 模式类型 | 独立模式（主菜单进入）                       |
| 解锁条件 | 通关主模式第 1 幕                            |
| 核心玩法 | 单局 Roguelike，熟练度成长，逐层推进         |
| 单局时长 | 20~40 分钟                                   |
| 地图结构 | 线性爬塔（每层 1 个节点，无分支）            |
| 层数     | 15 层 + 1 个最终首领                         |
| 存档     | 单局内可保存退出，死亡即结束（Roguelike 标准） |

## 二、与主模式的核心差异

| 维度     | 主模式                 | 熟练度远征模式                     |
| :------- | :--------------------- | :--------------------------------- |
| 成长主轴 | 融合进化 + 属性强化    | 熟练度成长                         |
| 初始生物 | 御三家选 1 + 随机 1 只 | 从 6 只品阶 1 生物中选 2 只 |
| 融合     | 核心养成手段           | 无进化链，融合不可用               |
| 驯服     | 核心获取手段           | 战斗中不可驯服，事件/商店可招募   |
| 熟练度   | 辅助成长               | 唯一成长主轴                       |
| 地图     | 3 幕爬塔，多分支       | 单幕长塔，无分支                   |
| 事件     | 通用事件池             | 专属事件池（围绕熟练度设计）       |
| 商店     | 通用商品               | 专属商品（围绕熟练度设计）         |
| 奇遇关   | 通用奖励               | 专属奖励（围绕熟练度设计）         |
| 死亡惩罚 | 全队阵亡即失败         | 单只阵亡即永久删除，全队阵亡即结束 |

## 四、地图结构

### 4.1 线性爬塔

```
第 1 层 → 第 2 层 → 第 3 层 → ... → 第 15 层 → 最终首领
```

- 每层 1 个节点，类型随机
- 节点类型及概率：

| 节点类型 | 概率 | 说明 |
| :------- | :--- | :--- |
| 战斗     | 60%  | 普通战斗 |
| 精英     | 12%  | 精英战斗，高奖励 |
| 事件     | 10%  | 专属事件池 |
| 商店     | 8%   | 专属商店池 |
| 奇遇关   | 5%   | 专属奇遇池 |
| 休憩     | 5%   | 回复 50% 生命 |

### 4.2 固定节点规则

固定节点优先于随机生成，覆盖对应层的随机结果：

| 规则 | 说明 |
| :--- | :--- |
| 第 1 层 | 强制战斗（教学战） |
| 每 5 层 | 必有 1 个商店 |
| 第 10 层 | 必有 1 个奇遇关 |
| 第 15 层 | 最终首领 |

### 4.3 地图生成算法

复用现有 `generateMap()` 框架，修改以下参数：
- `layers`: 单幕 15 层，每层 1 个节点（`cols = 1`）
- `middleNodeType()`: 按上述概率表生成节点类型
- 特殊节点：商店/奇遇关按固定规则插入
- Boss 节点：第 15 层固定为最终首领

## 五、熟练度成长系统（核心）

### 5.1 熟练度获取

| 场景         | 熟练度 | 说明               |
| :----------- | :----- | :----------------- |
| 参与战斗     | +2     | 上场即得，无论胜败     |
| 击杀普通敌人 | +2     | 每击杀 1 个            |
| 击杀精英敌人 | +4     | 额外 +2               |
| 击杀首领     | +6     | 额外 +4               |
| 存活奖励     | +2     | 战斗结束时该生物存活，可与参与叠加 |
| 事件奖励     | +2~5   | 部分事件给予熟练度 |
| 商店购买     | +2~5   | 部分商品给予熟练度 |

### 5.2 熟练度等级

| 等级 | 升级所需 | 累计 | 获得成长点 |
| :--- | :------- | :--- | :--------- |
| 1    | 1        | 1    | 1          |
| 2    | 2        | 3    | 1          |
| 3    | 3        | 6    | 1          |
| 4    | 4        | 10   | 1          |
| 5    | 5        | 15   | 1          |
| 6    | 6        | 21   | 1          |
| 7    | 7        | 28   | 1          |
| 8    | 8        | 36   | 1          |
| 9    | 9        | 45   | 1          |
| 10   | 10       | 55   | 1          |

满级 10 级，共 55 点熟练度，约需 8~10 场战斗。

### 5.3 成长选项

每消耗 1 个成长点，从以下选项中选择一个：

| 选项       | 消耗 | 效果                                      | 上限 |
| :--------- | :--- | :---------------------------------------- | :--- |
| 提升生命   | 1 点 | 生命 +2                                   | +20  |
| 提升速度   | 1 点 | 速度 +1                                   | +10  |
| 解锁技能槽 | 2 点 | 解锁第 4 技能槽（可装备 1 个额外技能）    | 1 次 |
| 解锁技能槽 | 3 点 | 解锁第 5 技能槽（可装备 1 个额外技能）    | 1 次 |
| 替换技能   | 1 点 | 将 1 个已有技能替换为技能库中的另一个技能 | 无限制 |

**技能槽解锁规则**：解锁第 4/5 技能槽后，立即从当前技能库中随机展示 3 个技能，玩家选择 1 个装备到新槽位。若不满意可花 1 成长点重新随机（与「替换技能」共用次数限制）。

### 5.4 属性提升上限

| 属性 | 上限 | 说明                 |
| :--- | :--- | :------------------- |
| 生命 | +20  | 最多消耗 10 个成长点 |
| 速度 | +10  | 最多消耗 10 个成长点 |

与事件/商店的属性强化叠加，但总上限不变。

## 六、生物获取

### 6.1 获取途径

本模式战斗中不可驯服，获取新生物的途径为：

| 途径               | 概率 | 说明                                |
| :----------------- | :--- | :---------------------------------- |
| 商店「生物招募」   | 中   | 商店出售随机生物（品阶 1~2，25 金币） |
| 事件「生物招募」   | 中   | 部分事件可招募新生物                |

### 6.2 生物池

- 从主模式基础生物池中抽取（品阶 1~2）
- 首领不可获取

### 6.3 队伍管理

- 队伍上限 6 只
- 超出时进入「处理队伍」界面（替换/放生）
- 本模式禁用融合，因此无融合选项
- 替换时可选择放生任意一只（含出战成员）

## 十、战斗设计

### 10.1 敌人规模

| 层数     | 敌人规模            | 说明     |
| :------- | :------------------ | :------- |
| 1~5 层   | 1v1                 | 前期简单 |
| 6~10 层  | 1v1 ~ 2v2           | 中期中等 |
| 11~14 层 | 2v2 ~ 3v3           | 后期困难 |
| 第 15 层 | Boss + 2 只小怪     | 终极挑战 |

**出战规则**：玩家最多出战 3 只生物（精英化设计），敌方 n 只时玩家最多可上场 min(n+1, 3) 只。

### 10.2 敌人强度

- 基础属性：复用主模式同品阶生物数据
- 缩放公式：`finalHp = baseHp × (1 + 0.05 × (layer - 1))`
- 速度不随层数变化（保持基础值）
- 精英/Boss 额外加成：生命 ×1.5

### 10.3 战斗奖励

| 奖励   | 说明              |
| :----- | :---------------- |
| 金币   | 每场战斗 8~16 金  |
| 熟练度 | 按击杀数结算      |
| 道具   | 精英战斗后 10% 掉落 |

### 10.4 最终首领

**首领：熟练之主 🐉**

| 属性 | 值   |
| :--- | :--- |
| 生命 | 40   |
| 速度 | 6    |

**技能：**

| 技能     | 类型 | 效果                                       |
| :------- | :--- | :----------------------------------------- |
| 熟练冲击 | 攻击 | 造成 8 点伤害                              |
| 熟练领域 | buff | 全体己方 +2 伤害，持续 2 回合              |
| 战吼     | buff | 自身 +2 伤害，持续 2 回合                  |
| 熟练爆发 | 攻击 | 造成 12 点伤害                             |

**被动：**

| 被动       | 效果                                             |

| 熟练汲取   | 每次攻击命中汲取 1 熟练度；累积 10 熟练度时伤害 +3 |

**小怪：** 2 只「熟练傀儡」（10HP，品阶 1，技能：爪击，被动：铁壁）

## 十一、回复机制

| 场景         | 回复量 | 说明                     |
| :----------- | :----- | :----------------------- |
| 战后自动回血 | 80%    | 仅回复存活生物，阵亡者不回复 |
| 休憩点       | 50%    | 商店内或休憩节点选择     |
| 商店药水     | 50%    | 10 金币，全队回复        |

**回复特点**：相比主模式（战后 60%），熟练度远征模式的回复更慷慨（80%），因为无法通过驯服/融合补充队伍，需要维持现有宠物的续航能力。但仅回复存活生物——阵亡者不会被战后回血复活。

## 十二、死亡与结算

### 12.1 死亡规则

| 场景         | 结果                                       |
| :----------- | :----------------------------------------- |
| 单只宠物阵亡 | 永久删除，熟练度清零，若队伍非空则继续    |
| 全队阵亡     | 本局结束，进入结算界面                     |
| 击败最终首领 | 本局胜利，进入结算界面                     |

## 十四、平衡性建议

| 关注点         | 建议                                     |
| :------------- | :--------------------------------------- |
| 初始生物数量   | 3 只（御三家固定）                       |
| 熟练度获取速度 | 每场战斗 +4，约 8~10 场满级              |
| 成长点消耗     | 属性 1 点、槽位 2~3 点、替换 1 点        |
| 属性上限       | 生命 +20、速度 +10，防止数值膨胀         |
| 技能槽上限     | 5 个，防止技能过多                       |
| 队伍上限       | 6 只，出战 3 只，强调精英化              |
| 敌人强度       | 每层 +5%，最终首领为 40 生命             |
| 单局时长       | 20~40 分钟，适合碎片化游玩               |
| 禁用融合       | 本模式禁用融合，熟练度是唯一成长主轴     |
| 驯服限制       | 战斗中不可驯服，生物获取靠事件/商店      |

## 十五、设计意图总结

| 目标                  | 实现方式                               |
| :-------------------- | :------------------------------------- |
| 独立的 Roguelike 体验 | 单局爬塔，死亡即结束，与主模式完全分离 |
| 熟练度为核心          | 禁用融合与驯服，熟练度是唯一成长主轴   |
| 紧凑的节奏            | 线性爬塔，15 层，20~40 分钟一局        |
| 精英化队伍            | 队伍上限 6 只，出战 3 只，强调核心培养 |
| 专属内容              | 专属事件、商店、奇遇，围绕熟练度设计   |
| 重复可玩性            | 难度分级、称号解锁、随机地图与事件     |
