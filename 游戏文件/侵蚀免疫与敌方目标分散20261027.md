# 侵蚀免疫与敌方目标分散

## 第四种侵蚀

侵蚀节点现在从四种效果中等概率选择一种，生成时固定并随地图保存：

| 标识 | 效果 |
| --- | --- |
| spd | 我方入场速度-2 |
| dmg | 我方受到伤害+2，多段每段生效 |
| burn | 我方每回合结束受到2点侵蚀伤害 |
| immune | 敌人免疫负面效果 |

节点出现频率、敌人生物池、奖励翻倍和失败规则不变。旧存档已有节点不重抽。测试关卡的侵蚀选项新增“敌人免疫负面效果”，战斗顶部明确显示当前侵蚀。

### 免疫边界

- 阻止灼烧、中毒、降攻、减速、眩晕、嘲讽、恐惧、时滞、荆棘反噬、暗影印记、灼烧烙印、锁链、技能封印及待生效封印。
- 技能、攻击命中被动、受击反应、间接传播和直接恐惧入口统一适用。被拒绝的灼烧不计为成功附加，火狐不会因此获得狐火；恐惧不积累，也不触发震慑。
- 敌人的自灼烧同样被拒绝；它不是“免疫灼烧伤害但允许持有灼烧”的火狐被动。
- 普通攻击、真实伤害、护盾吸收、移除护盾、治疗及正面增益正常。反伤被动造成的直接伤害不被免疫；“荆棘”技能附加的攻击后反噬状态属于负面效果，会被免疫。
- 虚弱、缓速药水无效且不消耗物品；腐蚀药水直接扣生命，不属于持续负面状态，仍生效。
- 我方不获得免疫。捕捉所得生物、战后队伍及下一场普通战不携带这个节点效果；同场敌人替补、召唤单位仍受节点规则保护。
- 免疫发生时记录具体敌人的免疫提示，不添加无效状态图标。

## 敌方目标分散

### 修正原因

旧逻辑在每个攻击技能内部只留下最高分目标。残血与可斩杀的高分使其他目标没有抽中机会，即使最后的技能选择是随机的，也无法分散目标。多个敌人预选指令还重复使用同一份快照随机计数，进一步同步了它们的选择。

### 新规则

1. 原技能评分继续决定攻击、治疗、增益等行动。可收掉最后一个敌人时，仍有合理的攻击优先级。
2. 确定单体攻击技能后，在当前合法目标间做加权抽取，不直接锁定评分第一名。
3. 每名目标基础权重为1；生命低于30%加0.15；预估可击杀加0.35。中毒／灼烧配合或暗影追猎符合条件时再加0.2。
4. 已有其他敌人的预选攻击指向该目标时，权重除以`1 + 已预约攻击数 × 0.75`，降低同回合集火。
5. 每名实际预选行动的敌人按推进后的种子计数取随机值，不再共用相同随机值。额外传给选择器的指令仅用于检查敌方预约，不读取玩家隐藏指令。
6. 前后排、贯穿、指定攻击、嘲讽与特殊技能目标条件仍优先；嗜血嗅觉仍强制攻击最低生命目标。只有一个合法目标时仍正常攻击，多段单体技能不拆散目标，群攻与随机范围技能保持原目标规则。

例如没有配合、没有预约时，三个合法目标中一名残血且可击杀，权重为1.5／1／1，抽中残血约43%；两个合法目标时约60%。若已有一名敌人预约攻击该残血目标，权重降为约0.857／1／1，抽中率约30%。残血仍有轻微偏好，但不会几乎必定被反复集火。

所有随机来自现有种子机制，读档相同局面得到相同结果。这个修正会改变后续敌方行动和战斗走势；不修改已保存的地图、奖励或伙伴数值。
