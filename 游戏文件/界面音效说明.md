# 界面音效

2026-10-31接入第一批五种界面音效。电脑与手机共用同一资源及播放逻辑；本批不含战斗命中、状态结算或背景音乐。

| 音效 | 触发规则 |
| --- | --- |
| 轻点 | 普通有效按钮点击、进入一般界面。 |
| 确认 | 确认、领取、购买、开始等操作；成功提示可替代同次轻点。 |
| 返回 | 返回、关闭、取消、离开等按钮；音效设置支持原生返回和Esc关闭。 |
| 切换 | 带选中语义的按钮、页签、原生下拉框及复选／单选控件。重复点击未改变的已选项不发声。 |
| 不可用 | 新出现的错误／警告提示及存档失败事件。原生禁用按钮保持不可操作，不为声音改变行为。 |

同次点击仅选择一种声音，错误／警告优先于确认、返回、切换及轻点。优先级只合并同一批待播提示，不延迟异步操作等待最终结果。一般按钮的点击声只表示操作被点击；异步成功或失败提示可在完成时再反馈。悬停、右键、拖动后被取消的点击不发声。轻点与切换共用60毫秒限频，不可用提示限频250毫秒。

首页退出按钮旁提供“音效设置”；游戏菜单内提供相同入口。支持开关、音量和试听，默认开启、音量65%。设置保存为本机独立偏好，不写入或改变远征存档；所有槽位共用。静音或音量0立即停止声音，切换后台立即停止且不积压，返回后由新的用户操作恢复。只在用户交互后解锁播放权限。

五个WAV由本项目程序原创合成，原始样本和生成脚本位于 `design/audio/ui-sfx-v1/`。运行副本为 `src/ui/assets/audio/ui/`，素材副本为 `美术素材/audio/ui-sfx-v1/`。资源通过Vite导入，随电脑构建和Android资源同步打包，不访问外部音频服务。

每次替换音色时同步上述三份WAV，保持文件名；重新构建，确认包内包含新音频。资源加载或设备音频不可用时静默跳过，不能阻塞操作、改变游戏动作或消耗随机数。

验证包括资源逐字节一致、五种触发、重复点击、失败提示优先、拖动取消、后台、静音与设置持久化，并复查首页及设置窗的六种横屏手机尺寸和桌面布局。设备实际音量、蓝牙延迟及不同手机扬声器听感仍需真机确认。
