# 主模式融合专项评估报告

评估日期：2026-10-20。运行时数据版本：`8881a49`，另含当前工作区新增的诊断工具；本轮未修改战斗引擎、宠物、技能、被动、敌人或平衡基线。

## 一、结论

降低材料数量已经解决一部分“合不出来”的问题，但没有自动解决“合完少一个单位是否划算”。本次压力样本中，无替补时优先复核 **泡泡→泡泡将、咪咪→蟒影、刺刺→棘尾**。

并非所有融合都弱：铁卫→铁壁神在能使用护盾与多段技能的策略下明显有收益；迅牙→迅天、灼刃→灼天在前瞻策略下大体能抵消减少一个单位的成本。不能根据原自动玩家的结果统一给三阶加数值。

有替补通常显著改善融合表现，但这不意味着替补是免费收益，也不证明“融合后阵容”胜过所有不融合的最佳布阵。下一轮应优先比较受影响的具体形态，而不是全面提高进化倍率。

## 二、实验设计

主矩阵 **23,040 场**，毒系起手敏感性补充 **1,440 场**，合计 **24,480 场**；种子为 2000–2019，主矩阵无超时。

主矩阵覆盖：

- 六条主要进化链 × 两个进化阶段。
- 满血与受伤两组；受伤组原有伙伴和待命替补均从约50%生命开始，新形态按真实规则回满。
- 快攻、防守反伤、毒火状态、回复消耗、进阶精英、首领小怪六种固定压力场景；首领采用对应幕的古树之主/岩壳巨像及真实小怪。
- 原贪心与一回合前瞻两种决策策略。
- 不融合、融合无替补、融合后补输出、融合后补治疗四种方案。

对照阵容是“两只材料宠+一只固定队友”；无替补组是“融合结果+原固定队友”；补位组加入一只原本处于待命的同阶段迅迅/迅牙或泡泡/泡泡将。坦克、反伤链站前排并搭配输出队友，其他链站后排并搭配坦克队友；融合与补位保留对应位置。

每个表格单元包含六个场景×20种子=120场。同组同种子配对，但单位和技能变化会改变随机调用顺序，不能保证每次随机事件相同。

### 解释边界

1. 这些胜率是固定压力样本的通过率，**不是主模式通关率或真人胜率**，也没有按地图遭遇概率加权。
2. 前瞻策略会枚举当前回合实际结果，能获知该种子下敌人行为；仅逐单位改进一次，不是全局最优，且可能低估两回合以上的组合。
3. 未测试五人满编、所有队友组合、困难/地狱、强化与诅咒组合、捕获、道具、祝福和跨战资源循环。当前实验均满足出战人数上限，但不是随机地图遭遇生成测试。
4. 补位组假定已有替补，没有计算获取它的成本，也没有比较“不融合但把替补直接换上”的最佳阵容。
5. 阵亡数受单位数量影响；无替补组单位更少，不能仅凭阵亡只数较少判断更强。
6. 前三结算指标包含结束回合后引擎立即执行的下一回合开始效果。伤害为实际HP扣减，不计过量伤害；获盾量不等于吸收量，状态事件数不等于层数或战术价值。

## 四、优先复核的三个阶段

### 1. 泡泡→泡泡将：续航资源与行动容量同时收缩

- 两只泡泡合计28生命，泡泡将22，保留78.6%。
- 两只水愈各回2，合计每回合潜在恢复4；潮汐再生回3，不能简单视为翻倍升级。
- 两只泡泡合计有10次水浴，每次5治疗；泡泡将的愈光为2次，每次8。实际有效治疗还受受伤和行动分配限制，不能把原始治疗总量直接当作战力，但这是明确的资源差异。
- 前三结算队伍有效治疗由14.46降到11.68，实际HP输出由12.82降到10.15。
- 无替补时，快攻样本100%→60%，进阶精英100%→50%；防守反伤和回复场景没有下降。

**判断：**优先验证“二阶支援升级是否足以补偿失去一位治疗者”。后续候选方向是治疗可用次数、支援行动效率或持续恢复价值；本轮不直接指定增幅，也不同时全面提高生命和伤害。

### 2. 咪咪→蟒影：毒源与启动节奏改变

- 总生命20→17，速度3→4；两次基础行动变一次。
- 原咪咪的毒牙使攻击自动附毒；蟒影变为对已中毒目标增伤，需要主动毒刺或其他毒源配合。
- 前三结算实际HP输出26.85→19.54，下降约27.2%。
- 进阶精英样本100%→10%；首领15%→0%。普通四类场景仍均通过，问题集中在压力更高的战斗。

**补充起手测试：**强制首回合毒刺后，无替补满血通过率68.3%→59.2%，受伤60.8%→40.8%，没有修复当前样本的损失。它仍不是所有最优毒序列的穷举，不能据此判定施毒本身无价值。

**判断：**优先复核进化时失去自动施毒的启动代价，而不是只给影袭加伤害。后续要比较有外部毒源与无毒源两种阵容，再决定是否调整毒刺效率、毒源或增伤兑现方式；不增加旧技能继承。

### 3. 刺刺→棘尾：生命与两个控制位的损失

- 两只刺刺22生命，棘尾16，保留72.7%，是首阶段最低的生命保留率。
- 被动单次反伤从2提高到3，但失去一个前排单位与一个控制指令位。
- 前三结算HP输出25.11→25.06，基本不变；通过率仍下降10.8个百分点，不能仅看伤害认定升级已经足够。
- 进阶精英样本75%→10%，其余普通四类场景仍均通过。

**判断：**优先复核前排有效生命、削弱/嘲讽覆盖与保护队友的收益。棘尾可以保持“控制反伤”定位，不必补成通用高伤攻击手。

## 五、不能按旧自动玩家误判的阶段

### 铁卫→铁壁神

满血无替补：原贪心55.8%→41.7%，但前瞻66.7%→90.0%。原贪心几乎只使用钢刺；前瞻会使用铁壁双击、铁壁领域等技能。前三结算获盾由两铁卫的8.72提高到铁壁神队伍27.68。

**结论：已有可兑现的机制提升，不建议当前直接加强。**先改善常规模拟器对护盾、多段和群体收益的识别，再用五人阵容和其他敌人复测。获盾量不是实际吸收量，不能据此断言防御恰好提升三倍。

### 迅牙→迅天、灼刃→灼天

满血无替补，原贪心分别下降13.3与14.2个百分点，但前瞻分别上升2.5与0.8个百分点。先手、条件连击与速度/灼烧机制会影响选择，单段伤害排序不能充分发挥。

迅天入场速度由迅牙7变为6，但它有先手技能与攻击后速度成长，不能只据初始速度下降判断三阶更弱。目前没有充分依据给它们统一提高基础属性。

### 蟒影→深渊蛇王

默认前瞻满血无替补69.2%，低于不融合73.3%；强制毒雾起手可提高到75.8%，超过该对照约2.5个百分点。与蟒影阶段不同，最终形态对启动方式更敏感。应先复核施毒与爆发序列，不宜直接归类为“必须数值加强”。

## 六、受伤组与一次性回血

| 进化 | 满血无替补相对差值 | 受伤无替补相对差值 |
| --- | ---: | ---: |
| 泡泡→泡泡将 | -15.0pp | 0.0pp |
| 铁墩→铁卫 | +3.3pp | +18.3pp |
| 刺刺→棘尾 | -10.8pp | +13.3pp |
| 棘尾→棘刺王 | -1.7pp | +8.3pp |
| 泡泡将→泡泡龙神 | -3.3pp | -5.8pp |

受伤组并不一律更适合融合。它包含进化回满生命这项真实收益，但不能用来证明长期战力一定提升；例如刺刺在满血时亏、受伤时获益，可能更像一次治疗与阵容压缩决策。

泡泡将→泡泡龙神两个健康条件下均有小幅下降，需要继续观察；样本尚不足以决定具体加强。泡泡龙神加入更多队友后，群体治疗/水幕的价值可能不同，当前三人对照尚未覆盖。

## 七、建议处理顺序

1. **优先做针对性候选验证：**泡泡将的续航预算、蟒影的毒源启动、棘尾的承伤/控制覆盖。一次只改变一个维度，不直接同时提高面板和技能。
2. **先校正策略再判断三阶：**铁壁神、迅天、灼天，以及深渊蛇王的毒序列。保留旧策略作对照，避免自动玩家改进掩盖游戏数据变化。
3. **补充阵容与决策边界：**五人满编；外部毒源、治疗与护盾协作；不融合但换上替补的最优布阵；不同站位与速度阈值。
4. **再做难度与整局验证：**困难/地狱、材料获取节奏和战后续航。删除行动点或加入祝福后应重新评估，不能沿用本报告的数值结论。

本报告没有实施任何宠物或敌方数值调整；上述方向仍是下一轮待验证的建议。
