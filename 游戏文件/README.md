## 维护规则

1. 属性／被动修改同步生物图鉴，技能修改同步技能图鉴和统一强化表；不要再分“强化表2／第三批”维护同一技能。
2. 地图与完整遭遇只维护投放文档，事件选项只维护关卡图鉴，造物与蛋生复杂交互放特殊机制；其他文件使用链接。
3. 已实现、待设计和已知实现差异分开标注。远征祝福、林地第三幕专属首领、体系专属动画仍未完成，不能因整理而视为实施。
4. 历史测试次数、旧APK哈希、旧版本的“不提交／未打包”指令不是现行规则；新的验收报告应记录本次代码版本及实际结果。真机待验仍如实保留。
5. 基础属性与被动入场加成分别说明，不把图鉴基础速度、最终战斗速度和敌方难度速度混为一值。旧存档不因文档更新重抽。
