# 技能强化表

> 熟练度远征模式专属系统。每个技能最多强化 3 次（连击/速度类最多 2 次），消耗成长点获得永久加成。

## 一、强化规则

| 技能类型 | 强化效果 | 每级加成 |
| :--- | :--- | :--- |
| 攻击技能（`kind: 'attack'`） | 伤害 +2 | +2 伤害 |
| 连击技能（`hits ≥ 2`） | 段数 +1 | +1 段（最多 2 次） |
| 治疗技能（`kind: 'heal'`） | 治疗量 +2 | +2 治疗 |
| Buff 技能（`kind: 'buff'`） | 效果值 +1 | +1 效果值 |
| 状态技能（`kind: 'status'`） | 效果值 +1 | +1 效果值 |

> **连击优先**：若技能同时满足「攻击」和「连击（hits ≥ 2）」，按连击规则处理（段数 +1 而非伤害 +2）。连击技能最多强化 2 次。

### 强化上限与绑定

- 强化绑定在**宠物 + 技能槽位**上
- 替换技能后，原技能的强化消失，新技能从 0 开始
- 传奇技能可强化，但消耗 ×1.5（向上取整）

### 强化重置

- 通过道具「还原石」重置某个技能的强化
- 重置后返还累计消耗的 **50%**（向上取整）
- 示例：+3 级累计消耗 30 点 → 返还 15 点

### 消耗表

| 强化等级 | 消耗 | 累计消耗 | 攻击/治疗加成 | Buff/状态加成 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 8 点 | 8 点 | +2 | +1 |
| 2 | 10 点 | 18 点 | +4 | +2 |
| 3 | 12 点 | 30 点 | +6 | +3 |

> **传奇技能消耗**：传奇技能消耗 ×1.5（向上取整），即 12/15/18 点。

### 强化预览

玩家在强化前可看到以下预览信息：

```
┌─────────────────────────────────────┐
│ 强化：爪击（当前 +1）               │
├─────────────────────────────────────┤
│ 当前：7 伤害                        │
│ 强化后：9 伤害                      │
│ 消耗：10 成长点                     │
│ 剩余成长点：12                      │
│ 【 确认 】  【 取消 】               │
└─────────────────────────────────────┘
```
