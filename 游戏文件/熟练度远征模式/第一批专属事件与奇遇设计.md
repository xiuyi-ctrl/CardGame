# 熟练度远征：第一批专属事件与奇遇设计

设计与实施日期：2026-10-29。第一批已接入运行代码、独立测试入口及手机横屏界面。

## 设计范围与确认边界

第一批为4个普通事件、3个奇遇奖励。重点是培养分工、技能纠错、成长点调配和技能突破，不新增货币、遗物或战斗被动体系。

已按用户要求确定：大师传承指定伙伴、指定技能，免费强化一级，可以突破常规强化上限，最高＋4。完整158项技能设计值见[大师传承突破强化表](大师传承突破强化表.md)。

本方案的费用、数值、投放限制及固定机制技能排除已实施，后续仍需真人试玩验证平衡。主模式不投放，熟练度队伍上限5、出战上限3不变。

## 普通事件一：分岔训练场

背景：两条训练路线分别通向独行试炼与双人协作场。

| 选项 | 效果 | 条件 |
| --- | --- | --- |
| 集中训练 | 指定1只存活伙伴，获得3成长点 | 有存活伙伴 |
| 双人训练 | 指定2只不同的存活伙伴，各获得2成长点 | 至少2只存活伙伴 |
| 离开 | 无事发生 | 始终可用 |

两种方案都是一次性获得奖励，不能先领取其中一项再返回领取另一项。双人训练不允许同一伙伴领取两份；不足两只时禁用并显示原因。

目的：集中补足核心技能升级费用，或者培养第二位战术支点；不是简单比较全队人数后永远选择收益更高的选项。

## 普通事件二：遗忘书屋

背景：书屋愿意收走一段旧记忆，换来新的战斗经验。

| 选项 | 效果 | 条件 |
| --- | --- | --- |
| 重新学习 | 支付20金币，指定伙伴及一个旧技能，从3个合法新技能中选1个替换 | 金币足够，存在合法替换 |
| 整理心得 | 指定1只存活伙伴，获得1成长点 | 有存活伙伴 |
| 离开 | 无事发生 | 始终可用 |

- 新技能沿用当前普通学习池，不引入传奇技能、不可学习机制技能或额外技能槽。
- 按技能ID去重，不出现该伙伴已经持有的技能；不足3种时展示实际数量，不重复补齐。
- 先展示旧技能及强化损失，再确认新技能；最终确认时才扣20金币。
- 替换不继承旧技能的强化。原强化及实际支出记录清除，不自动退款；原技能为传承＋4时必须明确显示损失。
- 同一事件、同一伙伴和技能槽的候选首次生成后固定；返回、更换查看对象和读档不重抽同一组候选。
- 不设置额外付费刷新；取消预览可回事件，不能领取奖励后回退。

目的：提供比常规替换更便宜的金币纠错渠道，同时保留拆解旧强化再换技能的取舍。

## 普通事件三：共鸣水晶

背景：水晶能够短暂连接两位伙伴的成长记忆。

| 选项 | 效果 | 条件 |
| --- | --- | --- |
| 连接伙伴 | 指定来源与接收者，转移1～6成长点，本次不收手续费 | 两只不同存活伙伴，来源至少1点 |
| 吸收水晶 | 指定1只存活伙伴，获得2成长点 | 有存活伙伴 |
| 离开 | 无事发生 | 始终可用 |

- 转移量为整数，不超过来源持有点数，来源扣多少、接收者获得多少。
- 确认前显示来源与接收者的前后点数，不占用常规转移的余额，也不改变其他界面的50%手续费规则。
- 一次事件只能完成一次转移；不能通过来回转移重复获得奖励。
- 先完成选择再确认，取消不扣点；领取后不允许切换到吸收水晶。

目的：将闲置点数集中到技能即将升级的伙伴，或者为后来加入的伙伴补足学习费用。

## 普通事件四：拆解工坊

背景：工坊可以回收技能训练投入，也出售一枚现成的强化石。

| 选项 | 效果 | 条件 |
| --- | --- | --- |
| 回收强化 | 指定伙伴的1个已强化技能，清除该技能全部强化，返还实际支付强化费用的100% | 有真实付费投入且可完整确认费用 |
| 购买强化石 | 支付30金币，获得1颗普通技能强化石，存入背包 | 金币足够 |
| 离开 | 无事发生 | 始终可用 |

- 回收只处理一个技能，不重置伙伴的生命、速度、其他技能或技能槽。
- 确认前显示技能等级变化、实际返还点数及传承等级是否会丢失。
- 大师传承等免费强化不产生返还费用。付费＋2后两次传承到＋4，回收时清除到＋0，只退原两次付费投入。
- 原还原石仍只返还50%，本事件不修改它的常规规则。
- 买到的强化石遵守常规＋2／＋3上限，不能借此继续提高突破后的技能。
- 点击购买后直接扣款、将强化石存入背包、返回地图并弹窗提示。回收强化保留选宠与选技能确认，完成后直接返回地图，弹窗提示返还点数，不进入成长点使用界面。
- 旧存档无法确认付费成本时，不凭等级推算退款；显示不可回收原因，保留购买与离开选项。

目的：让换打法具有可控成本，同时防止“免费强化→回收”制造成长点。

## 奇遇一：大师传承

奖励文案：指定一名伙伴的一个技能免费强化一级，可突破常规上限，最高＋4。

1. 选择存活伙伴。
2. 展示其可强化技能；每项显示当前等级、下一等级及实际变化。
3. 指定技能并确认，等级＋1，成长点不变，费用记录不增加。

| 当前等级 | 领取结果 |
| --- | --- |
| ＋0 | ＋1 |
| ＋1 | ＋2 |
| ＋2 | ＋3，即使原常规上限为＋2 |
| ＋3 | ＋4 |
| ＋4 | 不可再选择 |

- 不直接把低级技能升到＋4；不增加技能冷却、次数、持续时间、目标数或资源倍率。
- 选择前不依赖成长点余额；没有技能槽位变化，不要求额外空槽。
- 普通强化上限不变，敌人自动强化不增加四级。
- 固定机制／没有有效增益的技能建议不投放，完整排除项及理由见突破表。
- 建议16层起可出现，单局最多领取2次。两次可用于同一技能，使常规上限＋2的技能达到＋4；该限制为待验证的投放参数。
- 抽到奖励后，选择目标期间不再投骰；存取档保留已选伙伴、技能候选和是否领取，确认后不可二次领取。

目的：让一项核心技能成为本局的显著优势。重点观察连击、多段群攻和攻击被动叠加，先不为＋4额外增加新的战斗特效或触发机制。

## 奇遇二：成长之泉

奖励文案：集中培养一位伙伴，或让两位伙伴共同成长。

| 分支 | 效果 |
| --- | --- |
| 独享泉水 | 指定1只存活伙伴获得8成长点 |
| 分享泉水 | 指定2只不同存活伙伴，各获得5成长点 |

只有一位存活伙伴时仅允许独享；两种分支都没有额外金币费用。成长点发放后进入成长使用页，关闭详情或重新选择对象不重复发放。

目的：8点可支付普通技能第一次强化，双人合计10点更高，但不能全部压给同一核心。

## 奇遇三：空白契约

奖励文案：指定伙伴免费解锁下一个技能槽，并为该槽学习一个技能。

- 合法对象：有下一个可解锁技能槽、且普通技能池存在候选的存活伙伴。
- 仅解锁一个槽，依次为第3／4／5槽，不增加第6槽，不替换已有技能。
- 目标确认后展示去重的正常技能三选一，不给出同一技能的重复候选；不足3种展示实际数量。
- 不提前揭示随机技能。候选生成后保存，读档不重抽。
- 选择技能后，解锁与学习一次性完成；免费获得的技能为＋0，不继承其他槽强化。
- 候选页面可查看技能详情，领取后不能返回奇遇改选奖励；异常情况下没有合法候选不得消耗本次奖励。
- 全员已满技能槽或没有合法候选时，奇遇生成不抽取该奖励。

目的：扩展一位伙伴的战术手段，区别于直接加点或替换旧技能。

## 界面与交互

- 手机横屏一屏优先：选项、费用和风险先显示，背景故事简短；完整技能说明按需展开。
- 伙伴使用可点击头像卡片，不使用伙伴下拉框；大师传承以技能卡片选择。
- 大师传承预览显示“迅针＋2 → ＋3，3×5 → 3×6”，而不是仅显示“强化成功”。
- 返还、转移和强化的最终确认区固定可见，触控区域至少44px，正文不少于12px。
- 随机候选首次揭晓后保持固定，返回查看不重抽；领取确认只结算一次。

## 验证重点

- ＋2常规封顶的技能能经传承到＋3、＋4；其他来源仍不能突破；＋4不再领取。
- 表中158项无遗漏，固定机制技能不提供空强化；普通学习池不因为登记首领技能而扩大。
- 连击按段伤害、群攻按目标数与段数核算，控制时长和状态上限不随数字错误扩大。
- 免费传承不退款；付费投入只退一次；转移手续费仅本事件免除。
- 单伙伴、满队5只、零金币、零成长点、技能槽已满、技能满级、死亡伙伴及旧档缺失成本记录均可处理。
- 事件候选、奇遇候选和技能候选读档不重抽；预览、取消、最终确认不会重复发放。
- 比较同种子大师传承领取前后胜率、战斗回合、核心技能使用率及第30／50层损失，数值不只按面板判定。
