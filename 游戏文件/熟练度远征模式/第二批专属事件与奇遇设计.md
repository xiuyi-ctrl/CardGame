# 熟练度远征：第二批专属事件与奇遇设计

设计与实施日期：2026-10-29。第二批已接入代码、独立测试入口及横屏界面。下列数值为已实施的首版参数，后续仍需真人试玩验证。

第一批见[第一批专属事件与奇遇设计](第一批专属事件与奇遇设计.md)。第二批改造剩余6个旧事件及3个旧奇遇，完成后仍为10个事件、6种奇遇奖励。仅用于熟练度模式，队伍上限5、出战上限3、普通强化上限及大师传承规则不变。

## 一、设计方向

第一批解决加点、技能纠错、点数转移和突破；第二批补足实战培养、物资选择、后加入伙伴与死亡后的恢复。

- 不新增货币、天气、长期任务或独立战斗规则。
- 挑战使用当前层段的敌人属性与技能成长，不另外叠加伤害或生命倍率。
- 单体挑战避免纯治疗、纯支援生物单独出现；群体挑战采用具有前排、输出或状态配合的合法组合。
- 普通事件偏一次小收益与付费选择，奇遇承担传奇技能、整备工具和完整复活。
- 下列数值是首版建议，不能用第一批自动玩家结果直接认定平衡。

## 二、普通事件一：实战教官

替换 `battle_master`「战斗大师」。

背景：教官要求一位伙伴独立完成实战考核。

| 选项 | 效果 |
| --- | --- |
| 单人考核 | 指定1只存活伙伴，以当前生命独自挑战1名对手；胜利后该伙伴获得6成长点 |
| 离开 | 无事发生 |

规则：

- 确认前显示敌人、技能及参战伙伴，允许退出选择；确认开战后遵守正常战斗关闭规则。
- 对手先按当前层普通战整队模板抽取最高品阶，再从该品阶合法单体池中等概率选一名；不复制整队人数。首领后不跳档，传奇从32层起逐步加入，具体概率见[熟练度肉鸽模式](熟练度肉鸽模式.md)。排除首领、小怪、蛋生专属与纯支援单体；煤煤、刺刺及其进化仍可进入。
- 敌人照常使用当前层数的普通敌人属性、技能替换与强化规则，不额外提高倍率或叠加精英强化。事件生成后候选固定，取消、重开及读档不重抽，预览与实战一致；旧事件已存候选保留。
- 胜利奖励仅为6成长点，不再叠加普通战的参与、存活和击杀成长点，也不额外发金币。
- 伙伴阵亡按真实阵亡处理。考核失败后若仍有其他伙伴存活，返回地图继续远征；仅全队无存活伙伴时结束远征，不另扣金币或全队生命。开战按钮附近明确写出失败后果。选项描述为「指定1只伙伴单独战斗，胜利获得6成长点」。
- 战斗后的恢复沿用当前熟练度真实战斗规则，不额外提供免费满血。

区别：以单个伙伴承担风险换取集中培养，不再提供与分岔训练场重复的免费加点选项。

## 三、普通事件二：潜能祭坛

替换 `mysterious_altar`「神秘祭坛」。

| 选项 | 效果 |
| --- | --- |
| 淬炼体魄 | 30金币，指定伙伴执行一次生命成长：最大生命＋2 |
| 磨炼身法 | 30金币，指定伙伴执行一次速度成长：速度＋1 |
| 离开 | 无事发生 |

规则：

- 不消耗成长点；两条分支合计只能选一次。
- 计入原有属性成长上限：生命成长总计最多＋30，速度成长总计最多＋15；不另外开一套超上限属性。
- 生命成长时，当前生命同步＋2，仍不超过新上限；不是额外治疗或满血。
- 选满该属性的伙伴不可确认；全员该属性封顶或金币不足时对应选项禁用并说明原因。
- 必须记录该次属性成长实际支付的成长点为0。遗忘之石或其他重置流程不得根据属性档数推算出成长点退款；金币支出不转换成可退款成长点。
- 需先核对并补齐属性成长退款的来源记录，再开放该事件；不能只增加属性而留下退款漏洞。不能确认的旧投入也不得凭空补造。

区别：消耗金币补足一个关键属性档位，取代原来的免费概率加点与付费加点重复选项。

## 四、普通事件三：行脚补给站

替换 `expedition_supply`「远征补给」。

| 选项 | 效果 |
| --- | --- |
| 领取疗伤补给 | 治疗圣水×1，放入背包 |
| 领取训练补给 | 成长之书（中）×1，放入背包 |
| 离开 | 无事发生 |

- 两种物资免费二选一，只结算一次。
- 点击领取后直接存入背包、返回地图并弹窗提示获得的物品，不经过二次确认或成长点使用界面。
- 必须使用熟练度道具ID：治疗圣水 `heal_potion_g`、中型成长之书 `book_medium`；不能误发主模式治疗道具或捕捉食物。
- 不立即指定伙伴、不立即消耗道具，保留晚些时候使用的选择。
- 圣水沿用全队恢复50%生命，中书沿用指定伙伴＋2成长点。
- 不再额外提供固定金币选项。

区别：选择当前续航还是可储存的成长资源。

## 五、普通事件四：同行契约

替换 `pet_recruit`「生物招募」。

| 选项 | 效果 |
| --- | --- |
| 查看同行伙伴 | 展示两位不同物种的候选，选择1位加入；新伙伴附带入队成长点 |
| 换取旅费 | 获得15金币 |
| 离开 | 无事发生 |

候选沿用当前层段普通生物的解锁品阶与物种范围，不根据已有阵容加权，不引入首领、小怪、蛋生专属和造物。普通池开放传奇后，本事件才允许相应传奇进入候选；不额外提高传奇权重。

| 当前层数 | 新伙伴携带成长点 |
| --- | --- |
| 1～15 | 4 |
| 16～30 | 8 |
| 31～50 | 12 |

- 新伙伴满血、技能为本形态固定技能组、强化＋0；不获得敌方层数属性膨胀及敌方自动技能强化。
- 附带成长点属于该伙伴，可正常使用或按原规则转移，不再另发成长之书。
- 打开候选后仍可取消回到本事件；两位候选及其点数固定，取消或读档不重抽。最终确认伙伴后锁定该事件奖励。
- 候选不足2个不同物种时展示实际数量，不重复填满。
- 满队伍仍能领取，随后进入新伙伴处理界面，不自动覆盖、融合或放生任何伙伴。
- 手机候选页保留姓名、立绘、生命、速度和成长点；技能与被动通过详情查看，不放入下一形态或融合信息。

区别：降低中后段招到新伙伴却无法培养的问题，同时保留继续使用原阵容并拿旅费的选择。

## 六、普通事件五：协同试炼

替换 `arena_challenge`「训练场挑战」。

| 选项 | 效果 |
| --- | --- |
| 接受试炼 | 挑战当前层段的协作敌队；胜利后实际出战且存活的伙伴各获得3成长点，并获得20金币 |
| 离开 | 无事发生 |

- 按当前精英整队模板生成；不足两名时补一只一阶进攻／反伤伙伴，总计2～3名，不在16层突然追加第三人。具体层段表见[熟练度肉鸽模式](熟练度肉鸽模式.md)。
- 按该层段已解锁品阶构建合法组合：前排承伤＋输出、施毒＋中毒承接、灼烧施加＋灼烧承接、护盾支援＋输出等。
- 不强行要求每场都有治疗，也不允许多只纯支援组成没有进攻手段的队伍。
- 难度使用当前层段正常精英生成规则，避免精英加成重复计算；不额外加一层“较强”倍率。
- 我方照常布阵，最多3只出战；候补不领取出战奖励，阵亡伙伴不领存活奖励。
- 不重复发放普通战的参与、存活、击杀成长点。20金币属于本次战斗胜利收入，只计一次。
- 阵亡、失败和胜利后的恢复沿用正常熟练度真实战斗规则，失败结束远征，不追加随机处罚。
- 点击「接受试炼」直接进入布阵，不再经过中间确认页；可取消布阵返回事件。

区别：培养多位上场伙伴，与实战教官的单人集中培养形成选择。

## 七、普通事件六：回响墓园

替换 `revive_dead`「灵魂墓园」。建议取消原先“复活后永久只保留50%基础属性”的处理，用当前生命区分复活强度。

| 选项 | 效果 |
| --- | --- |
| 唤回伙伴 | 免费指定1只死亡伙伴复活，恢复至最大生命50%，向上取整 |
| 离开 | 无事发生 |

- 保留死亡快照中的原最大生命、速度、属性成长、技能槽、技能、强化、实际付费记录及未使用成长点。
- 不复制另一只伙伴的状态，不重新抽取技能，不借复活改变物种或进化路线。
- 清除战斗临时状态、护盾、技能冷却和场内次数消耗；保留原有永久诅咒，不额外提供净化。
- 无死亡伙伴时不进入自然事件池；满员时允许选择，进入处理队伍界面。
- 最终领取时将该伙伴从墓地移出。旧墓地快照缺失的数据不补造，能恢复多少以真实快照为准。
- 既有阵亡统计不回退；同一墓地记录不能被重复领取。复活后再次真实阵亡才重新生成墓地记录。
- 保留现有复活石规则；本批不顺带修改商店复活石的属性保留比例。

区别：提供一次恢复养成伙伴的机会，半血入队仍需要后续整备；稀有奇遇承担更完整的恢复。

## 八、奇遇一：传奇秘典

替换 `legend_recruit`「传奇招募」。原名称容易被误解成领取传奇生物。

效果：指定伙伴，从3个不重复的合法传奇技能中选择1个学习，免费。

- 使用现有传奇学习池，不包含首领召唤、碎岩重组及不可学习机制技能。
- 排除该伙伴已经持有的技能，不足3种时展示实际数量。
- 有已解锁空技能槽时放入该槽；否则指定1个旧技能替换。不自动解锁第6槽，也不附送槽位解锁。
- 新技能强化为＋0，不继承旧技能强化；替换前显示将清除的等级与实际投入，不自动退款。
- 候选按节点与伙伴固定，返回、切换查看及读档不重抽；最终确认才替换并领取。
- 无合法伙伴或候选时不进入本次奇遇候选。

区别：改变技能组合，而大师传承强化的是已经持有的技能。

## 九、奇遇二：匠师工具箱

替换 `gold_treasure`「金币宝藏」。

效果：获得普通技能强化石×1、还原石×1，均放入背包。

- 使用熟练度道具 `skill_enhance_stone`、`reset_stone`，不发放第四级专用强化道具。
- 强化石遵守常规上限，不能继续强化已突破常规上限的技能。
- 还原石仍只退实际支付成长点的50%，向上取整；免费强化不产生退款。
- 当全队既没有可普通强化技能、也没有可还原的已强化技能时，过滤此奖励；有任一用途即可保留。
- 一次发放两件工具，不再额外送80金币。玩家可暂存后使用。

区别：提供调整培养路线的物资，替代单纯大额金币奖励，不与成长之泉重复直接发点。

## 十、奇遇三：返魂之泉

替换 `revive`「生命之泉」。

效果：指定1只死亡伙伴完整复活并回满生命；其他存活伙伴恢复各自最大生命的25%，向上取整。

- 复活伙伴的永久数据保留规则与回响墓园一致，当前生命恢复至最大值。
- 其他伙伴的恢复不能超过最大生命，不增加最大生命，不清除永久诅咒。
- 无死亡伙伴时不进入奇遇池，不能单独选择全队治疗部分。
- 满员时先锁定本次奖励并进入处理界面；其他存活伙伴的25%恢复只结算一次，不因反复查看或处理新伙伴重复发放。
- 墓地移除、阵亡记录和防重复领取规则与回响墓园一致。

区别：比普通墓园多出完整血量和队伍恢复，承担稀有的战损修复价值。

## 十二、执行顺序与验收（已实施）

1. **先堵退款与重复奖励**：核对属性成长真实投入记录、技能实际投入记录、墓地快照及事件战斗成长点发放；给免费属性档位、双倍奖励和重复复活写回归用例。
2. **接入补给、祭坛与工具箱**：确认金币仅最终确认扣除，道具进入正确模式背包，普通上限及退款口径不变。
3. **接入同行契约**：候选固定、两位不同物种、分层成长点、满队处理及旧档不重抽。
4. **接入两种挑战**：按层段生成对手，验证1人出战、2／3敌人组合、阵亡失败、胜利收入与成长点只结算一次。
5. **接入复活及传奇秘典**：逐字段验证养成保留、墓地移除、技能替换损失、满员流程和不可重复领取。
6. **接入投放和测试入口**：保留标识、更新名称；测试能够指定全部第二批事件和奇遇，覆盖零金币、属性封顶、无死亡伙伴、满队及无传奇技能候选。
7. **界面及整局回归**：手机六种横屏尺寸与桌面实际截图；伙伴、技能使用卡片选择，确认固定，详情独立查看。执行完整测试、类型检查、构建及同种子模拟后再生成测试APK。未经另行要求不提交或发布。

评估分别记录挑战的选择率／胜率／阵亡、事件新增伙伴的出战率、复活后再次阵亡率，以及第15／30／50层到达与失败分布。免费复活能否过度抵消阵亡风险、同行成长点能否缩短新旧伙伴差距、传奇秘典是否压过大师传承，均需验证，不在接入同一步自动改敌方倍率。

实现约定：属性投入按 `statGrowthPaid` 保存，旧档未知投入不补造；技能投入继续按 `skillEnhancePaid` 保存。新试炼以独立标记进入真实阵亡／限定奖励结算，旧事件战斗保留原处理。协同布阵恢复上次位置，失效位置留空，布阵阶段可返回事件；确认开战后本节点不可再领取其他分支。

回归发现并修复两项关联问题：进入熟练度节点时按实际地图行同步层数，避免事件离开后投放与敌人强化沿用偏低层段；自动玩家满队时跳过不可购买的招募，避免反复购买形成循环。
