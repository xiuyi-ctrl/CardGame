# 界面音效第一版试听稿

日期：2026-10-31。原创程序合成样本，现已接入游戏界面；运行规则见[界面音效说明](../../../游戏文件/界面音效说明.md)。本文件夹保留独立试听页与原始音频。

方向：像素冒险的小巧操作反馈，短、轻、易分辨；用少量谐波保留像素感，避免尖锐方波和长尾混响。最终听感以实际试听为准。

打开 `index.html` 单独比较，也可直接播放 `ui_preview_sequence.wav`，顺序如下。

| 音效 | 文件 | 时长 | 建议用途与触发时机 |
| --- | --- | --- | --- |
| 轻点 | ui_click.wav | 65毫秒 | 普通按钮有效点击。按下时不发声，确认点击成立后播放，避免手机拖动误触发。 |
| 确认 | ui_confirm.wav | 240毫秒 | 开始远征、确认领取、保存成功等明确执行结果；同次操作用确认声替代轻点，不叠加。 |
| 返回 | ui_back.wav | 180毫秒 | 返回上一页、关闭弹窗；取消或关闭只发一次。 |
| 切换 | ui_select.wav | 75毫秒 | 切换地区、难度、页签、选择伙伴；只有选择实际改变时播放，不在鼠标悬停时播放。 |
| 不可用 | ui_unavailable.wav | 210毫秒 | 实际尝试但条件不满足时提示；长按或重复触碰不连发。原生禁用按钮不为了声音改变交互。 |

建议后续接入规则：同一次操作只播放一种界面音效；轻点和切换间隔至少60毫秒，不可用提示至少250毫秒；隐藏后台后停止播放。音量设置与游戏内静音规则单独设计，此页滑块只控制试听，不保存设置。

导出：48,000Hz、16-bit PCM、单声道 WAV，最长240毫秒，无长尾、无循环。各文件保留峰值余量；试听页默认音量65%，不是最终游戏混音值。手机扬声器实机听感尚待确认。

`generate.py` 使用Python标准库确定性生成原始合成样本与 `manifest.json`，无需下载第三方素材。它只写入本文件夹，运行方式：`python design/audio/ui-sfx-v1/generate.py`。

试听页为独立设计稿，音量滑块不影响游戏设置。运行副本位于 `src/ui/assets/audio/ui/`，素材副本位于 `美术素材/audio/ui-sfx-v1/`。
