# 三只生物像素统一对照

日期：2026-10-26。对象：迅迅、咪咪、煤煤。

三只统一样例已按用户要求接入运行素材，各生物清晰原稿保留。迅迅同步01.png、battle-momo.png、home-xunxun.png，咪咪同步06.png、starter-mimi.png，煤煤同步coal.png；沿用旧路径并同步美术素材副本。三只统一直接显示64像素图片、最近邻放大、无额外投影。

## 发现与处理

- 运行时混用了64像素画布及高分辨率原稿直显，额外投影也不同。
- 迅迅战斗页的 battle-momo.png 仍为旧棕色形象，首页 home-xunxun.png 则为已确认的青绿色像素形象；统一样例采用青绿色版本。
- 迅迅首页图为64×64，但包含1506种非透明颜色、187档透明度；规范版咪咪、煤煤已有硬透明边缘和23／24种颜色。
- 样例将迅迅使用现有导出工具统一为64×64、最多24色、透明度0／255；咪咪、煤煤采用已有规范导出。
- 三只主体最长边56像素、底部y=59；最近邻放大，无额外黑色投影，由素材自身的深色轮廓承担描边。
- 不把三只强行调成相同色相。保留迅迅明亮青绿、咪咪墨绿紫纹、煤煤灰黑暖白的物种配色。

## 查看方式

- 直接打开 index.html，切换浅色底／森林底查看对照。
- tools/mobile-layout/CreatureStylePreview.tsx 提供真实 UnitCard 战场卡片、布阵卡片对照，可通过项目渲染检查工具的 creature-style-compare、creature-style-battle、creature-style-formation 场景查看。
- assets/ 保存三只规范样例，xunxun/ 保留迅迅处理输入、导出和QC，baseline/ 保存改动前资源供静态对照。原有对照截图保留为本次接入依据；实际卡片预览会随当前运行代码更新。后续可按相同标准分批接入其他生物。

本轮验收：三张样例均为64×64、透明度0／255、底部y=59，非透明颜色分别为22、23、24色。类型检查通过；手机18组、桌面9组实际渲染检查覆盖浅色底、真实战场卡片及布阵卡片，未出现遮挡或横向溢出。
