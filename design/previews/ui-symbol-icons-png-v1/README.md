# 通用操作与提示图标 PNG · 第六批

`icons/` 内为 16 张独立的 128 × 128 透明 PNG，已接入通用图标目录和预加载。15 张用于现有界面，暂停图保留为预留素材，因为当前没有暂停功能。运行时副本在 `public/ui-symbol-icons/`，交接副本在 `美术素材/ui-symbol-icons/`；`index.html` 展示 16、24、32 和 64 像素下的效果。

| 文件 | 预定替换位置 |
| --- | --- |
| lock.png | 难度锁、遗物锁 |
| none.png | 不携带遗物的禁止符 |
| arrow-left.png | 返回、融合方向提示 |
| arrow-right.png | 下一步、继续前进、进化方向提示 |
| arrow-up.png | 战斗记录展开 |
| arrow-down.png | 战斗记录收起 |
| close.png | 弹窗关闭、取消选择、删除存档 |
| pause.png | 预留暂停图，当前不增加暂停按钮 |
| play.png | 继续、确认选择 |
| plus.png | 出战顺序空位等添加入口 |
| sparkle.png | 选宠技能标识、空位与说明装饰 |
| step-active.png | 当前步骤的橙金菱形 |
| step-inactive.png | 未激活步骤的灰白菱形 |
| marker-info.png | 普通提示与小菱形装饰 |
| warning.png | 警告提示 |
| error.png | 错误提示 |

以项目既有像素 PNG 为风格参考，使用内置 imagegen 生成四组 2 × 2 原稿，再用 generate2dsprite 进行品红去底、切图、居中和透明导出。保留深海军蓝阶梯描边、奶油色高光，操作用橙金色，辅助标记用青色，警告和错误用黄与红。提示词规格见 `prompts.md`。

原稿、透明图集、单图和处理元数据保留在 `status/`、`arrows/`、`controls/`、`steps/`。这批不包含边框、分隔线、选中角标或正文中的数学符号。

导出检查：16 张图均无空帧、源图边缘碰撞、输出边缘碰撞或粘贴截断；四组透明图集已逐组检查。

接入包含锁定状态、导航、弹窗关闭、战斗记录展开与收起、动画倍速和跳过、空槽添加、选宠装饰、步骤标记、图鉴分组及提示消息。所有通用 PNG 在界面准备阶段统一预加载；交互动作、焦点和关闭规则保持原样。
