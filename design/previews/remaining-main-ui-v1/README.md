## 接入说明

布局入口为 src/ui/App.tsx 和 src/ui/GauntletOrderScreen.tsx，独立样式为 src/ui/remainingMain.css，共用展示组件为 MainFlowArt.tsx。复用 main-flow-art 中无字林地、祭坛和营地背景，未从整页稿裁切背景；开箱与望远镜采用现有像素 SVG 体系制作独立图标，位于 src/ui/assets，并同步美术素材合集。

普通队伍管理只改 specialPending 为空且非 postBattle 的入口，原有特殊选人分支及出战人数判定保持不变；资料随悬停或聚焦变化，卡片点击仍切换出战。宝箱显示 chestResult 的完整结果，按原文本中的顿号拆成展示卡片，不重新抽取或发放奖励。瞭望塔仍调用 nodeInfo，修正零基行号的层数显示为行号+1，情报卡不可点击。车轮战沿用原来的点击、拖拽、槽位数与确认动作；按钮支持键盘点击。

小窗口隐藏滚动条，情报、奖励结果和资料内容区按需滚动，不裁切长文字或覆盖操作按钮。图片已加入界面预加载。
