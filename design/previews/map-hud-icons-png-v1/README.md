# 地图 HUD 图标 PNG · 第三批

7 张独立透明 PNG，均为 128 × 128。已接入地图顶部信息与操作按钮，以及当前位置旗标。运行时副本位于 `public/map-hud-icons/`，合集副本位于 `美术素材/map-hud-icons/`。

| 文件 | 用途 | 识别点 |
| --- | --- | --- |
| route.png | 路线 / 层数 | 带路径与标记的折叠地图 |
| party.png | 出战队伍 | 青绿爪印 |
| gold.png | 金币 | 金币堆 |
| skip.png | 跳过节点 | 双箭头与加速光点 |
| bag.png | 背包 | 青蓝旅行背包 |
| home.png | 返回首页 | 蓝顶小屋 |
| flag.png | 当前位置 | 橙金旗帜 |

原稿由内置 imagegen 生成。提示词以第二批节点图标为风格参考：深海军蓝阶梯像素描边、青绿与橙金强调色、高对比、单一主体、无文字；`core/` 为四图 2 × 2 图集，`bag/`、`home/`、`flag/` 为单图。以 `generate2dsprite` 去除纯品红背景、居中切图并检查空图及导出边缘。`index.html` 提供接近运行时尺寸的预览。
