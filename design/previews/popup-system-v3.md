# 弹窗美术 v3：像素远征终端

以已确认的覆盖存档、捕获食物、技能强化三张设计稿为视觉参考。预览中的数字仅用于排版，运行时仍读取实际游戏状态，不把整张设计稿作为弹窗背景。

## 统一视觉

- 奶油色纸面 `#fff9e9`、深墨色 `#101c2c`、灰绿内边 `#8a979b`、橙金角饰、硬边阴影。
- `src/ui/assets/popup-terminal-frame.svg` 以九宫格伸缩绘制阶梯框；顶部橙色扣片用 CSS 绘制，内容不随边框拉伸。
- 标题使用现有像素字体；正文和按钮使用系统字体。标题复用首页档案、爪印、地图、战斗捕获及道具图标，成长类使用独立像素铁砧。
- 主操作橙色，危险确认暗红，取消灰白；警告独立为浅红提示条。无持续动画、模糊和发光。

## 覆盖入口

确认/融合/释放/替换、删除/覆盖存档、熟练度继续、侦查/孵化、捕获食物/战斗道具、敌我生物与 Buff 详情、强化/还原/成长点转移、胜负结算、存档管理均沿用同一骨架。

强化的当前效果与强化后效果并排展示，小窗口改为上下排列；库存为零的食物保持可读的灰色禁用态。长内容只滚动正文、列表或详情区域，标题与操作按钮不随正文滚动。关闭、消耗、技能效果、结算时机和状态逻辑不变。

## 素材

新增边框、铁砧的运行时文件位于 `src/ui/assets/`，副本同步到 `美术素材/`。确认后的三张预览保留于 `design/previews/popup-v3-*.png`，不加入运行时预加载。

本轮不启动浏览器；类型检查与构建用于验证代码和资源引用，实际窗口视觉仍需游戏内确认。
