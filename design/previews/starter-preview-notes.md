# 开局生物选择界面视觉稿

三张图分别展示主线第一步、主线第二步、熟练度远征。界面现已接入游戏；预览图仍只是构图参考，运行时使用三张不含文字与角色的独立背景，不复用战前布阵或战后奖励的营地背景。

## 画面分工

- `starter-main-step1-v2.png`：林间契约祭坛，迅迅／泡泡／灼灼三选一；选中的主力会获得同种生物 2 只。
- `starter-main-step2-v2.png`：祭坛深处的石廊，铁墩／咪咪／刺刺三选一；获得同伴 1 只。和第一步属于同一地点，但镜头、地形及石龛均不同。
- `starter-proficiency-v2.png`：独立的室内远征试炼大厅，六只基础生物任选 2 只，选中顺序以 1／2 标记，保留 15／30／50 层里程碑暗示。

主线初始生命／速度：迅迅 10／3、泡泡 14／1、灼灼 7／5、铁墩 12／2、咪咪 10／3、刺刺 11／2。预览中的生物造型为概念示意；代码接入时应使用项目实际立绘、实时属性和文案，不把整张预览当运行时背景。

主线两步宠物布局后来按石龛参考图调整：共用 `public/starter-choice-stone.png` 透明空石龛作为卡片底图，宠物立绘置于中间石台、名称及生命／速度叠在下方铭牌；选中光效由 CSS 实时绘制。熟练度的六选二布局不变。

## 实际交互

主线先点卡片选中，再按金色按钮确认进入下一步或开始游戏；返回重选会清空候选同伴。熟练度选满 2 只后可点击「出发」，也可在选择页返回首页。没有改动开局队伍数量、随机种子生成、存档结构或战斗规则。

标题可以使用像素展示字体；卡片说明、生命速度、辅助提示及按钮文字使用清晰的系统字体。背景、底座、宠物、文字和选中态应分层实现，避免把交互内容烘焙进背景。
