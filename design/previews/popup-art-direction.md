# 弹窗像素美术系统（设计稿）

六张静态预览用于确认材质、层级和按钮语义；图中文字与数值是排版示例，正式界面由游戏状态实时绘制。运行时使用单独的无字透明石框 `public/popup-stone-frame.png`（合集副本在 `美术素材/`），预览整图不加入运行时合集。

## 视觉约定

- 主题是远征路上可反复使用的「石质告示牌」：深海军蓝石板 `#101c2a`、冷灰石边 `#526678`、苔绿 `#537c59`、青绿交互光 `#70d8bd`、暖金收益 `#e8c26a`、暗红风险 `#c87872`。边角有少量藤苔；内容区保持干净。
- 背景保留当前场景，统一覆盖深蓝遮罩（目标约 65–72% 不透明），不模糊像素图像。弹窗比背景亮一档，不能靠大面积霓虹发光夺走内容焦点。
- 标题牌可沿用 Fusion Pixel 字体；正文、数字、条件、按钮全部使用清晰的系统字体。标题约 24–30 px，正文 15–17 px，注释 13–14 px，主操作 17–19 px（以 1280×860 为基准）。
- 只为当前可执行的主操作使用暖金；当前选中/键盘焦点用青绿；不可逆操作用暗红；取消、关闭、战败确认用灰蓝。危险操作不得用金色表示奖励。
- 一个弹窗只保留一个主视觉记号：放生用爪印、强化用铁砧、胜利用交叉剑、失败用裂爪、存档用档案爪印。其余角饰克制。

`CodexScreen` 是整页覆盖式图鉴，不属于弹窗，保持独立页面设计；成就页和普通奖励/商店也不因这套弹窗系统而改版。

## 预览

- `popup-confirm-release.png`：小型危险确认，覆盖融合/释放/替换/删除等骨架。
- `popup-battle-food.png`：战斗道具列表骨架；背景借用了现有布阵参考图，**只示意弹窗本身，实际入口在战斗界面**。
- `popup-growth-enhance.png`：成长消耗与强化前后对比骨架；背景同样仅为美术示意。
- `popup-battle-victory.png` 与 `popup-battle-defeat.png`：胜负同框架、不同情绪；示例金币数不代表固定游戏奖励。
- `popup-save-management.png`：六槽位大窗；各槽进度是示例，正式渲染依存档数据。

## 接入时的素材拆分与验收

不要把预览整张图当作背景。已将无文字石框制作成一张通过 CSS 九宫格伸缩的透明边框素材；按钮与弹窗内容由界面绘制，同类弹窗共用骨架。现有事件、关闭规则、解锁、战斗结算时机和 RNG 均不变。

在 1280×860 与 960×640 检查：文本不压石边、确认/取消不换位、四行物品完整可见、六个存档槽位可读；内容超高时仅内容区滚动；焦点清晰，遮罩关闭语义沿用现有实现。本次不启动浏览器、不提交。

## 生成提示词摘要

预览使用内置 imagegen 生成，均以仓库现有营地、布阵、难度石框或战斗地面为风格参考：①石质放生确认框，青灰取消/暗红确认；②四行食物货架弹窗，零库存灰显；③同构战斗胜利/失败石框，仅切换金色/暗红情绪；④月夜营地前六槽位存档管理石框；⑤强化爪击的前后数值对照与成长点消耗。完整游戏文字、数值和状态仍必须由代码实时绘制。
