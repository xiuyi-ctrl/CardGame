# 地图顶部操作栏美术方案

对应截图最上方的一行地图 HUD，不是标题首页。[静态预览](map-hud-topbar-v2.svg) 已接入地图页的 React/CSS：图标和边框为独立像素图形，文字与数值由游戏状态实时绘制。地图、存档和按钮行为未改变；其他页面仍使用原 HUD。

横栏采用一块深蓝色「远征路牌」，仅四角有石边与青绿磨损，不重复使用大块苔石雕花。内容从左至右分为：地点牌、队伍与金币、跳关与背包、返回首页。地点牌的小徽记沿用标题页“道路通向爪印”的符号；这是一处识别点，不再给每个按钮增加装饰。

| 区域 | 视觉规定 |
| --- | --- |
| 地点 | 暖金标题 `#f0d98c`，其下的「远征地图」为低对比辅助文字；熟练度模式替换为实时层数，不烘焙幕次。 |
| 资源 | 队伍用青绿像素爪印，金币用暖金堆币；数值奶白色。两项并排放在同一阅读段，不使用系统 Emoji。 |
| 跳关、背包 | 同尺寸深色硬边按钮，图标是青绿快进标记与棕金行囊。只在悬停、键盘焦点时亮青绿描边；不常驻发光。 |
| 返回首页 | 独立置于最右，以细竖线与游戏内操作分开；按钮仍为次级色，避免误认为当前主任务。 |

正文、按钮和数值使用清晰系统字体，只有徽记与图标呈像素风。1280 宽栏高约 76 px；960 宽保持单行，去掉辅助文字并缩小间距、图标与按钮。背景保持不透明，避免地图亮点透过文字区。跳关、背包、保存后返回首页沿用原事件逻辑和可见条件。
