# 新版背包：像素远征终端

视觉参考：`backpack-items-terminal-v1.png`、`backpack-partners-terminal-v1.png`。预览数值仅为示例，运行时所有物品、库存、伙伴与属性均由当前存档绘制。

- 顶部显示背包、金币、队伍数量和关闭入口；关闭仍返回原有页面。
- 物品页左侧四列网格，点击只切换右侧信息；明确的使用按钮沿用侦察、跳关和远征道具动作。食物和战斗药水不可在背包消耗，双生符保持节点使用；净化药水引导到伙伴页。
- 伙伴页保留八格收纳，点击只查看，不改变出战阵容。详情显示生命、速度、诅咒、永久强化、被动及纯名称技能标签；融合、释放和净化继续使用原动作与二次确认。
- 使用奶油色纸面、阶梯描边、橙金选中角饰和现有营地背景；六只初始生物使用新版立绘。长物品列表和详情独立滚动，关闭及使用按钮保持可见。窄窗口改为上下布局。
- 23 张独立透明图标的文件映射在 `src/ui/backpackItemArt.ts`，治疗圣水的两个数据 ID 共用同一外观。切入背包前预加载库存图标、营地及伙伴图片。

本次没有修改游戏规则，不启动浏览器，也不提交 Git；实际窗口视觉仍待游戏内确认。
