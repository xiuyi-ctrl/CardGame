# 林间流动商棚预览

本目录的三张商店预览仅用于确认视觉，不参与游戏构建：

- `shop-main-1280x860.png`：主线商店，金币 12；浆果可买、鲜肉已购买，秘晶与侦察符金币不足；免费休整和第二次刷新均可用。
- `shop-proficiency-1280x860.png`：熟练度商店，金币 35；成长之书（小）可买、治疗圣水已购买，技能强化石与复活石金币不足；无主线专属休整。
- `shop-main-960x640.png`：同一主线样例的紧凑布局。

`shop-stall-background.png` 是独立生成的无文字场景图；对应 SVG 文件将背景、像素物品图标和系统字体文字分层，`shop-preview-generator.mjs` 可重新生成 SVG。价格与商品名称取自当前游戏数据，预览中的金币、库存与购买状态是演示样例。正式接入前不复制到 `美术素材/`，也不修改 `ShopScreen` 或商店规则。
