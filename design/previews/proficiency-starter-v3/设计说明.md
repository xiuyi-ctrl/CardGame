# 熟练度模式选宠界面美术 v3

设计日期：2026-10-28。已接入熟练度选宠页；最终概念图为 `proficiency-starter-v3-final.png`，运行时背景为 `public/proficiency-starter-hall.png`。卡框、角标与按钮使用代码绘制，生物使用现有透明素材。

- 主题：林地试炼大厅，深青石墙、铜色灯火与远景星仪。
- 布局：左侧六张三列两行契约卡，右侧双伙伴槽位、15/30/50层标记和出发按钮。
- 状态：选中使用青绿描边、金色顺序角标；未选中保持正常亮度。少于两只时出发按钮禁用。
- 卡片：生物立绘、底座和属性带分区；不以文字或框线覆盖生物。详情按钮用于按需查看完整技能与被动，不因查看改变选择。
- 颜色：深墨蓝 #101e2b、石灰青 #4c6467、铜金 #cfaa60、米白 #f5ecd4、青绿 #58dbbd。
- 字体：标题使用项目离线像素字体，正文与数值沿用游戏现有字体，保证小屏中文可读。
- 手机：横屏一屏显示六张候选、两个已选槽位和主要操作；先缩减背景、立绘与间距，触控区域至少44px，不做整页缩放。
- 接入边界：概念图中的生物只作示意；接入时直接使用现有透明生物资源，不截取概念图重画角色。数值从makeUnit等当前逻辑实时读取，不写死在美术背景中。游戏动作、选宠数量及存档规则保持不变。
- 可拆分素材：无字大厅背景、契约卡框、选中框、顺序角标、双槽位面板、返回与出发按钮底图。文字、属性、角色和交互层由代码渲染。
