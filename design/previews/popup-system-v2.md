# 弹窗美术方案 v2：远征终端石纸

本稿为视觉参考，运行时弹窗已按此视觉规则接入。预览图中的文字、数值、按钮与图标均由 HTML/CSS 独立绘制，不是嵌入式整图；游戏界面继续读取实时状态。

## 视觉规则

- 底色：石纸 `#fff9e9`；墨色描边 `#101c2c`；副边 `#8a979b`；普通按钮 `#e5e5df`。
- 交互：主操作橙 `#ff8a08`，选择/信息青绿 `#1fa79a`，危险确认暗红 `#ca5149`，奖励金 `#ffcc31`。
- 弹窗保留场景背景并覆盖深蓝遮罩，不使用模糊；边框为直角像素阶梯、双层内描边和硬阴影。
- 只有当前选择项出现橙色内框；危险操作不使用橙色。标题与正文均为独立文字，长文仅内容区滚动。

## 各界面套用

| 类型 | 入口 | 样式重点 |
| --- | --- | --- |
| 危险确认 | 放生、替换、删除/覆盖存档 | 宠物/目标肖像与后果并列，确认键暗红，取消键灰白 |
| 战斗列表 | 捕获食物、战斗道具 | 四行货架，图标在左、数量在右，零库存灰显 |
| 成长操作 | 强化、重置、成长点转移 | 当前值 → 结果值居中，成本与持有量同一行 |
| 战斗结算 | 胜利、失败 | 同一结构切换金色奖励/暗红失败信息；战败确认用灰白 |
| 存档管理 | 六槽位存档管理 | 两列三行，当前槽位橙框，空槽位虚线，删除入口独立 |
| 情报揭示 | 地图侦查、事件结果 | 青绿信息标题，只展示已揭示数据 |
| 轻提示 | 成功、警告、错误 | 无遮罩短条，左侧颜色编码，不打断操作 |

运行时对应 `confirm-box`、`battle-overlay-panel`、`growth-modal`、`overlay-box`、`save-mgmt-panel`、`toast` 六类结构；保持既有事件与关闭行为。设计预览见 `popup-system-v2.html`、`popup-system-v2.png` 和 `popup-system-v2-defeat.png`。
