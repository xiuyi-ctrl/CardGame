# 战斗图标 PNG 第一批

生命与速度图标已接入战斗及战前布阵的生物属性位；六种药水复用背包素材，已接入战斗道具弹窗。

| 文件 | 用途 | 来源 |
| --- | --- | --- |
| `life.png` | 战场生物生命 | 新设计，参考现有生命图标 |
| `speed.png` | 战场生物速度 | 新设计，参考现有速度图标 |
| `atk_up.png` | 攻击药水 | 复用背包已有 PNG |
| `spd_up.png` | 加速药水 | 复用背包已有 PNG |
| `hp_up.png` | 生命药水 | 复用背包已有 PNG |
| `atk_down.png` | 虚弱药水 | 复用背包已有 PNG |
| `spd_down.png` | 缓速药水 | 复用背包已有 PNG |
| `hp_down.png` | 腐蚀药水 | 复用背包已有 PNG |

统一规则：透明底、深海军蓝像素描边、亮色主体、左上角高光；生命与速度预期按 20–28 CSS 像素显示，药水按 32–48 CSS 像素显示。`index.html` 可按目标尺寸检查辨识度。

新生成素材使用内置 imagegen，提示词要点：单个居中的红色像素心形或金色像素闪电，参考仓库同类图标，深色硬边轮廓，透明背景，无底框、文字或多余装饰。交付图按最近邻缩至 128 × 128。
