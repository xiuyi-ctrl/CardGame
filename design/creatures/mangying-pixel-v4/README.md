# 蟒影像素美术 v4：重做进化剪影

日期：2026-10-26。

用户认为v3与基础咪咪过于相似，本版不再沿用直立C形颈和单圈坐盘。改为横向展开的双环盘身，身体占主要体量；颈部弧向侧前方，头部压低伸出，尾部从后方粗壮上卷。新增一对展开的短叶状颈鳍，保留成长感。最终形态的高耸宽颈、巨角和王冠保留给传奇阶段。

延续mimi-pixel-v2大色块、少量明暗、紫色平面毒纹与统一像素密度。不添加鳞片纹理或碎高光。生成参考中的v3仅标记需要避免的姿态，不作为最终轮廓。

raw-sheet.png为内置图像生成原稿，sprite-original.png为透明原稿，sprite-64.png为规范导出，preview-512.png为最近邻预览，pixel-qc.json为验收，line-compare.png为基础咪咪与本次进化的同尺度对照。
