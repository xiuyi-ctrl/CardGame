# 烈日神鹰美术 v1

谱系：焚风雏鹰→焚风鹰→烈日神鹰。保留赤橙羽毛、焦黑翼尖、奶白胸羽、金色喙爪及深色眼纹，统一像素密度。三阶分别采用短翼圆身幼鸟、斜向飞行的修长猛禽、宽翼日轮与五羽扇尾的成熟神鹰。

- `sprite-original.png`：清晰透明原稿。
- `sprite-64.png`：64×64透明PNG，最多24色、透明度0/255、底部y=59，四周至少4像素安全边。
- `preview-512.png`：最近邻放大预览。
- `raw-sheet.png`、`prompt-used.txt`、`export/`、`pixel-qc.json`：生成及处理记录。

本稿因与焚风鹰相似被替换，仅保留为历史稿。实际接入版本为 `solar-eagle-pixel-v2` 四翼造型。
