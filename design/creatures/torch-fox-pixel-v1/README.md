# 传火狐美术 v1

火狐的传火支援分支。传火狐采用幼年行进姿态和双尾灯焰；传火狐尊采用长身四足、奶白披鬃、三尾环抱的守护轮廓。保留赤橙毛色、黑足及耳尖、额心金纹，以尾端托火和护火姿态突出配合定位，与幻尾火狐及九尾炎尊分支区分。

- `sprite-original.png`：清晰透明原稿。
- `sprite-64.png`：64×64透明PNG，最多24色、透明度0/255、底部y=59，安全边至少4像素。
- `preview-512.png`：最近邻放大预览。
- `raw-sheet.png`、`prompt-used.txt`、`export/`、`pixel-qc.json`：生成及处理记录。

此次仅设计美术，未替换运行资源，不修改技能、数值或进化路线。
