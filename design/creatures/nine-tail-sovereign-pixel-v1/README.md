# 九尾炎尊美术 v1

火狐→幻尾火狐→九尾炎尊的最终进化。由低伏双尾成长形态改为成熟灵狐端坐，九条尾巴分层形成冠轮，前肢挺直、颈胸鬃毛厚实、头身比缩小，神态沉稳。保留额心金纹、黑足、奶白面胸纹、赤橙毛色与金焰尾尖。

九尾布局：左侧四尾、右侧四尾、中央最高一尾。尾巴为实体连接的身体结构，不使用漂浮粒子代替。
