# 熔甲兽美术 v1

熔壳虫→熔甲虫→熔甲兽的最终进化美术。依据前两阶的炭黑甲壳、橙红熔缝、奶白面纹和余烬触角设计。

由中阶高圆甲虫变为横向展开的六足重装巨兽，前肢粗壮、背甲后掠、头部成熟，配分叉冲撞角和赤红炉腹。以身体比例、姿态和轮廓变化体现进化，保持整条谱系的像素密度与描边。

- `sprite-original.png`：清晰透明原稿。
- `sprite-64.png`：64×64透明规范导出，24色以内、透明度0/255、底部y=59，四周至少4像素安全边。
- `preview-512.png`：最近邻放大预览。
- `raw-sheet.png`、`prompt-used.txt`、`export/`、`pixel-qc.json`：原稿、提示词与处理验收记录。

已按用户要求接入透明原稿至 `public/molten_beast.png`，同步美术素材副本；保留64像素导出，旧存档缺图时自动补齐。不改生物数值与技能。
