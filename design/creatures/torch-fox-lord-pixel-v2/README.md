# 传火狐尊浅蓝美术 v2

用户认为赤金传火分支与另一形态相似，要求浅蓝风格。本稿改为浅蓝毛色、月白披鬃、青白狐火、深蓝火种纹及额心纹，保留琥珀眼和深色耳尖、足部。传火狐采用双尾幼年行进姿态，传火狐尊采用长身四足、三尾护火轮廓。仅改变美术，不将玩法改为冰系。

保留 `sprite-original.png` 清晰透明原稿、`sprite-64.png` 规范导出及 `preview-512.png` 最近邻预览。64像素版最多24色、透明度0/255、安全边至少4像素、底部y=59。原稿和QC记录同目录保存。
