# 驯牌远征 (PetCard Rogue)

肉鸽卡牌宠物对战游戏。选择御三家伙伴，穿越随机生成的按幕递进地图（8~14 层），驯服敌人、融合进化，连闯 3 幕击败首领。

- **技术栈**：Electron + Vite + React + TypeScript
- **核心玩法**：固定技能数值、回合制战斗、残血驯服、融合进化、随机抉择事件、可播种随机（全局可复现）
- **平台**：Windows 便携版 `.exe`

## 快速开始

```bash
# 安装依赖（国内需镜像）
ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm install

# 开发模式（Vite + Electron 双进程热更新）
npm run dev

# 测试 / 类型检查 / 构建
npm test
npm run typecheck
npm run build

# 生成关卡情报 MD（默认 seed=2000；可设 DUMP_SEED 指定种子）
npm run dump-map

# 打包 Windows 便携版（产物在 release/）
npm run dist
```

> 打包遇到 winCodeSign 符号链接权限错误时，先设置 `$env:CSC_IDENTITY_AUTO_DISCOVERY="false"`。

## 玩法

- 开局 2 只宠物，队伍上限 8、出战 5；队伍已满时驯服/孵化/招募的新宠物可替换/融合/放生（队伍有空位时可直接加入；融合时待处理宠物也可作为材料）。
- 宠物只有生命/速度两个属性（物种固定值），伤害=技能固定值+固定修正；战斗胜利后全队回血 60%。
- 每只宠物带**专属被动**（减伤/反伤/再生/吸血/附加异常等，战斗中自动生效）；强势技能（愈光、战吼）每场限 2 次。
- 敌人残血（≤40%）可喂食驯服；宠物阵亡永久删除。
- 无等级经验，进化靠「融合」：第 n 阶需 n+1 只同物种（如 迅迅→迅牙（2只）→迅天（3只））。
- 每幕层数按幕递进（幕1 8~10、幕2 10~12、幕3 12~14）、中间行 3~5 节点；出发后第 1 行强制全战斗，精英前期更少出现；末层 2~3 个首领（从各幕首领池抽取，击败任意一个即过幕）。

### 难度系统

开局可选择难度（普通/困难/地狱），影响敌方 HP 缩放、速度加成、战后回血比例、商店价格倍率。

### 遗物系统

通关后解锁遗物，开局可携带 1 个遗物获得特殊加成（金币/圣果/宠物/药水等）。

### 幕间统计与评级

每幕击败首领后显示本幕增量统计（战斗/驯服/经济/效率等），通关后按 5 维度综合评级（S/A/B/C/D）。

### 成就与解锁

通关不同难度/评级可解锁新遗物和成就，主菜单「🏆 成就」查看全部进度。

## 熟练度远征模式

独立 Roguelike 爬塔模式，从主菜单「⚔️ 熟练度远征」进入（需通关主模式第 1 幕解锁）：

- **开局**：3 只宠物（迅迅/泡泡/灼灼），30 金币，无法驯服/融合/招募
- **地图**：线性 50 层，每层 1 个节点（战斗/精英/事件/商店/奇遇/休憩），层 15/30 为随机 Boss，层 50 为成长之主
- **成长系统**：战斗获得成长点（每场参与+2/存活+2），击杀奖励（普通+2/精英+4/Boss+6）

  - 分配属性：HP（递增消耗 2→10 点/次，+2HP）、速度（递增消耗 2→5 点/次，+1SPD），上限 +30HP/+15SPD
  - 强化技能：8/10/12 点（攻击+2 伤害/治疗+2/buff+1 效果值，每技能最多 3 级）
  - 解锁技能槽：第 3 槽 5 点、第 4 槽 8 点、第 5 槽 10 点
  - 替换技能：8 点（覆盖该槽位）
  - 还原石（25 金币）：重置全部强化，返还 50% 累计消耗
  - 技能强化石（40 金币）：免费强化 1 次（不消耗成长点）
  - 成长点转移：将 1 只宠物的成长点转移给另 1 只，手续费 = 转移量的 50%（向上取整）
- **回复**：战后回血80%，休息点100%+融合（继承副宠50%基础属性+30%成长点+可学技能），商店药水50%
- **商店商品**：成长之书（小）12金+1点、成长之书（中）22金+2点、成长之书（大）30金+3点、技能槽解锁50金、遗忘之石30金、治疗圣水30金、还原石25金、技能强化石40金
- **竞技场三模式**：模拟战（镜像，无惩罚，胜利+5成长点）、精英挑战（3精英，+100金+2成长点）、展览比试（+20金+指定宠物+5成长点）
- **背包道具专用屏幕**：技能强化石/还原石从背包使用时进入专属屏幕，直接选择宠物执行
- 详细设计见 [`游戏文件/熟练度肉鸽模式.md`](游戏文件/熟练度肉鸽模式.md)
