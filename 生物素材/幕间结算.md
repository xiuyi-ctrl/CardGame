## 幕间挑战 + 最终评级系统（完整设计方案）

### 一、设计目标

| 目标               | 说明                                                         |
| :----------------- | :----------------------------------------------------------- |
| **提供阶段性反馈** | 每幕结束给予玩家清晰的成就感和数据复盘，而非"打完就忘"       |
| **创造长线目标**   | 评级系统鼓励玩家反复挑战，追求更高评价，而非"通关即止"       |
| **解锁重玩价值**   | 高评级解锁新难度/初始遗物，形成"挑战 → 成长 → 再挑战"的正循环 |
| **强化叙事沉浸**   | 在幕间加入世界观的串联文案，让三幕不再是割裂的关卡，而是一段完整的远征叙事 |

------

| 幕次     | 界面主题       | 背景文案                                                     |

| **幕 1** | 🏕️ **远征启程** | "翠绿之径的风已歇，前方的路尚在雾中。整顿行装，你已踏出第一步。" |
| **幕 2** | 🌑 **暗影渡口** | "暗影沼泽的瘴气渐散，你听到了更深处的回响。真正的考验，才刚刚开始。" |
| **幕 3** | ⚔️ **终局之前** | "火焰与铁链的咆哮在身后沉寂。前方，是远征的终点——或是一切湮灭的起点。" |

### 三、最终通关评级系统

游戏通关后，进入一个独立的 **「远征评级」** 界面，对整局游戏进行综合评定。

#### 3.1 评级维度与算法

最终评级由 **5 个核心维度** 加权计算得出（总分 0~100），每个维度有独立评分与评级字母。

| 维度           | 权重 | 计算方式                    | 满分条件                        |
| :------------- | :--- | :-------------------------- | :------------------------------ |
| **征服者**     | 30%  | 三幕总胜率 × 100            | 胜率 ≥ 90%（含斗兽场/车轮战）   |
| **驯兽师**     | 25%  | 驯服率 × 100                | 驯服成功率 ≥ 80%                |
| **经济大师**   | 20%  | 终局金币 / 总金币收入 × 100 | 金币结余率 ≥ 30%                |
| **战斗效率**   | 15%  | 基于总回合数的效率分        | 总回合数 ≤ 90 回合              |
| **队伍完整性** | 10%  | 终局队伍规模 / 8 × 100      | 终局队伍 ≥ 7 只                 |

**最终总分 = Σ(维度分 × 权重)**

#### 3.2 评级等级

| 评级  | 总分要求 | 称号             | 解锁内容                                       |
| :---- | :------- | :--------------- | :--------------------------------------------- |
| **S** | ≥ 90     | 🏆 **传奇远征者** | 解锁「地狱难度」+ 初始遗物「传说印章」+ 勋章检测 |
| **A** | 75 ~ 89  | ⭐ **精锐指挥官** | 解锁「困难难度」+ 初始遗物「精英勋章」          |
| **B** | 55 ~ 74  | 🗡️ **可靠旅人**   | 初始遗物「旅行者护符」                          |
| **C** | 40 ~ 54  | 🌱 **初生牛犊**   | —                                               |
| **D** | < 40     | 💀 **幸存者**     | —                                               |

#### 3.3 评级界面布局

通关后显示评级界面，包含 5 维度评分、解锁内容通知、队伍快照，以及「再来一次」和「返回标题」按钮。

### 四、解锁内容详细设计

#### 4.1 难度级别系统



| 难度     | 解锁条件            | 全局修正                                                     |
| :------- | :------------------ | :----------------------------------------------------------- |
| **普通** | 默认解锁            | 无修正                                                       |
| **困难** | A/S 级通关          | 敌方 HP ×1.2、SPD +1、战后回血 40%、商品加价 20%            |
| **地狱** | S 级通关            | 敌方 HP ×1.5、SPD +2、战后回血 20%、商品加价 40%            |

精英节点额外 +10% HP、+1 SPD（叠加于难度缩放）。

#### 4.2 初始遗物系统（每局开局可选1个）



| 遗物             | 解锁条件              | 效果                                             |
| :--------------- | :-------------------- | :----------------------------------------------- |
| 🧭 **旅行者护符** | B 级通关              | 开局金币 +100                                    |
| ⚔️ **精英勋章**   | A 级通关              | 开局赠送 2 只随机精英怪卡                        |
| 👑 **传说印章**   | S 级通关              | 开局赠送 1 个「圣果」+ 1 只随机二阶宠物          |
| 🔥 **火焰勋章**   | S 级 + 队伍 3+ 灼烧被动 | 开局赠送 1 只「灼灼」+ 2 个「攻击药水」          |
| 🌿 **自然勋章**   | S 级 + 队伍 3+ 护甲被动 | 开局赠送 1 只「铁墩」+ 2 个「生命药水」          |
| 🌙 **暗影勋章**   | S 级 + 队伍 3+ 中毒被动 | 开局赠送 1 只「咪咪」+ 2 个「腐蚀药水」          |

> 勋章类遗物为隐藏解锁项，需要玩家以对应流派（队伍中≥3只同机制宠物）获得 S 评级后解锁，鼓励玩家尝试不同构筑。

### 五、幕间叙事串联

在幕间结算中，除了数据，还加入一段简短的 **「远征日志」** 文本，由系统根据本幕的关键事件自动生成，增强沉浸感：



| 触发条件           | 日志文本示例                                                 |
| :----------------- | :----------------------------------------------------------- |
| 驯服了传奇品质宠物 | "在翠绿之径的深处，我以一枚圣果赢得了【灼天】的信任。它眼中的光芒，将照亮前路。" |
| 宠物阵亡           | "N只伙伴在暗影沼泽的最后一战中倒下。它们的盾牌已碎，但它们的意志将与我同行。" |
| 高效通关           | "穿越火焰山脉的过程出奇顺利，每一次决策都精准到位。强者的道路，从不拖泥带水。" |
| 未触发任何特殊事件 | "一路平静地走过了翠绿之径，但我深知——远征的真正考验，永远在下一座山丘之后。" |
